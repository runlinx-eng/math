# 数学探索

项目目录：`/Users/zj1-6/dev/math`。原 `agents/experiments/math-explorer` 目录保留为迁移前副本。

本地、离线的中文数学探索空间，基于 Marble / os-taxonomy。只做数学、电脑端和孩子入口；年级、年龄、教材不决定路线。

**当前固定来源的 587 个数学节点均已接入有限学习任务，组成 231 条短路线；1,223 条原关系中有 776 条设有联合操作。** 这不是全部数学知识，也不代表每个源目标的完整能力已评估。孩子尚未试用，活动完成不等于掌握。

## 打开

双击 **启动数学探索.command**，或在本目录运行：

```sh
python3 scripts/server.py --open
```

入口：[数学探索](http://127.0.0.1:43827/?v=51#space)。[把想法说清楚](http://127.0.0.1:43827/?v=51#space/pack/reasoning)。已有页面刷新即可；如需按新版取景重新看整张图，点“全貌”。启动窗口保持打开，结束时按 Control+C；再次启动复用当前服务。只监听 127.0.0.1，需要 Python 3 与支持 WebGL 2 的浏览器，无 npm 安装、数据库、模型接口或账号。保留的平面入口为 `v2.html#map`。

## 这一版怎样使用

默认打开一张可旋转的立体知识地图。587 个节点共用固定坐标：横向按五个主题、23 个内容分组聚集；高度按 851 条关键前置关系统一分层，前项始终在后项下方。372 条辅助关系保留为虚线，不决定高度。全图保留全部 1,223 条源关系；节点基础大小一致，高度和距离不表示难度、年级、掌握程度或规定路线。

“顶视 · 分布”看主题与内容分组，“侧视 · 层次”看整张图的前后层次，“立体总览”同时观察两者。三个按钮只移动相机，选中节点也不重排知识点。全貌按实际知识点取景，先显示五个主题名称；放大后依次出现分组和知识名称。选中节点时淡化背景，橙线从基础指向这里、蓝线从这里指向后续；实线与虚线仍区分关键和辅助关系。密集处可平移、旋转、查找，或在侧栏展开全部直接关系。点“开始”进入已有活动。

选中一个想法后，侧栏直接列出它的联系；鼠标停在名称上或用键盘聚焦时，地图临时突出对应的点和线，点名称才切换。点“追溯基础”或“查看后续”，可沿来源里的关键关系查看全部分支；“隔几条联系”表示最短路径的关系数量，不改变空间高度，也不规定学习顺序。“上一处”恢复上一个节点的关系范围、视角和列表位置。

重名想法会根据来源中的数学目标添加区分，例如“等值分数 · 看图识别／细分与合并／同倍变化”。1,223 条源关系均有本地中文说明，并保留来源原文；说明根据源理由和相关目标编写，尚未经过独立数学审阅或实际使用验收。逐条对照记录位于 `docs/spatial-exploration/relation-review.json`。

活动小图形在选中或悬停的节点旁显示，表示这里能做什么，例如分份、走数轴、搭积木或画图；点“开始”才进入真实活动。小方形标出未完成的活动现场，菱形标出绑定到节点的待续问题。完成节点与完成联合任务分别记录，只有实际做完联合任务才点亮对应连线。

顶部“原有空间”可回到原来的布局；原有空间与新全图分别保存视角；问题还保留坐标版本、观察方向和缩放。v47、v48 旧问题继续恢复保存时的原坐标与相机，切回三个观察按钮才返回新全图。切换前先退出正在打开的活动或工作面，原有学习数据、问题和草稿保留。尚未选择视图且原空间有未结束现场时，会先恢复到原空间。全图也保留原来的路线入口：先看五个方向，再选一个分组。有多条路线的分组先给 2–3 个选择；“数的样子与大小”先收成“看清数量／沿数字走／数字与数量对应”三个方向，每次最多三条路线，可用“再看看”换一组；选定后只展开 2–4 个编号节点。编号是建议顺序，可以自由跳看。返回、上一处和刷新保留刚选的路线和所在组。

“合起来与拿走”先选“摆出故事／拆开与凑十／换个顺手的算法”，再选一条有2—3个节点的小路线。

“成组与平均分”先选“一堆分成几份／排成行，看乘除／换个办法算”，每条路线只展开2—3个节点。可以分物品、拆阵列、把十个换一捆、逐位分与乘回检查、搭因数树、配共同因子、排列并运行查找规则。

“一份与同一个量”先选“分出一样多的份／把一份接成一个数／换个样子，说同一个量”，每页最多三条路线。原A、G、H也在这些方向里。分开的每一片仍能看见来自哪个整体，回来时能接着原来的分配继续。

“问问题与收集”先选“把记录看明白／试做一次调查／让问题更可靠”。模拟调查从同一份原记录走到表、图和结论；更正后重新核对，旧记录仍保留。

“把数据画出来”先选“把记录看明白／看时间与份额／看分布与联系”。逐条放点、按区间归组、拼出份额，再比较同一数据的不同画法。点已放齐后，录入控件收起，接着看趋势或回答问题；需要时可展开更正。

“比较与推断”先选“找一个代表值／把两组放在一起看／从一部分推到整体”。搬动分数堆、排数据卡、比较整群点，再从同一个总体反复抽样。每次实际抽到的记录都保存，不挑选结果。

“形状有什么共同点”先选“看边和角／拼合与转动／折叠与构造”。可以搭立体框架、拼图、尝试折线和用圆弧找交点。

“位置与变换”先选“找位置，认坐标／移动与翻转／折叠、转动与图案”。可实际放点、移动图形、折回镜像、转动并比较铺图。

“转弯与角”先选“先转一转，看开口／把线和角连起来／拼图形，试条件”。可实际改变开口、移动量角器、拼角和用圆弧交点构造三角形；“一条斜边和一个角”还可比较三边正方形与参考角比例。

“用单位比较”先选“比一比，再量／用不同的尺／换单位，画记录”。可以对齐起点、摆单位、放砝码、读刻度，把同一个量换成不同单位，再把测量记录画成点图。

“边界与铺满”先选“铺里面，拆成几块／沿外边走一圈／包外面，装里面”，每页最多三条路线。可以铺方格、拆图，转动立体并对应展开图，再比较拼接后藏起的面。

“装得下多少”先选“换容器，量一量／一层一层填空间”。可以把水倒进相同的杯子比较，用同一个物体比较轻重，再把分数边长的小方块按层填进盒子。

“从平面到立体”先选“转动与辨认／拼搭与折合／移动切面”。可以转动立体、组合积木、把纸片折成两头是三角形的盒子，或移动切面比较形状。

“相等与未知数”先选“找出盒子里的数／把关系写出来／拆开，再收起来”。可以改变两边、试数对、拆括号，或找两条线共同经过的位置。

“一起变化的量”直接选“从图形走到公式／在平面上找位置／让图线跟着变化”。可以改变图形尺寸、在坐标平面放点，或改变数值观察图线。

“放大、缩小与比例”先选“一百份里的多少／配在一起，分给各人／一起变化与缩放”。可以涂百格、比较两组配比、实际分等份，或改变图形倍数并观察面积。

“寻找与创造规律”先选“摆一摆，发现重复／数怎样一步步变／改规则，看结果”。可以搭图案、转动积木、比较不同规则，并把操作接到相关节点。

“可能与不一定”先选“先看机会有多大／让结果跑起来／几件事一起发生”。先圈结果、试机会，再比较实际记录、搭出路径和两圈关系；旧L路线仍可进入。

## 完成与每天接续

每个任务须有成立的作品才完成。点开、任意拖动、错误提交或直接跳总结不会点亮。首次错误、提示、重答、当前作品和解释都保存；首次未用帮助的正确操作另留证据。自由解释只保存，不按字数或提交就判懂。

全景显示今天新增的节点与连接。路线里展开“把想法连起来”，实际共同使用两个想法后，才点亮对应源边；两端分别完成不会自动亮线。点击“留到下次”保存问题原话、位置和操作现场，下一次从问题继续；“先放着”允许转去别处。没有问题时接着未完成任务或建议下一处，没有对应活动的问题照样保留。

随机实验保存种子及实际结果，重新打开不会重新抽一组；图上的比例来自实际模拟，不为显示规律调整结果。模拟测量、折叠和调查不代表已经完成真实工具操作或现实调查。固定任务完成也不证明长期保持。新数词活动以中文适配；原英文拼读拼写没有评估。音频本机播放，手写只保存，不自动判字；口述计数也未自动评估。

旧活动与早期 `journeys.portions` 保持历史完成含义，不升级为新版独立证据。旧 A–03 的“半杯”节点现为 A–04；新 A–03 是另一个来源 ID 的小数节点。旧、新活动交替写入时保留双方记录。

## 离线与备份

资源在本机。首次缓存完成后可离线重开；浏览器可能清理缓存，启动脚本仍是可靠入口。学习记录在当前浏览器、当前地址的 localStorage；换浏览器、端口或清理站点数据不会自动迁移。

通过“更多 → 导出学习备份”保存 JSON。导入先校验、合并历史、保留当前草稿；坏文件不覆盖，导入前另存快照。存储键 `math-explorer-v2`、备份格式 2，包含 `lessons`、`lessonContinuation`、`daily`，并兼容旧 `activities`、`journeys.portions` 与 v1 记录。

主世界视角和路线选择存于 `math-explorer-space-v1`，不作学习证据，也不包含在学习备份中；随问题保存的位置与操作现场包含在备份中。
