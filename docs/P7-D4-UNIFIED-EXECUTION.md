## 1. 可执行的最小机制（不是另外三道关卡）

同一学习页面的固定顶部 `.stage-top` 始终提供：真实知识标题、简短来源学习目标、现有三步非强制状态提示、由当前活动与检查状态派生的行动指令 `#action-cue`、**唯一高亮操作** `#actions .primary`。任务 x/n 仍使用现有 `#status`；返回入口在独立页面 `#back`、嵌入时由原 3D 工作区外层提供。顶部保持 sticky，长任务滚动不丢失操作位置。

活动正文继续从 `TASKS`、`BRIDGES` 的实际任务构造，`#work` 始终只有一份；`widgets`、`renderExtra`、原来的 3D 教具与全部动作/字段事件保持原位置及尺寸。通过 `executionCue` 与 `activityTitle` 仅选择**呈现文字**，不生成题目或数学验证规则。任何未单独适配的任务类型进入通用现有教具+操作指令，而非被排除。

`#learning-check` 只呈现实际检查反馈/具体修改指导（尤其 grid / equivalent / line），系统解释只在已有证据和必要时出现；`#learning-next` 承载主动请求的关联任务、模拟应用及原历史重做，`#record` 提供尝试与原始来源。没有新存储字段。孩子的解释始终与已检查作品区分。

## 2. 一个真实状态决定一个主操作

| 真实状态 | 固定顶部行动 | 运行时责任 |
| --- | --- | --- |
| 新题/自由构造 | 根据 task.type 简述在哪里操作，`检查我的作品`；counttwenty 未具备条件前禁用检查 | 维持原输入与原判题 |
| 检查错误 | 有来源的具体修改建议优先，`修改后重新检查` | `currentSubmission` 与原历史 |
| 改动后的未复检作品 | `重新检查`；不沿用旧证据 | 原状态判断 |
| 作品通过、下一题存在 | `进入下一题` | 已配置同组任务 |
| 最后一题通过 | `整理这次发现`（文字可选） | 原 summary 状态 |
| 总结草稿待保存 | `保存我的发现` 唯一高亮、真实继续为次级按钮且可达 | 原 notes/draft；失败不能报成功 |
| 总结已保存/无草稿 | 真实后续路线或源关系 `BRIDGES`，否则返回原知识空间 | PR #49 来源校验与原 3D 关闭 |
| 无专门任务的知识节点 | 保留原 3D 观察、知识关系和当前工作区合法入口；**不生成伪任务** | 此分支不扩充 3D 配置 |

初次任务中单一按钮可以被点击并获得原判题反馈；这不是软件强制的“先操作完才能提交”关卡。不同题型仍自行决定是否支持检查就绪条件。上方固定不代表不需要滚动查看教具，且不能代替儿童真实理解测试。

## 3. 完整能力的去向

逐 ID 可追溯清单见 `docs/P7-D3-CAPABILITY-AUDIT.md` 和 `node scripts/build_p7_d3_inventory.mjs` 输出 `verification/p7-d3/capability-map.csv`、`capability-map.json`、`audit-counts.json`；栏目 `source/id/originEntry/userTask/dataJudging/currentUI/uiRole/showWhen/accessGuarantee/recommendation/status/evidence/preservation` 继续作为完整映射，测试不得出现遗漏。

| 类别 | 执行位置 | 保留与调用边界 |
| --- | --- | --- |
| 固定框架 | 顶部 `stage-top` + `action-cue` + `actions` | 一次只突出一个主动作；状态来自原记录 |
| 数学内容 | `learning-problem` 与 `learning-interaction/work` | 根据实际任务调用原专属交互，不虚构内容 |
| 即时辅助 | `check-feedback` / `math-explanation` / `hint` | 真实判题之后或主动请求时；数学说明不抢答 |
| 学习延伸 | `p3-learning-flow` / `record` / 系统说明 | 关联源边、自由文字与模拟实践保持区分 |
| 后台能力 | `state.js`、`daily.js`、`storage.js`、导入/导出、离线、思维反馈 | 保持原格式、保存状态、异常呈现和恢复路径 |
| 待归类保留 | `PRACTICE/models[-1]`、旧 v2 活动、`journey.html`、两项实验、旧 quiz | **不删除**；原入口未完成等效性与浏览器人工核查，标记未决风险 |

尤其注意：`PRACTICE/models[-1]` 的原自由操作入口仍存在“可能不可达”的旧风险。本轮没有声称恢复、替代或已删除。不得把能力清单的“源码接入”写成实际孩子可使用的证据。原有 587（537 领域+50 思维）节点、1,223 源边、1,996 节点任务、776 源关系桥与 1,552 桥内任务由原数据/生成器核查，不能以文档声明作为测试通过。
