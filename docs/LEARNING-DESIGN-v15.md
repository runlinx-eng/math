# 数学探索：结构、活动与证据

2026-10-26，扩展内容版 v15。149 个可学习源节点、472 个节点任务、51 条短路线、78 条连接活动。内容与技术检查完成，孩子尚未试用；历史设计保存在 `LEARNING-DESIGN-v8.md` 等文件中。

## 学习的入口

只做数学、电脑端、孩子入口。年级和年龄不控制路线。先看五个主题，再进入少量分组；有多条路线的分组先提供 2–3 个选择，选定后只展开 2–4 个编号节点，允许跳转。B06–B09 在同一分组的28条路线按三个方向收拢，每次最多三条，可用上一组/再看看换组；方向、组和路线刷新后保留。返回和上一处保留选定路线。全图 587 个节点、23 个分组、1,223 条数学关系仍可查。

连续三维空间保留同一张画布、固定位置与来源关系。位置与距离帮助辨认，不表示年级、难度或掌握程度。分类、坐标和路线为本地适配，连线来自原始关系；相邻编号不自动构成新先修关系。当前普通入口不铺开全部小球，完整图仍可主动展开。

B10在“合起来与拿走”新增8条路线，先给“摆出故事／拆开与凑十／换个顺手的算法”三个方向，各方向不超过3条路线；不同分组不会混显所有方向。

## 动手、换条件、再命名

活动按“通俗问题 → 可改变的对象和反馈 → 换条件或表示 → 总结正式名称”组织，只打开一个操作现场。任务与 448 个源目标逐项对应于 [覆盖表](phase5/COVERAGE.md)。130 个节点适配原研究，19 个缺研究节点补充本地依据，具体见阶段 2、阶段 4 以及 [B07](phase5/B07/RESEARCH.md)、[B08](phase5/B08/RESEARCH.md)、[B09](phase5/B09/RESEARCH.md)、[B10资料](phase5/B10/RESEARCH.md)。

| 内容 | 主要数学对象 | 操作保留的证据 |
| --- | --- | --- |
| 分数、比例与缩放 | 等分、分组、百格、数轴与对应条带 | 切口、选取、整体单位、预测及量的对应 |
| 平面与测量 | 单位方片、长宽、尺、砝码和容量模型 | 覆盖、行列、单位、工具选择、估计及实际模拟值 |
| 立体与展开 | 真正可转动的立体、自画六格、铰接折叠 | 面线角标记、折前预测、相对面和折后检查 |
| 数据与随机 | 模拟记录、不同图表、转盘、重复抽样 | 分类、比例尺、构造结果、种子及逐次结果 |
| 数量与数的表示 | 逐颗标记、配对、分组、短时点图、数轴、位值束、中文音频 | 物品身份、数量不变、每站变化、听读与笔迹记录 |
| 十进位结构与运用 | 十格长条、百格板、换装台、数轴、虚拟代币 | 双向交换、不同分拆、原始预测、零占位、包装余数 |
| 大数、小数与近似值 | 数位筹码、固定小数点的位移、相邻两站、端点试验、罗马符号 | 首次猜想、换组守恒、数字位置、实际估位、有效数字、边界记录 |
| 数轴、负数与数的范围 | 有向跳跃、零点距离、范围、立方体、余数分份与不断放大的区间 | 首次猜想、正确拆法、端点试验、真实积木和精确分数 |
| 合分与加减策略 | 两堆、十格框、配对、三堆与单位捆 | 原量和变化、十的中途站、不同配对、算式、错误和帮助 |
| 规律与论证 | 重复单元、增长塔、天平、十进制束与数对 | 保持结构、代回检验、数量守恒、理由链和反例 |

B08的大数筹码按标签计单位，不暗示体积比例；取近似值直接从原数判断，末尾零可记录精度。区间限定非负半入约定；人口、场馆与深度明确为模拟数据。

B09的自选数轴跳跃允许不同正确拆法，范围试数允许自选正确的内部和外部数；量尺需要真实对齐与连续拼接。立方体可搭建、转动与拆层。分数缩放与√2夹逼采用精确整数比较；有限次放大不替代无穷的一般理由，分类所用的数学依据不等于孩子已独立论证。

B10凑十保留同一颗圆片的身份，分两段实际搬动；只写最终答案不能完成。等号反向可以成立，固定整体的左右交换不重复计数。事实族要求四个对应动作，减法提供换序与分组反例；帮助及活动内纠错反馈留下支持记录。少量回忆不计时，不宣称全范围熟练、三秒回忆或真实手指能力。

三维用于适合的对象，不强迫所有概念都表现成三维模型。模拟调查、屏幕测量和折纸明确限定为模型活动，不能声称孩子已进行真实调查或会操作实物。

随机实验只生成一次并保存；恢复时不重新抽样。次数更多通常让比例更集中，但每轮不保证更接近理论值，活动展示真实采样和明确标注的反例。有限的数列不能唯一决定后续，增长活动明示采用固定变化规则。按目的选图允许合理的不同选择。

构造、解释与迁移也存在于传统课堂。本项目的特点是空间组织、可改变的对象、知识联系和持续记录；不把交互形式本身当作理解证据。

## 完成与证据

| 对象 | 当前含义 | 边界 |
| --- | --- | --- |
| 完成／未完成与整体进度 | 149 个已开放源节点的活动进度 | 替代活动、浏览和连接任务不重复增加分母 |
| 节点完成 | 每个任务至少有一次成立的作品 | 帮助后可完成，但不成为首次独立操作证据 |
| 首次独立操作 | 首次提交成立、未用提示或先看反馈，最新作品仍成立 | 固定案例的操作证据，不代表整体或长期掌握 |
| 开放解释 | 保存问题与孩子原话 | 不按字数、提交或机器猜测自动判懂 |
| 连接完成 | 两端想法在对应联合任务中实际使用 | 两端分别完成、浏览连线都不亮线 |

错误首次提交及后续修正合并保留，导入不会清除提示记录。一般论证须有构造、能适用于整类对象的理由及反例辨别；仍不把排列给定理由当作独立解释能力已被评估。最后的正式定义帮助命名前面的操作，不以读过定义作为验证。

旧活动与早期 `journeys.portions` 保持历史规则，旧完成不升级为新版独立证据。旧 A–03 半杯节点现为完整的 A–04；来源 ID 不变。

B06–B08 的数词节点明确改编为中文，不宣称完成英文读写。百数表和数字站点只提供部分口述准备；口头流畅性未评估。短时点图不能判断是否心里逐个计数，重复看会记为帮助。手写不凭笔画数量评分，屏幕手指不代表真实手指协调。连续数站点仍有练习成分，界面变化不自动成为发现式学习。

## 保存与接续

学习记录仍用原 v2 备份中的可选 `lessons`、`daily` 字段；旧记录、草稿与提示保留。主世界视角及所选短路线单独存储。数据活动可导出 CSV，无账号、云同步或模型接口。

78 条连接活动、156 个联合操作均对应源边；今日新增按本地日期与首次完成时间去重。问题原话、未提交作品、任务步骤、随机结果、教具视角及世界位置随学习备份保存。

下一次优先显示一个问题入口；“先放着”当天不再占主入口，次日可再出现；“想明白了”只结束问题。没有对应活动时保留位置，没有问题时继续未完成现场或建议下一处。恢复旧问题时，较新的草稿另存为恢复历史，不丢弃提示与尝试；当天继续中的刷新保留新操作。
