# 数学树 · 关系、学习入口与反馈用词审查（2026-11-02）

当前分支：`feat/language-concept-audit-v1`。本轮承接 [概念文字基准](TERMS.md)、[587 节点命名台账](NODE-NAME-AUDIT.json)，不改数学来源、空间坐标、知识群归属或学习状态计算。

## 核心区分

**关系方向**回答「从哪里来、接着会用于哪里」；**强度**说明这条联系在来源图中的性质；**学习活动状态**只表示相应任务是否达到程序定义的完成条件。三者不能混成一句“必须学完”。

根据来源数据 `dist/data/math.json`，现有 **1,223 条数学前置方向边**，其中 **851 条 hard（关键基础）**、**372 条 soft（辅助联系）**。每条边的方向是 `prerequisiteId → topicId`，辅助联系不自动转成必修路线。现有 `dist/spatial-reasons.js` 提供 1,223 个与来源边键对应的中文理由，显示时还核对英文来源理由是否未变化；这些是可追溯的解释，不构成外部数学教研认证。

## 一、关系方向的用词前后对照

| 出现场景 | 原说法 | 修改后 | 为什么 |
| --- | --- | --- | --- |
| 三维节点详情 · 回看来源 | 这里会用到 | **相关基础** | 明确是从当前知识点往前看，而非“这里”的不明指代 |
| 三维节点详情 · 往后探索 | 还会连到哪里 | **相关后续** | 明确是真实来源的后续节点，而非地图上的空间邻近 |
| 备用学习地图 · 知识点详情 | 这里可能用到的基础 / 这里会在什么地方再出现 | **相关基础 / 相关后续** | 和三维地图采用相同关系方向 |
| 备用学习地图 · 汇总的群组间联系 | 这些基础可能用得上 / 继续走，还能发现什么 | **相关基础（知识群）/ 相关后续（知识群）** | 知识群的连接是多个知识点来源边的汇总，不强迫整群线性学习 |
| 关系强度提示 | 关键基础 / 辅助联系 / 辅助关联 | **关键基础 / 辅助联系** | 与源 hard/soft 对应；区分方向与强度 |
| 浏览搜索提示 | 想靠近哪个想法？ | **查找主题、知识群或知识点** | 层级称呼与前两轮已审定名称一致 |

**视觉呈现约束**：每条列表依然显示真实来源节点和对应中文理由；`相关基础` 与 `相关后续` 不替代 `关键基础` 与 `辅助联系`。前两者是方向，后两者是关系强度。原始数学边、理由全文、筛选能力、相机不变。

## 二、学习活动标题审查

已抽查 `dist/learning/catalog.js` 及主题活动模块 `phase5/b17.js`、`b22.js`、`b38.js`。现有设计将**儿童问题式活动标题**与**正式数学名称**分别存储，是合理的两层表达。例如：

| 互动标题（保留） | 正式概念（保留） | 判断 |
| --- | --- | --- |
| 分细了，会变多吗 | 等值分数 | 用矛盾问题激发比较，正式概念仍可见 |
| 同一个量，换个名字 | 十分位、百分位与小数 | 问题标题可自然化，但需保留准确的位值内容 |
| 切细一点，还是原来的量 | 等值分数的生成与约分 | 具体行动与概念目标对应 |
| 机会放在哪里 | 0到1的概率刻度 | 方便引导数轴表示概率 |
| 让别人看见你怎么想 | 展示解题过程 | 将学习活动和推理表达连接 |

本轮**不把这些问题式活动标题批量改成术语**，也不新建题目或改变活动答案。实际需要统一的是导航类型：

| 原说法 | 修订后 |
| --- | --- |
| 23 个探索包、打开探索包 | **23 个知识群、打开知识群** |
| 备用地图显示原始 `n.title` | **显示 587 个节点共用的审定展示名称**；搜索仍兼容来源原名 |
| 没有活动：“完整的动手活动还在准备” | **这个知识点暂时没有独立学习活动，可以先查看相关基础和后续知识** |

## 三、完成与反馈：只说明程序确实记录的内容

- 「**活动完成 2/3**」表示已开放活动的任务完成数，不是知识点掌握 2/3；备用地图的数量显示补上“活动”限定。
- 「**有本次独立操作证据**」只在相应任务实际记录到独立、有效的操作时呈现，不等价于普遍性理解。
- `dist/learning/thinking-feedback.js` 对少数任务返回「你刚才的办法」与实际有效操作的描述；不会把儿童的文字自动判定为数学思维掌握。该机制本轮不修改。
- 已完成的学习路线保留「问题式活动标题 + 正式概念 + 尝试与反思」，不将「看了解释」「访问知识地图」计入活动完成。
- 留下的问题由用户手动标记“想明白了”，这是用户自述的整理状态，不是 AI 数学能力认证。

## 关系理由数学准确性核对：第一批（2026-11-02）

已对全部 1,223 条来源关系执行 **ID、方向、强度、英文原理由与对应中文理由的完整性检查**；完整性核对不是逐条数学正确性审稿。第一批从条件、数量与角度等易产生错误联想的解释入手，按精确来源边修正以下 5 条中文说明，不更改来源英文理由或任何数学关系：

| 来源边（前项 → 后项） | 修订边界 | 目的 |
| --- | --- | --- |
| 小数与分数 → 扇形统计图 | 在扇形统计图中，整圆 360°，四分之一对应 25% 和 90°圆心角 | 避免将角度、比例直接混作同一种量 |
| 互补事件 → 概率模型 | 列全所有可能、互不重叠的基本结果，概率和为 1 | 补足概率模型成立的覆盖条件 |
| 哪些边长能组成三角形 → 全等三角形 | 三边与两边及非夹角的条件不同 | 不把不充分的边角条件说成全等判定 |
| 单位换算 → 由比例图求面积 | 长度按比例换算，面积按比例尺因子的平方变化 | 避免将长度缩放直接当面积缩放 |
| 0 到 1 之间的概率 → 所有结果的概率和为 1 | 事件发生与不发生的概率相加为 1 | 明确互补关系，而不是只描述概率范围 |

这 5 条是**经具体数学条件复核的文字修订**，不代表另 1,218 条已通过独立数学教研审核。后续按“有数值或公式的理由 → 带条件与例外的理由 → 其余说明”继续核对；遇到来源边本身可疑时记录问题，不偷偷改动节点依赖或自动转成必修路线。用户视觉验收与儿童理解测试仍单独待办。


## 数学条件核对：第二批（2026-11-02）

从原有 1,223 条来源边中，聚焦抽取分数、几何面积、随机概率及数学建模相关关系，对照前后知识节点的来源目标与英文关系理由。核对并修订 **8 条**展示用中文原因（第一批 5 条，本阶段累计 13 条专项修订）；原始英文理由、来源 ID、关系强度和地图坐标不变。

| 关系 | 补齐的数学条件 | 儿童应避免的误解 |
| --- | --- | --- |
| 理解分数 → 等值分数 | 比较二分之一和四分之二须针对同一整体 | 不同整体各自的一半未必等量 |
| 哪些边长能组成三角形 → 全等三角形 | 任意两边之和大于第三边；两边和非夹角不足以唯一确定 | 不是随便三条长度就能成三角形 |
| 分数乘法 → 三角形与平行四边形面积 | 三角形面积使用对应底边的**垂直**高，再除以 2 | 不是任选一条斜边就当作高 |
| 等值分数 → 约分 | 分子、分母同时除以大于 1 的公因数，值不变 | 不是只把写法改得短就叫约分 |
| 等值分数 → 十分之几与百分之几 | 十分之三与百分之三十等值 | 细分后份数多了，不代表总量变大 |
| 用实验估计概率 → 概率模型 | 相对频率是概率估计，需用后续观察检验 | 实验频率不是天然精确概率 |
| 用乘法求长方形面积 → 乘法口诀与乘法表 | 一边加倍、另一边不变时面积加倍；两边都加倍则面积四倍 | 面积不总是随边长加倍而只加倍 |
| 角的和有什么规律 → 扇形统计图 | 360°来自不重叠、不遗漏地覆盖整圆 | 局部几块扇形的圆心角未必合为 360° |

新增 8 组按具体来源边定位的文字边界回归断言，保护上述条件免遭后续措辞改写时被遗漏。**断言只是防回退检查，并非算法自动判断数学真伪**；剩余来源理由尚未逐条通过独立教研审查。完成这一批后应再检查可见卡片中的层次、文字长度与真实儿童是否理解，仍不据此合并 Draft PR。


## 数学条件核对：第三批（2026-11-02）

针对**统计推断、比例图像、数据分散程度**再核对并修正 8 条来源边的中文理由。此前 13 条，加本批累计 **21 条专项文字修订**；统计的数学条件仍来自原始学习目标与英文来源理由，**未更改任何数学边或 hard/soft 关系**。

| 来源边 | 本批补充的适用边界 | 避免的误解 |
| --- | --- | --- |
| 一次函数图像 → 正比例与比例关系 | 正比例为 y＝kx，其中 k≠0，图像经过原点 | 不把一般的一次函数都当正比例 |
| 比例关系的图像 → 正比例与比例关系 | 正比例图像与反比例 y＝k/x（x≠0）的图像不同 | 不把反比例画成经过原点的直线 |
| 计算平均数 → 到平均数的平均距离 | 各数据与平均数之差取绝对值，再求平均 | 正负偏差相互抵消后误认为无分散 |
| 计算平均数 → 用样本进行估计 | 用随机抽取且具有一定代表性的样本均值估计总体均值 | 把样本均值当作精确总体值 |
| 一个量占另一个量的几分之几 → 用样本进行估计 | 用样本比例估计总体数量时须注意抽样前提 | 用便利样本的比例直接推断所有人 |
| 等可能的结果 → 总体、样本与公平抽样 | 每个人同机会抽中，也可能偶然抽到不具代表性的样本 | 公平抽取不保证任何一次样本准确 |
| 平均数与极差 → 四分位数与四分位距 | 四分位距＝上四分位数－下四分位数，描述中间一半数据的离散 | 不把四分位距误当数据极差 |
| 四分位数与四分位距 → 两组数据差多少 | 比较中位数差异时结合四分位距，不能只凭中心差判断图形重叠 | 中心差异不能替代实际分布比较 |

测试补充 8 组按原始来源 ID 查找关系的边界断言，连同上一批 8 组合计 **16 条专项防回退用例**。已修订理由依然由来源英文理由校验；整份 1,223 条原因的存在/来源一致性检查仍然不等于逐条数学或儿童教学验收。剩余说明按风险审查，不因追求覆盖数字而批量改写。
