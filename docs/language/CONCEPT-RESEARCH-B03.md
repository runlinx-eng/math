## 三、来源目标与教学边界

**源描述：** 通过对图形、物体和集合重复对半，连接二分之一、四分之一和八分之一，并表示图形与物体的八分之一。

**必须覆盖的三个源目标：**

1. 将纸条先对折，再把已有部分继续对折，标出 halves、quarters、eighths。
2. 用同一个披萨说明 2/8 与 1/4 是相同的量。
3. 把正方形和圆形分别平均分成8份，各涂其中1份，并说明为什么是八分之一。

**核心概念边界：**

- 二分之一：一个整体被平均分成2份，其中1份。
- 四分之一：一个整体被平均分成4份，其中1份。
- 八分之一：一个整体被平均分成8份，其中1份。
- 重复对半：1个整体 → 2个半份 → 4个四分之一 → 8个八分之一；每一步都要把已有的每一份继续平均分成2份。
- 2/8 = 1/4，前提是两者指向同一个整体；两个八分之一合起来正好是这个整体的一个四分之一。
- 正方形的八分之一和圆形的八分之一表示各自整体的同一比例；如果两个整体大小不同，涂色部分的绝对面积不一定相同。
- 等份要求面积或数量相等，不要求每一份的形状必须全等。

## 四、研究支持与设计判断

1. **从公平分享和等份开始。** IES 指南建议用单个整体和物体集合的公平分享建立早期分数概念，再延伸到分数顺序与等值关系；但 Recommendation 1 的证据评级是 minimal，故把它作为有研究依据的教学建议，而不是强因果结论。
2. **重复对半是本节点最直接的学习路径。** 澳大利亚 Year 2 标准明确把 halves、quarters、eighths 与 repeated halving 连接；NSW 教学资源也将“用重复对半创造 quarters 和 eighths”列为可观察行为。
3. **把“等份”与“形状相同”分开。** ETS 学习进阶报告中的折纸认知访谈发现，部分学生把形状全等当成等份条件。数学上真正要求的是面积或数量相等，形状可以不同。
4. **固定整体。** 研究报告指出孩子可能在分割后把剩余部分重新当成新的整体。解释 2/8 = 1/4 时，必须让两边都指向同一个披萨或纸条。
5. **同时使用连续整体和离散集合。** 折纸、披萨、正方形和圆形是连续整体；8个相同计数物可让孩子看到集合中的一半、四分之一和八分之一分别是4、2、1个。
6. **不把高阶内容塞入本节点。** 本节点不要求一般分数运算、通分、十进制转换或复杂数轴比较。
