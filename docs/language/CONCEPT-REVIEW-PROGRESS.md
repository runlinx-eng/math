## 七、批次施工规则

1. 每批 10–20 个节点；按数学概念、真实前置关系和来源类型组织，不按 ID 机械切片。
2. 先看来源 `title/name/description/evidence/assessmentPrompt/ageRange/standards`，再看真实前置与后续关系。
3. `hasResearch=false` 节点先做研究依据分流；来源不足时标记阻塞，不猜测补齐。
4. 每个节点分别记录：来源核对、内容范围、数学审查、表达质量、图示审查、儿童理解状态。
5. 批次完成后跑相关单测与浏览器回归，更新本台账和 JSON 清单，再提交 Git。
6. CI 通过只代表自动检查通过；不替代独立数学复核、人工审图或儿童理解测试。
7. 所有批次留在同一个 Draft PR；完成全量验收后统一收尾。
