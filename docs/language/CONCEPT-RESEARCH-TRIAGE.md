## 研究完成的判定规则

1. 找到可追溯的课程标准、教学研究或可靠专业来源，并记录具体支持哪一项学习目标；不能只列相邻知识点作为证据。
2. 区分来源支持的数学事实、教学策略建议和本项目拟设计的活动；不把模型生成的教学建议写成实证结论。
3. 对涉及概率、统计分布、面积体积、比例缩放、算法等高精度内容，安排独立数学复核。
4. 研究记录完成不等于儿童理解通过；真实儿童理解与迁移测试另行验收。
5. 原 `RESEARCH-GAPS.md` 中的“可先比较的已有研究 / 拟学习动作 / 验证”是研究计划，不是已核验来源或已完成研究。
