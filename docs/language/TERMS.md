# 数学树：概念与文字表达基准（第一阶段）

状态：**第一批概念层级已统一；第二批 5 主题、23 知识群界面文案已建立覆写并进入自动验收**。2026-11-02，工作分支 `feat/language-concept-audit-v1`。完整原文与建议对照见 [五主题与 23 知识群文字审查](THEME-GROUP-REVIEW.md)。

## 核心原则

**精准命名，按需解释，多种理解路径，凭行为证据判断理解。**

- 稳定名称负责指向同一数学概念；孩子看不懂时，解释可换说法、换图示、举例、对比反例或动手试，不用模糊的别名取代数学术语。
- 每条界面文字分清「这是什么」「为什么有关」「现在能做什么」「实际做到了什么」；避免一行文字同时承担四个职责。
- 数学关系必须来自来源边；文字只能解释关系，不能创造关系、强加主干或规定唯一课程路线。
- 「浏览/看过/开始/提交/完成活动/理解/掌握」是不同事实。引导步骤完成不等于学会数学，任务进度不等于知识掌握度。
- 五大主题、23 个知识群是**组织与导航分类**；不是因名称相似而新增的数学前置关系。保留 537 个领域知识点在地图中的原位置、另有 50 个数学思维节点在学习与关系内容中可访问，不强行绘制到地图。
- `main` 交互基准 [INTERACTION-RULES.md](../spatial-learning/INTERACTION-RULES.md) 继续有效；本阶段只修改文字和相关断言，不能更改节点、关系、坐标、相机、点击权限和学习完成逻辑。

## 第一层：标准概念（本轮固定）

| 层级 | 标准名称 | 含义 | 不在层级标签中混用 |
| --- | --- | --- | --- |
| 产品 | 数学探索 | 整个体验的名称 | 将「数学树」用作产品全部能力的替代词 |
| 结构 | 数学树 | 来源数学节点与真实联系形成的数学认知框架 | 把一个视觉造型当作数学上的唯一主干 |
| 界面 | 知识地图 | 空间中浏览数学树的可操作视图 | 将空间距离当作必然的学习前置 |
| 一级 | 主题 | 五个数学主题分类 | 一个方向、章节 |
| 二级 | 知识群 | 23 个导航分类组 | 一簇想法、知识簇、探索包 |
| 三级 | 知识点 | 带来源 ID 的领域数学概念/知识内容 | 一个想法 |
| 相关能力 | 数学思维 | 推理、建模等思维发展内容，单独于领域地图节点 | 用「学习中」暗示用户当前学习进度 |
| 关系 | 基础 / 后续 | 真实来源联系的方向 | 因文字简化而更改 hard/soft 的事实 |
| 学习 | 学习活动 | 用户可以操作、提交和比较的活动 | 活动完成 = 理解或掌握 |

注意：日常解释中可以自然地说「想法」，但**不可**在主题/知识群/知识点的层级标题、搜索类型和数量标签里替代标准术语。原始数学术语、来源 ID、以及重名限定语均不因界面规范而自动改写。

## 第三层：内容与解释分工（待第二轮逐项实施）

一个知识点可组织为「**正式数学名称** + **一句精准定义**」，其后按需提供：
1. 换个说法：尽量平实但保留概念边界；
2. 换一种表示：图形、数轴、表格或空间示意；
3. 举例与反例：区分成立条件、例外、易混概念；
4. 动手试试：真实可执行的观察和操作；
5. 为什么：来源关系和数学依据。

这些是**可选的理解方式**，不是要求全部堆在一张卡片。内容若尚未审稿或活动尚未实现，不应伪称解释或学习效果已经提供。

## 本阶段技术验收

1. 所有修改限于用户文字、文档、检查用例及必要的缓存版本；数学节点 ID、原始名称、1,223 条来源边、真实关系解释原文均不动。
2. 五步导览仍按原先真实节点和步骤操作；非目标知识可悬停但不能在导览中越级点击；全貌与归位行为不变。
3. 旧的知识分组搜索及学习入口不因名称修改失效；动态进度数字仍由实际数据计算。
4. 自动化检查通过只代表技术回归。真实儿童的语言理解、学习效果需要独立验收。
