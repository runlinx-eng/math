## 2.1 前台／后台能力分层与唯一下一步（新增产品决策）

**能力完整不等于入口全部显露。** 本清单的每一行新增 `uiRole`、`showWhen` 和 `accessGuarantee` 三列；生成器按真实能力类别进行分层，测试确保没有无归类条目。此分类是**交互去向设计**，不是已实现的前台行为或删除授权。

| 层级 | 具体能力 | 何时可见 | 保留条件 |
| --- | --- | --- | --- |
| **当前操作** | 当前题面、数学教具、实际操作、检查、错误修正和唯一后续动作 | 当前任务激活，其他任务不同时铺在页面上 | 每个题型原判题、独立专属教具、提交历史与刷新恢复保持不变 |
| **按需辅助** | 合适时机的提示、数学解释、源关系、联合任务、短路线、拓展、个人发现、恢复入口 | 学习阶段/触发事件或孩子主动展开，绝不与当前主操作争抢焦点 | 有明确可发现的次级入口，不能把所有东西塞进“更多”后宣称已覆盖 |
| **后台能力** | 判题及状态机、来源与思维证据、自动保存、旧模型数据、离线缓存、备份、兼容与冲突校验 | 不占当前题面；只在保存成功、异常或明确进入记录工具时呈现相应可理解状态 | 后台仍要有真实的审计与恢复路径，导出/导入在记录工具中可达 |
| **待归类保留** | `PRACTICE/models[-1]`、三类旧工作面活动、早期路线、实验室、旧测验 | 不增加成儿童前台常驻入口；**既有可访问路径仍保留** | 如旧自由操作原入口已不可达，应明确记为风险/待修复，不冒充完成归并 |

**下一步合同（学习运行器界面）**：按当前作品派生状态，在当前任务视觉层级只能有**一个突出的下一步**，且按钮对应真实有效动作：

| 当前状态 | 当前突出行动 | 可以存在但不争抢主操作的入口 |
| --- | --- | --- |
| 初次进入／自由操作 | **先动手操作**（无需额外模式切换；实际作品形成后突出「检查我的作品」） | 必要工具、可请求提示 |
| 检查未通过 | **按具体反馈修改作品**，随后「重新检查」；无需先点击“重试模式” | 查看本次错误依据、保留的历史记录 |
| 已修改、尚未复检 | **重新检查**；旧通过状态不代表已改作品 | 原尝试依据 |
| 检查通过且仍有本组下一题 | **下一题** | 这次已核验的数学说明（不抢答自由解释） |
| 最后一题通过 | **整理自己的发现**（文字可选，允许直接继续） | 主动打开系统解释、回看操作 |
| 总结有未提交文字 | **保存我的发现**；明确保存结果，之后恢复真实继续入口 | 可选跳过；草稿不中断、不丢失 |
| 总结无未提交文字 | **继续探索：一个真实存在的关联任务**；若无则**返回知识空间** | 查看其他关系、拓展、历史；明确关闭始终可达但不重复突出 |

- **不是一个“下一步”按钮永远不变**，而是每种可验证状态仅有一个当下主意图。观察、猜想、拖动、构造、反例、解释在专属教具内部自然进行，不为 UI 统一再强制增加模式或中转页面。
- 教师式完整系统结论不能先于孩子被要求回答的自主解释，尤其总结页 `lesson.summary` 应在孩子表达之后或主动展开时出现。数学事实保留；系统说明、可验证作品与未经核查自由文字分别标识。
- 3D 视图「探索／学习／足迹」承担顶级入口；当前知识「打开学习」是单一学习入口；来源关系及拓展是条件性能力，不建立第二张图。重复的返回按钮、同时突出保存／返回／重试必须通过实际视口验收处理。
- **后台不等于不可访问**：导出、导入、历史证据等应从「足迹／记录工具」清晰可查；重要错误/保存失败主动浮现，不得无提示丢数据。待归类条目要有单独的访问风险清单，不靠隐藏为“精简”。
- **验收**：CSV 每行都有分层和触发规则；每类代表任务在不同阶段抓取主操作数与实际到达目标；确认“一个主行动”与“辅助可达”同时成立。PR #49 的完成页改动需优先以真实 DOM/Chromium 验收；本 PR #50 不替其改运行时。

## 3. 五类状态及暂不处理原则

1. **已完整接入**：仅在来源、运行器、入口及保存/恢复测试都逐项通过后才允许定为「完整」。CSV 当前的「1 · 源码技术链路已接入」不等价于儿童/浏览器验收完成。
2. **已接入但交互不合理**：如完成后的下一操作在视口外、历史信息干扰思考；需要真实 DOM/视觉证据。
3. **存在但入口不清晰**：折叠的联合任务、实践入口、旧工作面的独立活动。
4. **尚未归类、暂保留**：旧 `PRACTICE`、早期路线 A、旧测验、两个英文实验室等。
5. **确认重复且具有等效替代路径**：**本次没有任何条目获准删除**。必须先核对输入、判题、历史恢复、视觉及实际操作均等效，才能列入此类。

CSV 中对未完成浏览器验收的“1”标记是**源码接入等级**，而非已验证的完整接入声明。所有行保留源路径及审计边界。
