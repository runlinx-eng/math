# 每天从哪里继续（阶段 3 建立，阶段 4 延续）

本版只给一个主要继续入口。没有问题时先找未完成现场，再建议路线里下一处；当前 50 个节点都完成后，可以继续尚未完成的连接活动。孩子随时可以转去全图里的其他位置，没有每天必须完成的数量。

## 一次学习如何接到下一次

1. 完成节点中的实际任务，点亮这个源节点；替代活动去重。
2. 在路线的“把想法连起来”或节点总结的“连起来试试”进入共同操作。两个操作均成立，才点亮对应的真实源边。淡线表示当前路线的已有关系，金线表示完成过连接活动；展开后可查看联系理由。
3. 有新疑问时点击“留到下次”。保留问题原话、所处节点、未提交的作品、任务步骤、教具视角和世界位置；不按关键词猜测答案或推荐尚不存在的课程。
4. 下次从最近一个未结束的问题继续。多个问题在“问题”中查看；“先放着”当天不再占据主要入口，次日重新出现。“想明白了”只结束这个问题，不改变节点或连接进度。
5. 回到问题时恢复留下问题的现场，并另存被替换的新草稿及操作证据。继续操作后，当天刷新会保留新操作，不再次强制恢复旧现场。

没有对应活动的问题仍保留原话与位置，明确说明活动尚未开放；回到那个位置，不生成虚假的课程或连线。直接进入其他路线也不会被问题强行拦住。

## 进度和保存

今日新增按浏览器本地日历和首次达到完成条件的时间统计。重做、刷新、跨天、重复导入均不重复点亮。全景按当前 50 个已开放的不同源节点显示整体进度；42 个连接操作不冒充新增知识点。阶段 3 当时的基线为 12 个节点、18 个连接操作。

备份格式仍为 2，新增可选 `daily`（连接活动、问题、继续入口）；旧备份缺少此字段时正常兼容。原来的新旧活动、未提交草稿、提示、错误及解释记录都保留。问题现场包含在学习备份中；一般地图浏览位置仍是独立的本机视图记录。

“完成”只代表满足固定任务条件。借助提示完成不会成为首次独立成功，问题被标为想明白也不证明解释正确或长期掌握。这里没有模型评分、家长入口或自动教学效果判定。

## 当前验证边界

阶段 3 的浏览器检查采用独立桌面上下文、真实控件和模拟日期。它验证技术上的跨天恢复，不是孩子真实隔天体验。当前技术结果见 [验证记录](../VALIDATION.md)；阶段 4 的实际试用仍需孩子至少两次使用，其中一次隔天继续。
