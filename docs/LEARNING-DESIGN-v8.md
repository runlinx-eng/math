# 数学探索：结构、活动与证据

2026-10-24，阶段 3 每日接续版 v8。当前有 12 个节点的活动，孩子试用未进行；历史设计见 `LEARNING-DESIGN-v7.md` 与 `LEARNING-DESIGN-v6.md`。

## 学习的入口

只做数学、电脑端、孩子入口。年级和年龄不控制路线。孩子先看五个主题，再进入少量分组；已有三条路线各显示四个编号节点，编号只是本地建议，允许跳转。全图 587 个节点、23 个分组、1,223 条数学关系仍可查，不把全部内容铺在眼前。

连续三维空间保留同一张画布、固定位置与来源关系。位置与距离帮助辨认，不表示年级、难度或掌握程度。地图分类、坐标和路线是本地适配，连线来自原始知识关系；相邻的编号不自动构成新先修关系。

## 动手、换条件、再命名

新活动采用“通俗问题 → 可改变的对象和反馈 → 换条件或表示 → 总结正式名称”。共享界面只打开一个操作现场。分数采用切分、百格、数轴和杯子；体积采用真正的三维填充、旋转、拆层和切分；数据采用逐条模拟观察、自己记录和图表构造。三维不是所有知识的固定表现模板。

12 个节点、30 个任务与 36 个源目标逐项对应于 [覆盖表](phase2/COVERAGE.md)。10 个节点适配原研究；2 个数据节点按 [补充依据](phase2/RESEARCH.md) 实现。模拟记录明确标注，不把软件中的模拟调查称为已完成真实调查。

操作可以展示或检验数学关系，但不能自动证明理解。构造、解释、换情境也可出现在传统课堂中；本项目的区别在空间组织、可改变的对象与可持续记录，不宣称这些教学方法为独家发明。

## 完成与证据

| 对象 | 本版含义 | 边界 |
| --- | --- | --- |
| 主界面完成／未完成 | 已开放节点的活动进度 | 只统计 12 个源节点，替代活动不重复计数 |
| 新活动完成 | 每个任务至少有一次成立的作品 | 提示后完成仍可完成，但不会成为首次独立证据 |
| 首次独立操作 | 首次提交成立、未提示或看本题反馈，最新作品仍成立 | 固定案例中的操作证据，不代表长期或整体掌握 |
| 开放解释 | 保存针对本节点的问题与孩子原话 | 不按字数、提交或机器猜测自动判定理解 |
| 浏览与自由试 | 保存当前现场 | 不增加完成或连接证据 |

新活动记录包含实际切口、选中对象、层数与体积、分类计数、尝试次序和提示。错误首次提交及后续修正合并保留；导入不会清除已用提示。总结中的正式定义帮助命名先前操作，不拿读过定义当作验证。

旧活动和早期 `journeys.portions` 保持历史规则：旧活动提交构造/迁移可记录完成，早期路线完成只代表短体验。因此旧完成不升级为新版独立操作证据。旧 A–03 的半杯节点现有完整活动，新路线编号 A–04；旧 ID 不变。

## 保存与接续

学习记录进入原 v2 备份的可选 `lessons`、`daily` 字段；旧记录、草稿和提示均保留。两个旧工作面及新旧窗口交替保存经过测试。主世界视角与学习记录分开存，浏览不改知识位置。数据活动可把两列记录导出 CSV；没有账号、云端同步或模型接口。

阶段 3 已接通“每天点亮、共同用两个想法、留下问题、下次继续”。已有 9 条连接活动、18 个操作，都对应真实源边；两端完成不会自动亮线，也不增加节点完成数。今日新增按本地日期和首次完成时间去重。问题原话、未提交作品、步骤、教具视角及世界位置随备份保存。

下一次优先显示一个问题入口，“先放着”当天不再占主入口，问题仍在列表、次日会再出现；“想明白了”只结束问题。没有对应活动就如实保留位置，没有问题则继续未完成现场或建议下一处。恢复旧问题时，后来产生的草稿另存为恢复历史，不丢弃提示和尝试；同日继续中的刷新保留新操作。具体规则见 [每日接续](phase3/DAILY-FLOW.md)，源边和操作对应见 [连接清单](phase3/CONNECTIONS.md)。

## 接下来的实际验证
