## A 复用边界与优先级

正式已有 71 个审阅家族的 `binding(task,{sessionId,index})`、独立 `replay`、原题 taskHash、失败/改正/重试历史、原生来源排他及桥接负例，可作为**设计参考**。13 个仍有非 A 的控件类型也有已审 A 位置：`x-pvbench`(26 待审)、`x-placecalc`(13)、`x-a30-grid`(12)、`x-r37-steps`(10)、`x-a30-solid`(7)、`x-a30-pieces`(4)、`x-wideshift`(4)、`x-orderlab`(3)、`x-a30-circle`(2)、`x-r37-share`(2)、`x-multable`(1)、`x-t32-order`(1)、`x-unitwalk`(1)。数字只是**同控件剩余筛查题量**，不代表可直接批量升级；尤其 `x-r37-steps` 具有多种不变量。

推荐先审 `thousandstep:0..3`、`tensmove:0..2`+`hundredsmove:0..2`，再审 `triArea:0..3`。前两组复用现有回放方式但必须核新的十/百/千单位与跨位结果；后者数学风险高，需对垂直高与剪拼重叠做原子几何审核。工具选择、自由论证、真实调查/概率理解等暂列人工或新合同优先，不强求严格自动 A。

每个未来开发 PR 独立冻结全部源 ID、原 taskHash 和原事件窗口；列出可验证不变量、原题支持的真实动作、失败纠正和隐藏数据/桥接反例；保持旧判题与原 v2 数据；真实 Chromium 仅跑定向家族/P10 有关项并核必要原件、PR 当前 SHA CI、merge 后 main Required/Fallback。工具显示的数值、系统生成的辅助图、正确最终答案都不是儿童独立证明。
