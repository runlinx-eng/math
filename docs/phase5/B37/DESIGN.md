# B37 设计：放大、缩小与比例

“放大、缩小与比例”先提供三个方向：一百份里的多少、配在一起分给各人、一起变化与缩放。七条新路线各有三个节点；原 I 路线仍可进入。路线与空间位置是本地组织，38 个联合活动逐一对应上游已有有向关系。

百分数先在百格中涂出同一部分，再换成分数、小数或实际数量；计算时区分折扣、折后价和增长后的总量。配比活动先摆两种量、留下判断，再比较同时乘倍数和各加相同数量；同类物品使用同一尺度，不同单位各自比较前后。按比分配要把等大的块实际分给不同的人。

放大活动把原图与新图画在同一尺度：孩子选择倍数，记录两条对应边，再比较面积；九块图示是系统提供的支架。问题较多时，先完成眼前操作，再出现后续记录，避免一次铺开所有输入框。地图、利息与单位换算目前以可追踪的分步记录为主，尚不是开放探索。反比例的曲线由系统按规则绘出，不把它当成孩子独立作图。

首次错误、操作反馈与帮助、问题原话、未完成作品、空间视角及后来的草稿继续保留。图中数值或分配被修改后，旧记录仍保存在历史里；对当前作品的判断需要重新核对。结构化操作和有限题目不自动评判自由解释、一般证明、真实测量或长期掌握。

孩子尚未试用；能否自己开始、界面是否有趣，以及真实隔天能否从问题继续，仍需实际观察。见[依据](RESEARCH.md)与[逐目标覆盖](COVERAGE.md)。
