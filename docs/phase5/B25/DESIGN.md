# B25 设计

“转弯与角”先给三个方向：“先转一转，看开口／把线和角连起来／拼图形，试条件”。EU–FB共8条路线，每条3个节点；每次最多出现3条路线。24个源节点有82个有限任务；19条连接均对应真实源依赖，每条连接包含两步相关操作。空间分组与路线编号是本地导航，不能冒充新的源关系。

孩子可以移动箭头、转动射线、改变边长、将不同角叠到直角上比较，先估计再检查，把量角器中心和基线移动到角上，给边画刻痕，拼合三角形三个角，连接多边形对角线，移动一组交角，以及通过圆和射线的交点构造三角形。先体验开口和变化，再在总结中给出名称；必要的数字和符号保留在操作现场。

量角器通过按钮移动，屏幕构图根据实际坐标计算；体感转向、实体尺规、自由画图与开放论证不在自动评价范围。题目中的固定候选、直角参照、自动生成的射线和提示都是脚手架；完成有限操作不等于全面掌握。首次估计、错误、帮助、未完成作品、问题原话、视角和后续草稿按已有机制保存。

24个源节点的72个目标逐一记录有限对应与空缺，见 [覆盖表](COVERAGE.md)。孩子尚未试用，不能据此判断上手、兴趣、独立理解或真实隔天续学。
