# B09 · 从数轴走向负数与数的范围

9 个源节点、4 条短路线 AN–AQ、44 个节点任务；6 条真实源边各有两个联合任务。累计127节点、407节点任务、43路线、62连接。数的分组继续采用三个方向、每组至多三条路线、选中后只呈现2–3节点；导航顺序不创造先修边。

## 学习动作

- 数轴上的计算：先放起点、保留猜想，再自己选择方向和跳跃长度。箭头按比例绘制，长度表示变化，终点表示结果。明确要求先20再7的任务检查指定操作；允许自己分两跳时接受不同正确拆法，例如47先加3再加13。
- 工具选择：数轴和百数表都能处理两位数加减，需要实际移动；双色小珠呈现两小堆。模拟丝带和门需要量尺对零、连续拼接、记录正确单位。长门限定两段，引出换长尺的用途，并未声称短尺永远量不了。
- 零的另一边：每站自己输入，倒数经过0到负数；把温度和楼层放在等距数轴。跨零计算要把到0和剩余变化分别画出。减负数先从0表示括号里的变化，再反向撤销，避免只背符号口诀。
- 位置与距离：主动定位正负数和小数，再描回0的路程。−8小于−3，但欠8元的量大于欠3元；数序和距离分别判断。
- 可选范围：移动边界，选方向和是否包含端点，再自己写出符号。连续长度允许小数；画半直线或两端区间后，实际代入边界、里面和外面；允许自选正确的整数、小数或分数，不要求恰好选示例数。两步不等式把两边同时减、同时除以正数，改变后的数量实时显示。
- 相同边长：铺正方形、逐层搭真实可旋转的正方体；49块与64块反过来找边长。相同因子逐个加入乘式。更高次幂用连续相乘的结果链，并对照3+2²的运算次序。
- 精确位置：不断缩小夹住√2的一段。两端平方通过精确分数比较，三位小数1.414必须有能支持该近似的范围；它与√2用近似关系连接。
- 两点之间：3/4、1/3、1/6逐轮记录商和余数，观察结束或重复。数卡比较√9、√2、π与有限1.414；分类依据不能只看根号或显示位数。两段不同区间中亲自插点、选择一边、重复放大；取中点的一般理由和有限屏幕演示分开说明。

## 记录与实现

11种模型共用原有任务、问题、备份和完成系统。新增六个本地资源，没有新依赖或服务。立方体适配既有CubeView，保留实际块身份、分层与相机；可用画面点击或逐层按钮操作。改变边长会清空当前搭建，旧猜想保留。
