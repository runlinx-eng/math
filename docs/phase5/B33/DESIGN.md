# B33 设计

“钱与选择”入口分成“看面值，摆一笔钱”“付出去，找回来”“估一估，做选择”三个方向，GK–GP 共六条短路线，每页最多三条。20 条联合活动逐条对应上游有向边；路线本身不制造先修关系。

孩子可以直接点钱放到桌面，点桌面上的钱拿回一枚，记下多种组合并看见每一种由哪些面值组成。英国、澳大利亚和美国示例明确标记币种，澳大利亚50c与$2以示意大小、颜色和形状区分；画面不伪装真实票币。第一次摆错或分类错会保留，等值组合允许多种真实可行解。金额以整数便士或美分保存；公式的十进制运算以有理数计算，结果按分四舍五入，不用浮点误差判错。

预算的五种物品全部买入会超过$60，孩子可调整出不同的可行组合，实时看到合计及余下金额。单价先预测，再换成相同重量比较。估计和精确值分开记录：$36接近约$35但不等于精确找零$34.95。现金取整、10% GST仅用于题目明确给出的澳大利亚情境；已含税金额不重复加同一税额。

小表格要求实际输入引用单元格的公式，计算使用安全限制的四则运算、括号和百分号；公式改动后必须重新计算，不能拿旧结果提交。它使用固定示例，尚不是完整电子表格。预算篮和后面的固定表格例子并不联动。条形、数轴、算式可以为同一测量故事切换；点图复用已有的模拟测量操作。
