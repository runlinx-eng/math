# B39 设计：选方法、读图与检查

HU–HW 三条短路线并入“先计划，再检查”，原路线和三方向入口保留；每页最多显示三条路线。路线分组是本地导航，不新增源依赖。

百数表中先预测再按固定步长移动，比较从偶数与奇数出发各加2，以及加1经过行末。移动横向标尺读取一条曲线、标出两个与横轴或另一条线相交的位置，再读模拟路程时间图。曲线、方格和路程图是系统画的；交点按明确容差判断为近似值，不把它当作精确解。

算法选择接受心算、写下步骤和计算器等选项；只有选计算器时要求在屏幕内实际输入相应算式。专门的计算器任务先留下估计，再输入和核对，出错记录保留。会选一个方法和会算出结果，并不能证明孩子实际做了选中的心算或纸笔过程。开放原话只保存不判懂。真实生活测量、无支架图表、独立规划和持续理解均需其他证据。
