| 来源主题 | 本地操作与边界 |
| --- | --- |
| 同分母加减、越过1 | 两个同尺度原量分别涂出，接起或拿走；记录整份与零头。分母所指的小份大小不变 |
| 分数分解 | 小份间实际分组，每组对应一个加数；保存不同分组，交换顺序不算新拆法 |
| 带分数加减 | 一个整体换成d个小份，或反向合整；可以先全部换小份再算，不把另一有效方法判错 |
| 相关及不同分母 | 自选共同单位，图实际重新细分；数值等价、有效更大共同倍数与最简形式分开检查 |
| 分数乘整数 | 一次接完整的3/8或7/3，连续走指定次数；不是只数最后有多少个单位分数 |
| 分数乘分数与面积 | 横向和纵向选择，重合格数与每格面积共同决定量；跨过1后单位正方形的边长相同 |
| 配方与估计 | 先选动作、留估计范围，再构造准确量，最后回看原范围。允许承认估计不准，原记录保留 |
| 分数与百分数作为算子 | 整体实际等分、选择小份、记录单份与取出量。百分数还需写等值小数；超过100%时保留两份相同的整体 |
| 连续变化 | 虚构45元练习：减原价20%得36，再按36增10%得39.6，取一半得19.8；每轮的整个明确变化，显示常见金额小数，不把折扣量当成折后总量 |
| 除以10/100 | 复用固定小数点、数字右移和位值筹码；37÷10、4÷100分别再构造各位的量 |
| 整数除以单位分数 | 在总量里逐组装入每组的量，记录组数，乘回检查；除数越小，组数可能越多 |
| 单位分数除以整数 | 原小份继续等分，实际分配给不同人，核对公平、守恒和每人相对原整个的份额 |
| 一般分数除法 | 先构造组数与余组，再把两边同时乘同一因子，让每组量为1；不允许只翻转前面的数 |
| 自编故事 | 提供文本现场并保存。非空仅表示作品存在，语义、独立建模与表达质量不自动判定 |
