# B11 设计与验证目标

本批制作23个源节点、86个节点任务、8条短路线 AZ–BG，以及23条真实源关系的46个联合任务。累计数量由 [阶段5覆盖](../COVERAGE.md) 生成，运行检查由 [当前技术验证](../../VALIDATION.md) 记录。此处描述设计及验证要求，不提前声明测试或孩子试用通过。

## 入口与路线

仍在“合起来与拿走”提供三个方向：“摆出故事／拆开，再合上／换个顺手的算法”。B10与B11共16条路线藏在这些方向下，每页最多3条；选路线后只展开2—3个节点。上一组、再看看、返回及刷新保留选择，不增加一层复杂状态说明。编号是导航，不能冒充源图先修关系。

| 路线 | 方向 | 节点 |
| --- | --- | --- |
| AZ 搬几颗，还是搬几捆 | 拆开，再合上 | onesbridge、tensmove、decadetake |
| BA 两堆合在一起，找条近路 | 拆开，再合上 | twodigitpair、addhundred、flexhundred |
| BB 哪些位置会跟着变 | 拆开，再合上 | oneslarge、tenslarge、hundredsmove |
| BC 选个伙伴，说清理由 | 换个顺手的算法 | showwhy、fourparts |
| BD 换过两道门，再记下来 | 换个顺手的算法 | buildthousand、columnthree、flexthousand |
| BE 更多位置，同一条规则 | 换个顺手的算法 | columnfour、columnlarge、decimalsum |
| BF 让故事一步一步走完 | 摆出故事 | storymoney、storylarger、storymillion |
| BG 放大关系，检查是否靠谱 | 换个顺手的算法 | mentalbig、checkrough、checkpurpose |

五主题、23分组、587节点与1223条数学源边保持不变。23条新连接中含已有批次的起点；两个端点分别完成不等于连接完成，仍须做联合任务。

## 五种操作面

| 操作面 | 孩子做什么 | 可检查的证据 |
| --- | --- | --- |
| 数位换装台 | 先猜，选择各数末位放在哪种单位，再合并、十换一或一拆十、实际取走；书写任务还要逐列填结果 | 对齐相同单位、总量守恒、跨零拆分、剩余量及结果各位；仅填答案不能代替必要交换 |
| 自选计算路径 | 留猜想，选择每步的正负变化与落点，可以撤回改路 | 每步与前一落点衔接，总变化正确；明确要求拆分或补偿时才检查相应结构 |
| 四堆结伴 | 自选两堆合并，输入小计，再选下一对 | 每一原始部分只出现一次，没有漏项；不同正确顺序都可成立 |
| 连续故事账本 | 逐件选择增加或减少、变化量、当前量和自己使用的方法 | 事情顺序、中间量、单位与最终问题相符；错误第一次输入不抹掉 |
| 估计与倒着检查 | 先选取整间隔、写近似数与估计，再精算、逆向核对和判断候选答案 | 估计先于精算；保证范围与精确相等分开；反方向运算真正对应原来的数 |

操作先于正式名称。屏幕单位筹码以列标题说明价值，不把相同大小的图块当作实际等体积物品。小数内部按整数百分之一计算；3.4与2.78的原始标签长度不同，仍须让十分位对齐十分位。

元认知节点保留“为什么”的总结入口，解释只保存不自动判懂。完整纸笔竖式、长期流利、真实心算以及完全自主的多步问题规划均未由这些控件自动评估，具体限制见 [依据与边界](RESEARCH.md)。

## 数学与保存检查

全部86个节点任务及46个联合任务需通过实际浏览器控件执行，并核对空白不完成、完成后刷新仍成立、页面没有横向溢出及实际保存模型可读。数学检查应包含：

- 跨十与不跨十、跨百与整百不跨千的对照；连续零拆分和多个加数进2。
- 拆换不凭空增减，不能在数量不够时取出负数；过度拆分的保护不应损坏存档。
- 小数原标签不等长时正确对齐；整数百分之一避免浮点误差。
- 标为书写的任务逐列填结果，不能漏掉零占位和要求保留的小数末尾零；输入时焦点保持。
- 正确的替代路径、加法两种逆向检查和不同分组顺序不应被误判。
- 最初猜想在对齐错误后仍保留；局部错误反馈记为支持，之后改对不能升级为首次无帮助证据。
- 错误故事步骤不推进；错误估计不开放后续精算，同时保留最初记录。
- 取整的保证范围包含真实和、差，但范围内的错误候选不能被称为精确正确。

三方向、路线分页、旧路线保留、返回与刷新需要实际检查。以52−4拆出十个一但尚未取走为中途现场，保存问题原话；模拟次日返回应恢复原现场、第一次猜想与世界视角，并保留后来另做的草稿。实际导出再重复导入不应丢错答、提示或重复问题；新模块缓存后需能离线继续。回归已有空间与每日接续流程。

技术检查采用独立测试记录。模拟次日与自动控件检查不代表孩子真实使用过；孩子两次试用及其中一次真实隔天继续仍待进行。
