# B21 设计

summarize包的DP–DV七条双节点路线进入三个方向：找一个代表值（2条）、把两组放在一起看（3条）、从一部分推到整体（2条）。只给完成/未完成；编号与位置只用于导航。14节点43任务；40条真实源关系各有两步联合活动，完成两端并不自动完成连接。

行动先于名称：移高补低、逐卡排队、逐条量到共同位置的距离、同尺比较与换形状、由原人数搭比例图、修改图的起点、逐次抽名单、逐份放大样本。正式名称在节点总结；必要单位、图例和明示的四分位方法保留。原数据、假设和适用范围可查看。

均分移动守恒；0分新增的是一份记录。距离0计入份数；MAD保留单位。四分位采用排序后两半中位数、奇数时排除整体中位数。两组同尺，长尾空白不折断。摘要接受匹配数值且说明侧重点的均值/MAD或中位数/IQR；长尾的指定任务检验稳健摘要。开放文字只保存，不判理解。

抽样模拟使用固定初始种子推进的Fisher–Yates抽取；每轮不重复编号，下轮重新从完整总体开始。社团对照明确标人为模型。不重抽出满意结果，不把一次随机样本当必定代表。较大样本演示保存两组全部结果并读实际范围；这不是置信区间或绝对误差界。均值点和个体点用相同单位和范围，但代表不同对象。

状态需可重放；原预测、错误、帮助、修改、未录完的本次样本、下一次抽样种子、问题原话和摄像机位置均保存。导入不覆盖后来草稿；离线资源完整。独立浏览器核查所有活动、三个入口七条路线、较矮桌面、模拟隔天续接、备份合并与离线。技术完成不等于孩子学会，真实试用仍未发生。

实际容量探测发现当前全节点/连接模拟完成记录超出浏览器原始JSON额度。新增storage.js，超过200万字符时尝试无损LZW16压缩并校验；小JSON保持原样。读取兼容两种格式，错误或额度不足时不覆盖原记录。恢复、下载仍用普通JSON，导入前快照也使用同一保存适配。备份上限50MB，覆盖当前约32MB的格式化全量下载；不代表可无限累积。
