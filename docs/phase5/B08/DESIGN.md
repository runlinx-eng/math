# B08 · 大数、小数与近似值

24 个源节点，9 条路线 AE–AM，80 个节点任务；14 条真实源边各有两个联合任务。仍使用三个方向、每组至多三条路线、每条2–3个节点的空间入口。导航顺序不是新增先修边，原587节点与1223条源边均保留。

## 学习动作

- 带单位的筹码：亲自构造四至七位数和千分位小数，写各部分的值；两数逐行构造后对齐比较。相同大小的筹码依标签计值，不暗示实物体积比例。中文按万分组，英文读写目标不冒充完成。
- 移动与换组：保留首次预测，实际添取1000，遇到十个千或没有可取的千，亲自合万或拆万。数位移动采用固定小数点，正向乘10、反向除10；记录整个移动序列。科学记数法要自己把第一部分移动到1至10之间，再填补偿指数。
- 比较与排序：排卡、对齐、指出首个不同位、在数轴估位；负深度按数值顺序，不能按绝对值排序。估位容差与精确排序分开验证。
- 取近似值：自己填相邻两站、放置原数，再写最近的一站。多操作数一次显示一个工作区，各自取近似值后再估和或积。有效数字先点出要保留的位置，再作一次接近判断；保留13.0、2.90、0.0050的精度信息。
- 区间：自己决定两端，实际测试边界后选择是否包括。下端包括、上端不包括只适用于本批非负数半入约定。自由解释保存待评，界面没有假装自动证明理解。
- 罗马数字：符号拼装、可读小段切分、逐段加值；XX的两个X都值10，没有十进制位值，也无单独零符号。规范IV与钟面IIII传统分开说明。

五种新模型共用既有记录、问题续接、备份和进度系统，不引入外部服务。计算用百万分之一整数单位，避免12.95等中点的浮点漂移。当前数字范围与精度有明确上限；不是任意精度计算器。
