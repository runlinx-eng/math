# B10 设计与验证目标

22个源节点、65个节点任务、8条短路线AR–AY、16条真实源关系的32个联合任务。只有完成联合操作才点亮连接。五主题、23分组、587节点、1223条源边和坐标保持原样。

入口在“合起来与拿走”先提供“摆出故事 / 拆开与凑十 / 换个顺手的算法”三个方向，再显示最多3条路线，最后2—3个节点；路线可跳着选。原有“同一个数”的三个方向保持自己的分组范围。

## 学习对象

| 操作面 | 孩子做什么 | 检查什么 |
| --- | --- | --- |
| 两堆与故事 | 自己摆数量，选合并、取走或配对，写等式 | 原量、变化和结果对应；未知位置可以在开头或变化处 |
| 固定一堆分两份 | 逐颗换边，保存不同配对 | 整体守恒、零、交换左右不重复计数 |
| 经过十 | 实际搬圆片，留下十的一站，再继续 | 同一颗没有重复；两段确实拆出原变化量 |
| 三个数的一家 | 两种合并、两种取走，各写一句话 | 同一整体与部分，减法顺序不能乱换 |
| 接着走 | 选起点，逐站输入，纠错可退一步 | 起点不算一步；从较大数继续加 |
| 三堆先合两堆 | 自选两堆合并，带上第三堆，保存两种路径 | 配对不同，第三堆没丢没重复；便利配对之外的正确算法仍可保存 |
| 一与十 | 摆增加的单位，合并并实际十换一 | 35+5与35+50区分；交换守恒 |
| 少量回忆 | 不计时输入，必要时看圆片 | 有限答案，第一错答、帮助和纠正；不评分速度 |

每个节点至少有真实构造或变换，不以单独选择题代替操作。自由解释在总结保存但未自动判定；正式名称在总结出现。手指只是屏幕示意，点图是离散点的构造，不冒充实物与自由纸笔表现。

## 必须通过的技术检查

全部65+32任务使用浏览器真实控件执行，空白不能完成，完成与刷新一致。数学边界包括反向等号、相同配对不重记、原量未知、零、十的中间站、事实族、计数差一步、减法反例及单位交换。

三方向与8路线在3D中打开，返回和刷新保留位置。做到一半的问题保存、模拟跨日恢复、后续草稿保留、实际下载与重复导入、离线继续均需检查。回归已有三维操作、音频、随机数据与老路线。自动检查不替代孩子实际体验；孩子尚未试用。
