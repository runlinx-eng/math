# B06 实际制作边界

23 个不同源节点；76 个节点任务；8 条小路线；10 条原始关系各 2 个联合任务。具体清单由 [build_phase5_coverage.mjs](../../../scripts/build_phase5_coverage.mjs) 校验生成。

入口在原 `number-sense` 分组中分成三个选择，每次最多再展示三条路线，然后展示两三个想法。整个过程保持同一 3D 空间；不增设课程层级，不改动原图、坐标、先修关系，也不把路线相邻当成知识先修。

| 入口 | 路线 | 主要动作 |
| --- | --- | --- |
| 先把数量看清楚 | P、Q、R | 标记、配对、重排、短时观察、拆分与分组 |
| 沿着数字往前走 | S、T、U | 改变起点与步长、顺逆行、跨数位边界 |
| 让数字和数量对上 | V、W | 听数、位值构造、中文标签、比较与排序 |

基础内容可以跳过；没有按年龄加锁。每次保留一个任务面板和少量操作，不把整批 23 个节点同时摆成导航选项。全图仍可展开全部源节点，未制作节点不假装已经能学习。

各活动保留最初错误、帮助、修正和未完成模型。点开不算完成，两个端点完成也不自动点亮连接，必须完成联合操作。未完成的数轴站点、分组、听读状态、手写笔迹可随问题保存和续接。显示只有“完成／未完成”；这些状态表示活动完成，不是能力认证。

为源目标保留四类区别：有限实例的结构化核对、可选但未评分的解释、真实世界动作待验证、语言本地化改编。所有边界在覆盖表逐项列明，不用一个“已覆盖”替代。

阶段 4 的 50 个节点及 21 条连接作为历史基线冻结；当前累计 73 节点、31 条连接单列于阶段 5。用户尚未安排孩子试用，实际自主起步与隔天继续的效果均未验证。
