# B31 设计

“装得下多少”分成“换容器，量一量”和“一层一层填空间”两个方向。GB、GC 是新增短路线，旧 B、E 仍可进入；同一方向最多三条。12 条新增联合活动逐条对应上游有向边；路线是导航，不因为排在一起就产生新的先修关系。

孩子先预测，再把两份水倒入相同杯子比较。左边示意容器具有相同深度，因此图中的水面面积和所代表的水量成比例；高窄容器并不一定装得更多。另用同样满的量杯反复倒入，可换大杯、小杯并保存各自杯数，也可重新倒。半满、四分之一满以同一容器容量为整体。质量通过同一中间物分别放上模拟天平比较，再按结果排序。估计先于量杯或质量秤的数值显示，读数需先分清标数间的间隔。

分数边长立方体在真实三维视图中逐块放置、旋转和分层；填满后依次记录层数、小块大小，再比较小块总体积与三边相乘，保留刚才记下的数量。边长 1/2 的小块占 1/8 立方单位。每次换成不同形状的任务时重新取景，回到同一个未完成现场时恢复原视角。混合分数沙盒示例是可旋转计算模型，不呈现所有细分块。长度、面积和体积单位分开。
