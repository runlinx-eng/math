# B29 设计

原有“用单位比较”的三个方向保留。新增 FT“把长度故事摆出来”和 FU“分给每份，走过零”，均是两节点短路线；单次列表仍最多三条。路线编号只是导航，15 条联合活动逐条对应上游有向关系。

孩子拖动分界，在同一长度条中标出已知与未知；换问法时未知位置改变，算式接受等价的加减关系。两段质量并排共用同一尺度，相加时按实际长度接起来；面粉按克逐份分配，总量守恒，允许多次分配和撤销。模拟时钟按真实 60 分钟进位，跨零间隔可按孩子自选的正整数步长移动，也接受一步到位。先行动，再在总结看到正式名称。

分界没确认、漏放一段、不公平分份、只走到零、单位不符均不能提交为成立作品；调整已确认的分界会使旧结果失效。保留首次错误、帮助、未完成作品、原问题及后来的草稿。开放文字只保存，不自动判懂。所有物品和工具都是模拟，固定样例、辅助显示、自动评分无法证明孩子能自行画图、实体测量、解释或全面掌握。
