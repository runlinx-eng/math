# B15：成组与平均分·批3

19节点、73节点任务、BY—CE七条短路线、32条真实源关系的64个联合任务。继续使用“成组与平均分”的三个方向，每页最多三路线，每条展开2—3节点。原世界587节点、1223条数学关系及空间坐标保留；制作顺序、路线编号和距离不变成先修边。

| 路线 | 核心动作 |
| --- | --- |
| BY 把关系抱成一块 | 图形摆正与倾斜、拆3份(n+5)、同一整体换表示、亲自写括号结构 |
| BZ 顺着算，再倒着走 | 算式分支逐块合并、区分同级顺序、幂与负号、按反序撤回操作 |
| CA 方向与顺手的算法 | 延续有向乘积、四种除法方向、自选面积切块、连续加倍和补偿 |
| CB 用更小的单位乘和分 | 小数化为小单位逐列算，实际换十与换回；分到余数后换更小单位并补0 |
| CC 大概、精确与实际用途 | 自主先估、输入实际计算器算式、检查数量级、读回整辆车或可细分长度 |
| CD 让故事里的数量看得见 | 对比几倍与多几，列全搭配，构建等组/等分/面积，接两步并标中间量 |
| CE 几倍与几个步骤 | 找结果、参照量或倍数，自选三步计划，拒绝同值但错误的故事关系 |

新12类模型位于b15-model/view，复用B13阵列分组、B14面积与按位乘法、B08位移。表达式使用有界语法解析，不调用eval；先后关系由语法树确定，数值与构造同时核对。互不依赖的分支可以换先后。写表达式的任务不要求先算数；后续修改输入不能提交旧构造。

小数乘法把已有整数列记录解释为十分之一或百分之一，再由孩子换回原单位；它不自动验证独立手写的排版。小数除法点的位置由原数确定，孩子输入余数换小后的量，再带下一位。原数末尾有余数时必须亲自补0；每步余数小于除数，最后乘回核对。

比较条使用同一固定比例，改变份长和份数会立即改变条带，必须提交与当前输入一致的构造。搭配表逐对留下唯一组合。故事卡保留来源量身份，每个量用一次；中间意义来自给定标签，开放解释另存，不冒充独立命名。

错误选择、原估计、动作历史、求助、修改都保留。刷新、原问题、模拟次日恢复、被替换的后续作品、实际备份与离线仍走统一机制。不能只浏览、只答最后数字或只完成两端就点亮连接。
