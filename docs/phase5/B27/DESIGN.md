# B27 设计

“从平面到立体”分为“转动与辨认”“拼搭与折合”“移动切面”三个方向，每次最多三条短路线。原 F 路线与记录保留；新增 FD–FH 五条路线。编号、分组和空间距离只是导航，九条新增连接均核对为源依赖。

活动使用本地 Three.js 立体：旋转并分类平面和立体，在立体上点亮一个平面，按序叠放立体，以及从平面画和两类展开图猜立体。三棱柱固定五个位置的纸片沿共同边折合，可停在中间并继续；转动与按钮均可操作。截面先预测，再通过滑块移动实际切面并观察相应三角形、方形、圆形或六边形，最后留下发现。圆锥的竖向切面固定通过尖顶及底面中心。

第一次错误和纠正、帮助、未完成模型、切面／折叠位置、观察视角及问题原话沿用既有本地记录机制。生活物体只是近似模型，平面分类、预设搭建、截面和开放解释均有边界；完成活动不等于掌握。孩子尚未试用，上手和兴趣未验证。
