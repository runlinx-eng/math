# B38 教学依据与适配边界

来源为固定版本 `a8719737ff86ef7940ba5feca11940de1204103e`：20 个节点均有上游教学研究。原始目标、活动建议和每一条关联保留在 [source-review.json](source-review.json)；它们是设计建议，不是经孩子实测的课程。没有按原记录的年龄或年级限制进入。

本次另核对的公开依据：

- [数学实践：构造论证与检验他人推理](https://corestandards.org/wp-content/uploads/2023/09/Math_Standards1.pdf) 将推理链和反例列为数学实践；它是目标描述，不是本软件效果试验。
- [EEF：用教具和表示发展理解](https://educationendowmentfoundation.org.uk/early-years/maths/use-manipulatives-and-representations-to-develop-understanding/) 建议明确教具和数学关系的对应，并支持孩子表达、讨论与使用自己的表示；它涉及有人支持的教学场景，不能直接证明本地交互的效果。
- [EEF：用例题支持数学问题解决](https://educationendowmentfoundation.org.uk/news/eef-blog-using-worked-examples-to-support-mathematical-problem-solving) 讨论分析例子、不同策略与表达理由；不证明固定卡片即可评估独立论证。

本地设计：先摆数量或改变条件，再对照他人的说法；从例子和反例转向正式名称。可自行输入数寻找反例，或操作原有纸带、立方块、圆片与图形。题目和推理卡为有限支架；开放解释原话单独保存，系统不评对错。真人交流、自由绘图、现实工具选择与自主规划不能由这些操作推出。

源目标中 `6×8` 的一个表述将结论提前当作前提；这里使用 `6×10=60` 与 `6×2=12` 推出 `6×8=60−12=48`，避免循环。乘数实验限定原数大于0、乘数为0至3：乘1可推翻“总变大”，但不能推翻“总不变小”；乘1/2或0可推翻两者。一个反例推翻普遍断言，多个符合的例子不构成一般证明。
