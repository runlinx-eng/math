# B38 设计：把想法说清楚

“把想法说清楚”先提供三个方向：把理由讲明白、把生活变成数学、先计划再检查。新增 HN–HT 七条短路线，旧 O 路线保留；每页最多三条，每条2–4个节点。路线和空间位置是本地导航，不生成新的先修关系。

第一条路线从摆出加减过程出发，拆开一捆十、指出错误，再自己在十列中拿走两列，连接乘法理由。三角形题按已知角与内角和排列理由；分数除法先分装再检查错误。反例实验可自己选择原数与乘数、先预测再看到同尺度的两条带；“总会变大”和“总不会变小”分别检验。两个前提在数学上可以互换顺序时接受两种顺序。首次猜测、修改和支持记录保留。

其他路线适配已有图形、时间、单位、购物、比例与多步模型。13 条联合活动仅对应原始有向边。每个目标对应的任务与限制见 [累计覆盖](../COVERAGE.md)。

限制：一些沟通、规划和复杂建模仍以给定卡片、固定示例或分步填写为主，旧教具在不同节点会重复出现；这些操作不能判定自由论证、独立选工具、自由绘制比例图或真实生活建模。解释可保存，不自动判断；模拟“同伴”不是真人与对话。完成指完成活动，不代表掌握。尚未进行孩子试用。
