# B13 设计与验证目标

新增24个源节点、90个节点任务、8条三节点路线、26条真实源连接的52个联合任务。来源、两份缺口简报和限制见[RESEARCH.md](RESEARCH.md)，逐目标范围见[累计覆盖](../COVERAGE.md)。

## 入口

“成组与平均分”先给三个方向：一堆分成几份、排成行看乘除、换个办法算。每次最多三条路线，第四条放在“再看看”；选定才展开三个编号节点。BI—BP是本地导航顺序，不是新先修边。保留全景、实际源关系、整体进度以及完成/未完成两个孩子状态；不新增家长页、年级限制、移动布局或指南层。

先给“把这堆分公平”“转一下数量会变吗”等具体问题，操作后再给等分、包含、交换律、分配律和因数对等名称。输入留在稳定区域，调整图不打断正在输入的算式。

## 操作与可检查证据

| 操作面 | 孩子做什么 | 检查什么 |
| --- | --- | --- |
| 空盘与物品池 | 添盘、逐颗拖动或点选搬动、批量取出、轮流分配 | 固定物品守恒、各份数量、份数与每份角色、余量和对应式 |
| 阵列 | 调行列、实际提交摆法、先预测再转向、自己选切线 | 同一批点、行列结构、两块都乘共同因子、单位和算式对应 |
| 事实重建 | 混合乘除逐个回答，卡住时看图 | 有限答案与看图记录；不计时、不声称全表熟练 |
| 长方形收藏 | 同一总量摆出不同整数长方形 | 1、平方根和所有因数对，镜像不重复 |
| 三数挑伙伴 | 自己选一对先乘，再接第三个数，可退回换法 | 每个原数恰好使用一次，中间量正确，允许有效替代顺序 |
| 除法换位置 | 交换全部与组数，比较同宽单位格 | 12÷3与3÷12不同，接受等值分数和精确小数 |

物品身份与每次动作可重放校验；伪造图形状态不能通过导入。重摆和撤销不抹掉历史。原答、第一次预测、错误提示、支持与修正随记录保存。阵列滑块改变后显示新的预览，必须重新“摆成这样”；旧摆法不能带着新尺寸通过。

因数对24、36以及全部未知位置有专门任务；不是仅复用名称。未知式还要代回原式。7×30、7×300与估算区分个数、单位量和近似含义。乘零、乘一、除以一、奇偶零边界均有实际任务。源全部目标中未实现的口述、实物、绘图、全表熟练和一般证明逐项写入覆盖表。

## 验证要求

- 全部90个节点任务和52个联合任务通过实际控件完成；空白不完成，源边逐条核对。
- 拖动保留物品身份与总量；不均分即使数字正确仍不通过。支持拖动和点击两种方式。
- 首次错误预测、切块漏乘、未知量代入错、镜像重复、数量不足均有反馈；修正不升级为首次独立证据。
- 新阵列预览不得误用旧提交；多字符算式输入不失焦。桌面无横向溢出，单位格可读。
- 三方向、所有8条路线、分页、返回与刷新保留；不会一次展开24个节点。
- 问题保存两轮分配，后来第三轮另留草稿；模拟次日恢复原问题、准确物品位置、首错和世界视角。
- 实际导出、重复导入和离线继续保留上述证据；4个新模块完整缓存。
- 有界复查旧两步故事、空间、每日接续及延迟加载，旧活动和源图不改写。

这些为技术验证目标，通过结果写入制作记录与当前验证。实际孩子试用仍待进行。
