# B20 设计

DI–DO七条两节点路线。display入口沿用“把记录看明白”并增加“看时间与份额”“看分布与联系”；C/K保持可达，collect的三方向不改变。只有真实源边制作联合活动，编号不是先修关系。

核心教具：逐条计数与图例、等间隔时间折线、按行列找时刻与跨小时走分钟、分数数轴点图和杯中均分、扇区构造、等宽区间归组、五数箱线与隐藏形态、成对落点与手调趋势线。同一数据在不同表示中保持身份、单位与尺度；第一错误、提示和修改保留。给定图的读取与亲手构造分开记录。

未制作的先备由当前活动的小操作承接：60分钟一小时、整周360度、排序后取中间、成对数轴定位。不会给未制作节点增加完成，也不制造空跳转。

覆盖验证包括所有任务与真实连接、数学边界和多种合理答案、三方向与旧路线、较矮桌面、部分作品和原问题、模拟次日、真实下载/重复导入、离线与旧活动回归。孩子尚未试用，完成活动不等于全目标掌握。

完成逐点作图后，坐标录入和更正折叠，留下趋势或应用问题。没有明显直线趋势时隐藏画线项，并保留改变判断的历史。集中范围允许紧靠16的多个合理端点，不限定唯一机械答案。
