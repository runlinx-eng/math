# B30 设计

“边界与铺满”分成“铺里面，拆成几块”“沿外边走一圈”“包外面，装里面”三个方向，FV–GA 六条短路线与原 D/E 保持可达，每页最多三条。路线编号是导航，不新造知识先修关系；31 条新增联合活动逐条对应上游有向边。

先通过选择单位方格、外侧线段与两个角放置长方形，再比较面积和周长。分块必须不出界、不重叠、不遗漏；允许可行的不同拆法，部分任务为体现给定乘法结构，明确限定块的面积。可构造有共同边但无孔洞的组合形状。移动或复制固定的平面图形，观察面积不变；三角形的垂直高和斜边分开。圆周按同尺度展示，计算明确使用 π≈3.14，并区分周长与面积单位。

盒子、棱锥和棱柱可在真实三维视图中旋转和点选，固定展开图与被选的面同步；展开图本身不是连续折叠动画。组合立体分开时显示原本贴合的两面，接回后只选露出的外面；体积相加，表面积排除接触的两个面。开放文字只保存；固定样例、模拟对象、图形与数值核对不能证明一般公式、实物操作或独立解释。

保留首次错误、提示、部分作品、原问题、立体和世界视角及后来被替换的草稿。详见[研究依据](RESEARCH.md)和[逐目标覆盖](COVERAGE.md)。
