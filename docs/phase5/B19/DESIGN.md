# B19 设计

四条新小路线DE–DH，各2节点；collect入口三方向，同时保留原C、J路线。共8个源节点。只有已具备活动的真实源关系有联合任务；路线顺序不制造先修边。

主活动一次只显示一步：定问题 → 逐条记录 → 算成表 → 画图 → 回答。每一步都使用同一份记录。返回更正一条记录后，后面的表图与结论须重新检查；原尝试保留。三天观察和15人调查均明确为模拟。固定题目的结构选择可核对，自编问题/解释单独保存且不按字数判定理解。

其他活动包括一一配对比较、缺失和错误记录处理、名义/有序数据分类、测量背景、时间取整。公式只接受有限COUNTIF语法并实际执行，绝不eval。图从共同零点和统一尺度开始，柱图/点图/表可合理替换。并列最多/最少必须全部报告。原卡片、过程历史、第一错误与提示、问题、摄像机、后来的替换草稿沿用既有保存机制。

技术验证须覆盖任务初始不可完成、真实操作完成、记录更正导致下游失效、坏范围/空白/并列/伪造历史、较矮桌面、路线和原入口可达、刷新/备份/重复导入/离线/模拟隔天。孩子尚未试用；真实收集、独立报告和真实隔天使用仍待观察。
