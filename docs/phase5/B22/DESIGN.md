# B22 设计

chance包先给三个方向：“先看机会有多大”（旧L和DW、DX），“让结果跑起来”（DY、DZ），“几件事一起发生”（EA—EC）；每次最多三路线，单条2—4节点。旧路线L保留原ID和记录。15节点45任务，34条连接均核对为源关系，各有独立的两步操作。

先在等机会的卡片或小格中亲手选出有利结果，再写占整体的分数；自己排序机会卡并在0—1的尺上比较。画面用具体词，节点总结给概率、互补、独立、集合等正式名称。必要的总数、单位和事件条件保留。允许等值分数、集合内任意顺序和机会相同卡片的不同顺序。

操作模拟前保留最初预测。每一任务在初始化时生成种子，实际结果由该种子可重放：公平骰60→600次显示全部六面计数，硬币或隐藏规则装置显示自己的真实频率；不同任务可以有不同结果，不能为了结论重抽。数字模拟先选择0—3，再逐轮读到第一次A；实际数字、未完成序列、数量和随机状态均保存。

每组不放回的实验只先假设取到指定颜色，再对比放回与不放回；从同一个初始袋子比较。两次事件按行搭满格子，顺序不省略；概率树四条路径各自填写条件机会。两圈活动从总体、两圈总数、重叠构造四区，也允许逐个放数字；涂并集/交集/补集时记住所选择的区域，改动未保存时不能沿用旧结果通过。

节点与连接实际操作、随机结果原样回放、首错、帮助、原问题、后续草稿、次日、备份与离线分别验证；自由文字只保存。概率模型数据和屏幕模拟不代表现实实验，有限任务不等于长期掌握。孩子尚未试用。
