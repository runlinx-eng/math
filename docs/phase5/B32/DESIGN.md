# B32 设计

“时间怎样走”先给三个方向：“先后与用了多久”“转动钟面，看时刻”“日历与时间单位”。GD–GJ 是七条短路线，每次最多显示三条；GJ 在原单位入口也可到达。路线只负责导航，35 条联合活动都逐条对应上游有向关系，并非把并列节点当作先修关系。

先用相同时间轴比较谁先开始、谁先结束与谁用得更久；时长不同于结束时刻。时间条从左往右，明确要求前半场时只能选较早的一半，其他未指定位置的等份允许选任意一份。钟面长针按分钟移动，短针同步缓慢移动；可以点五分钟位置或用滑块选择每一分钟。分数时间可用等份条和钟面四分之一圆理解。

模拟秒表需要开始、活动前进、结束时停止；提前停止的首次选择仍保存。时间轴以 60 进位，允许不同的有效分段。日历按公历计算，跨月题保留两个月所选日期；日期间隔从起点向后数，起始日不额外算一天。12／24 小时制中的中午与午夜用明确文字区分；罗马数字钟面允许摆错并改正。

首次错误、提示、原问题、部分作品、位置与后来草稿延续现有本地记录机制。屏幕上的钟表与秒表是模拟；固定例子、自动核对和保存原话不评真实计时、自由表达或长期掌握。15 份上游研究和 4 个本地补充的依据及目标边界见 [研究](RESEARCH.md)和[覆盖](COVERAGE.md)。
