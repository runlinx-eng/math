# B36 设计：一起变化的量

在“一起变化的量”中直接提供三条短路线：从图形走到公式、在平面上找位置、让图线跟着变化。每条路线包含 2–3 个节点，编号只是建议；14 条联合活动对应上游已有关系，不把空间位置、相邻编号或本地分组当成新的先修边。

孩子可以改变长方形的长宽或三角形的底和垂直高，比较一圈与里面，先猜再看结果；将正数、负数和分数代入同一关系；点击坐标平面或输入数对放点。两轴上的点不属于任何象限。负数代入平方时用括号区分 `(−2)²` 与 `−2²`。

改变“每步变化”或起点，图线同时改变，可留下多条线作比较；比较模拟的两人位置时，位置更高和前进更快是不同问题。孩子按规则实际放点；点数足够后，系统按规则绘制直线或曲线，并在界面注明，这是继续观察的支架。二次曲线的两个横轴交点可直接选中，也可在另一组图上估计交点。

公式改写接受实际等价的写法。平方反推既可出现正负两个结果，也可能在实数范围内无解；除法要求除数不为零。任务保留首次错误、提示、问题原话、部分作品、世界视角及之后的草稿；恢复问题时不覆盖后来的操作。

这些都是有限情境和结构化操作，不证明孩子能独立绘图、进行一般推理或长期掌握。孩子尚未试用，兴趣、起步和真实隔天继续仍需观察。数学及教学依据见[研究](RESEARCH.md)，逐目标范围见[覆盖表](COVERAGE.md)。
