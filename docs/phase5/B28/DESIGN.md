# B28 设计

“用单位比较”先选“比一比，再量／用不同的尺／换单位，画记录”，每页最多三条短路线。原 E 同时属于单位、面积、体积；本批只在单位入口为它设置分组，面积和体积入口仍直接显示原路线。新增 FI–FS 共11条路线。路线编号和空间位置仅是导航；新增连接逐条核对为源依赖。

孩子先移动起点对齐、把同样大的单位放满，或用模拟天平、砝码和量杯比较；再选择工具、先估后量、观察不同大小单位和读取仪器刻度。换单位时输入自己的数量，画面用同一尺度比较原量与输入量；英制近似明确写出。测量点图先逐个记录模拟物体，再将每条记录放到等距刻度上，重复值不能省略。

首次错误、帮助、部分放置、测量记录、问题原话、世界视角和后来草稿沿用本地保存。活动先用可见量和日常说法，收尾呈现正式名称；开放解释只保存不自动判懂。生活物件、纸片、天平和量杯都是模拟，不代替真实测量。孩子尚未试用，起步、兴趣和学习效果没有证据。
