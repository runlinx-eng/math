# B34 设计

“寻找与创造规律”先展示三个方向：摆一摆、数怎样变、改规则看结果。GQ–GV 六条短路线每条 2–3 个节点；20 条联合活动都能对应上游已有有向边，路线分组和相邻编号不是新先修关系。

孩子可以补一个重复片段，自己选两种形状创造另一段；可以把 1、3、5 组增长的三维积木转动、点击空位填出下一组，也可以用按钮放。空位轮廓预先呈现七块，是明确支架，不能据此声称孩子独立预测出了七块。画面先用日常说法说明做什么，收尾再给正式名称。

数列用明确起点和步长逐项生成，小数用整数刻度核对，负数可以过零；两列数能形成数对并在网格标位置，更换起点后重新检查两倍关系。2、4、6 的活动先保留自己的猜想，再展示两种明确规则得到 8 或 10，避免把有限前缀当成唯一答案。

执行、生成和设计步骤可逐步观察条件与结果：50 不属于“大于50”；超过100后停保留192，下一次会到80以上之前停则保留77；先按3分类会把15过早归入单一类别，重新排列后可再运行。改动步骤后不把旧运行结果冒充当前结果。组合网格可逐格选择，避免重复和遗漏。

原始问题、部分积木、视角、首次错误、提示和修正沿用现有记录和续接机制。自由解释、独立绘图、一般证明和长期理解不由固定活动自动评估；孩子尚未试用。详见[研究](RESEARCH.md)和[覆盖](COVERAGE.md)。
