## 从来源保留了什么

| 内容 | 本地动作与诊断 |
| --- | --- |
| 一半、四分之一、形状等分 | 先分8颗或12颗，再模拟折痕；有相同块数但不等面积的反例。允许长方形不同方向等分 |
| 份数与一份大小 | 固定相同整体，预测后涂片、覆盖；1/2与1/4、1/4与1/8换顺序比较，最早预测保留 |
| 等面积而形状不同 | 16格由孩子涂成四组等面积，保存两种分界；重命名颜色不能当第二种分法 |
| 部分集合 | 每颗保留身份，先分到相同数量的组，再取若干组。3颗相对12颗可以是3/12或1/4，不能是3/9 |
| 分数作为数 | 固定0到1为单位，走到1/4、1/2、3/4与1/3；画到4的数轴也不改变单位 |
| 大于或等于1 | 连续积累相同单位份，构造4/3、7/4、4/4与5/1；份的大小不变，数量增加 |
| 分数乘整数 | 五次各3/8与四次各2/3实际按组跳；精确吃掉15/8与必须购买2个分别记录 |
| 分数与除法 | 先发完整份，余下每个切成与人数相同的等份；原整体边界、每小片身份和去向保留。50÷9=5又5/9可乘9倒查 |
| 求量的几分之几、建模 | 分组/条形先找一份，再取几份；500克的3/4得375克，1米的3/4对应75厘米；答案必须带回单位 |
| 多表示互译 | 4×23的面积分块与按位计算相接，0.3与3/10同点；35/100、0.35、35%同一着色量，另用8/100迁移 |
| 混合数系 | 大位、小位、负数、小数与分数在同一尺度定位排序；相等卡片允许任意先后，不强迫假顺序 |
| 精确表达 | 完整单位、分子分母与等值术语、六种比较符号；金额适配元/分。3.5元与3.50元数值相等，保留两位只是一项指定记录惯例 |
