# B16：一份与同一个量·批1

22个源节点、74个节点任务、CF—CN九条短路线、40条真实源连接的80个联合任务。累计259节点、882节点任务、92路线、236连接、472联合任务、784项目标对应。

“一份与同一个量”入口只有三个方向：分出一样多的份／把一份接成一个数／换个样子，说同一个量。原A、G、H分别接入这些方向，保留路线ID和记录。每页最多三条路线，孩子选定后只看该路线2—4个点，不增加完成状态。

| 路线 | 主要动作 |
| --- | --- |
| CF 从一半到四份 | 逐颗公平分、折痕模拟、不同分法比较、把所有小份拼回整体 |
| CG 份数、形状与大小 | 同一整体上预测后叠片，涂等面积不同形状 |
| CH 一堆东西，取其中几份 | 分到等组，再取一组或多组；换总量再试 |
| CI 沿着一份走过去 | 固定0到1分间隔、迭代、跨过1、整份与零头 |
| CJ 不同写法，共用一条线 | 读高亮数字实际量，混合数定位与排序，六种符号 |
| CK 小份累起来，整个分下去 | 相同分数的成组跳跃、按整份采购；完整份先发，余下继续细分 |
| CL 换一种图，认出同一件事 | 配方条形、米厘米、面积与按位计算、百格换表示、读图求差 |
| CM 说清楚，再讲理由 | 单位与术语、共同小份、纠正几十行、原角搬移无缝拼半圈 |
| CN 故事、图与关系 | 未知条形两边同步变化、表格转坐标、圆图比例、方程与分数路程 |

新模型位于`b16-model.js`，界面在`b16-view.js`与`b16.css`，复用B14面积/按位算法及B15表达式/比较条。新模型动作回放验证保存内容；首次预测、错误操作、检查、求助、修改都保留。部分集合的物品与分开的每一小片有稳定身份。分割后的源整体框仍可见，移走的小片留下位置，避免把“3个整体各分4份”误看成一堆没有来处的小块。

分数值用有界整数分子分母和交叉乘法比较，5又5/9接受为精确值，小数近似不能冒充它；0.75与3/4接受为同值。算式还要符合关系，不能只比最后结果。通分要求实际画出可同时细分两边的单位。已有画面与当前份数等设置不一致时不能提交旧构造。三角形需要同一原角身份、无缝无重叠覆盖半圈，理由顺序也被保留；自由论证另存未评。

整体画布、587个源节点、1223条源关系和固定坐标不改。路线顺序与空间距离不变成先修边；连接只从真实源边建立，仍需独立联合工作，不能仅凭两端完成点亮。

桌面验证采用1440×1050与1366×900。任务开始先给操作对象，输入在分配或构造后出现。长任务允许纵向展开，重要数学比例不随文本挤缩；不增加手机布局、家长入口或外部服务。当前完成指实现与技术检查，孩子理解、愿意继续及真实隔天使用尚未验证。
