# B07 交互与验证设计

21 个源节点，7 条路线 X–AD，71 个节点任务；11 条真实源边各有两个联合任务。第一入口仍是原三个方向，每次最多三条路线，换组不离开三维世界。组、路线、相机、返回和刷新保持；各条路线仍只显示2–3个节点。路线和空间位置不是新造的先修关系。

## 主要对象

- 交换台：十格长条与百格板保留相同单格尺度，十百合千仍显示十板。亲自合起和拆开；固定数量操作始终守恒。初始数量和总数输入均不能替代需要的交换动作。
- 多种表示：方块与线点需分别重搭并保存。三种分拆按数量组合去重，不能重复点保存凑数。实物吸管/积木能力仍未评估。
- 改变数量：先存预测，再添取；有误可以逆向改正，原始预测与操作路径保留。190加10、300减10要求正确换装，避免“永远只改一位”。
- 大小与位置：自己搭出两边，再比较最高不同位；包含大于、小于、相等、同百同十与零位。排序还需真实数轴位置；47须更近50，346须略在300–400的中点之前。点位置的近似与准确排序分开处理。
- 估计和配对：先存估数再逐颗标记核对，估错不阻止学习；两两配对不重用物品，偶数表现成两组相加，包含零边界。不判定孩子是否在心中逐一计数。
- 实际问题：包装、倒推、虚拟代币明确各单位。236全换成23个十与6个一，区别十位数字3与总共有23个十。代币为100元/10元/1元，不混用外币小单位。

七种新模型复用旧记录和任务系统；数表与47到120逐站计数直接用B06模型。没有复制应用、引入账号、服务器API或生成模型。

## 验证方式与边界

规则检查覆盖守恒、错位、零、非标准分拆、预测不改写、错步可修正、估位范围、配对唯一性及备份。浏览器逐个通过真实控件走完所有新节点和连接；另外验证路线组、部分作品、模拟隔天、下载导入与离线。解释只保存，不靠字数或选择题推断已懂。

数词是中文改编，原英语目标未评估。屏幕表示、口述准备和固定场景完成不等于现实工具操作、朗读流利、任意情境迁移或长期掌握。孩子尚未试用，没有把技术检查当成实际学习反馈。
