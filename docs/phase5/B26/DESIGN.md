# B26 设计

沿用“转弯与角”的三个方向，在“拼图形，试条件”中加入 FC「一条斜边和一个角」，每次显示原有三条路线中的一个选择。FC包含两个源节点、10个有限任务；两条连接均对应源依赖，每条包含两步相关操作。路线编号和位置是本地导航，不是新造的前置关系。

孩子先选择直角对面的边，比较三边上的正方形与同尺度面积条，放大后再看变化；接着区分有无直角、求未知边并用两种横竖辅助线找坐标距离。另一个节点先切换观察角，为同一三角形标出斜边、对边、邻边，再观察放大前后比例，最后在有限例子中选择sin、cos、tan并用可选本地计算器算边或反算角。

图形和面积来自实际坐标，放大时屏幕尺寸与面积条分别按两倍和四倍变化；面积条不是切拼证明。已完成的边名控制可以收起并重新编辑，计算器显示结果后保持展开。平方与比例有可选说明，使用帮助、第一错误、未完成作品和原问题按既有机制保存。

六个源目标均标明有限任务对应和未评范围；未实测实体工具、任意公式变形、开放解释和一般证明。孩子尚未试用，不据此判断上手、兴趣或实际学习效果。
