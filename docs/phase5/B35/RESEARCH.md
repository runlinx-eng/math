[美国教育科学研究所代数教学指南](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/WWC_Algebra_PG_Revised_02022018.pdf)建议关注表达式、数量和等式的结构，讨论不同步骤与典型错误；本地的移动、分组、代入与图像活动是依据该方向设计，并非对该产品的效果验证。

等号表示两边同值，未知字母表示数。对等式两边做同一加减，或同乘／同除一个非零常数，可以保持解的等价；只改一边、除以零、把步骤串成不真实的等式，都不能当作保持等价。原式代入验证，不以操作次数或点击提示代替独立理由。负数与分数答案不能因为不是正整数就被拒绝。

一个含两个未知数的等式通常有多组解，是否能列全要写清正整数、整数或范围等限制。图上两条不同直线相交的点满足两式；平行直线无交点、重合直线有无穷多个共同点，不能把“总有唯一交点”当一般结论。[OpenStax 联立方程](https://openstax.org/books/intermediate-algebra-2e/pages/4-1-solve-systems-of-linear-equations-with-two-variables)说明交点、平行和重合的区别。图上读数是近似位置，仍应代回两个原式核对。

字母前的系数表示乘法，不是幂；`3x` 与 `x²` 有不同结构。同类项必须变量及其指数相同，符号属于对应的项；[OpenStax 多项式说明](https://openstax.org/books/algebra-and-trigonometry/pages/1-4-polynomials)给出同类项合并条件。括号前的因子要作用于括号内每一项；双括号的四个乘积也要逐一计算。负号乘积可用符号表，不能把负数乘积画成物理负面积。提取公因式后展开回原式检查；本批的有限整数系数例子不代表所有多项式因式分解。

有限示例、已给定的卡片与栏位属于支架。自由建立符号、口头解释、一般证明和跨情境迁移不能由正确点击自动判定。第 n 项规律要区分“下一项怎样变”和“由位置直接算”；从 3、7、11 开始，第 n 项为 4n−1，第一项在 n=1，而不是 n=0。
