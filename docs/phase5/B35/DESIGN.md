# B35 设计

“相等与未知数”提供三个方向：找出盒子里的数、把关系写出来、拆开再收起来。GW–HC 七条短路线每条 2–3 个节点；原 N 路线归入第一个方向，仍然可以进入。20 条联合活动逐条对应上游已有有向边，导航分组和相邻编号不自动制造先修关系。

孩子可以从已知数沿数轴走到目标、排列两个先后动作并代入一个数、记录一对一对满足关系的数。等式变换支持两边同时加减、乘除非零数，以及两边增减同一份未知数；不同的有效步骤都可以使用。只改左边给出不提交的对照预览，记录这次尝试。最后把结果放回最初的关系。天平只是等式变化的示意，负数不代表实物负重量。

卡片按变量和指数归组，不能把 x、x² 与 y 强行合并；乘积表让孩子逐格写出括号里各项的乘积，再输入合并后的结果。因式分解填写共同因子和括号中的数量，实际展开回原式；修改后的旧检查不会当作新结果。负号表是符号运算，不是负面积。

两条线在同一张坐标图中，可以直接点坐标或输入数字并逐条验证，选中的点就是要检查的答案；半格支持分数与小数两种输入，不再要求重复抄写坐标。除交点例子，还对比平行和重合的情况。给定的图、动作卡、括号位置及系统自动排序是支架，不等于孩子能独立建模、完成一般证明或口头解释。原始问题、首次错误、未完成作品、世界视角和后来草稿沿用本地记录与续接机制。
