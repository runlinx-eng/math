## 三工作区统一交互契约

| 工作区 | 选中后主要动作 | 次要入口 | 切换和恢复规则 |
| --- | --- | --- | --- |
| 探索 | 详情卡「开始/继续学习」或「查看联系」 | 收藏、关系、相机聚焦放在原地的次级区域 | hover 只预览；click 才选择；唯一 active-target |
| 学习 | 当前 `#actions` 唯一主按钮：操作→检查→修改/下一题→保存 | 帮助、资料、问题、路线默认收起 | 切到足迹/探索暂停而不是销毁 iframe；恢复原题和草稿 |
| 足迹 | 有真实未完记录时「继续这个知识」；否则先展示记录/草稿 | 全部历史、备份、旧记录、待续问题 | 不以浏览/收藏冒充学习完成；保留对应知识上下文 |

**减法准入：** 每删除一个按钮必须提供「旧位置→可发现的新路径→真实点击证据→返回/刷新/草稿恢复证据」四项证据；缺任一项不删除。禁止通过 CSS 隐藏关键功能却不提供替代路径。真实节点点击只通过 3D 标签交互触发，不使用 hash 或 `force` 绕过。

## R2 建议实施顺序及验收

1. 先统一 `continue` 与 `journal` 的可发现路径；仅删除确定重复的可见入口，不动处理函数和存储格式。
2. 详情卡 `open` 为唯一主 CTA；收藏、关系视角等清晰降级，不互相抢占焦点；旧活动继续可通过可发现的二级入口访问。
3. 学习页内外两种「返回」先验证：嵌入课程、独立课程和草稿态；路径一致后才收纳重复控制。
4. 足迹的节点级继续入口统一取最近真实任务；保留旧记录、作品、导入导出和完整历史。
5. 独立记录 1440×900、1280×720、980×760、620×800、1000×1350 的探索/学习/足迹截图，并增加触摸点击、Tab/Enter、焦点可见性、无 hover 触控、浏览器后退/前进/刷新、两次不同真实节点点击、草稿恢复及 P10 升级 3/3 的验证。
