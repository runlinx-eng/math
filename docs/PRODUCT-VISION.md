# 数学树｜产品定位与长期设计原则

> **文档性质：产品愿景与长期设计约束（Product Vision / Product Principles）。**
>
> 适用于 3D 知识探索、数学学习、数学思维、学习反馈及学习足迹等后续设计与开发。它不是某一阶段的需求清单、数学能力评分模型或已验证的教学效果声明。
>
> 建立于 2026-11-08 的产品目标对齐。后续变更应保留理由、对产品目标的影响及验收依据。

## 一、产品最终目标

**让孩子在连续、可自主探索的数学知识空间中，建立数学知识的结构认知，通过实际活动发展数学思考与解决问题的能力，并通过反馈、反思和迁移持续深化理解。**

产品由三个相互关联但不能相互替代的部分组成：

| 部分 | 核心问题 | 产品职责 |
| --- | --- | --- |
| **3D 知识树** | 学什么？知识之间如何联系？ | 呈现真实数学知识的基础、分支、交汇及发展关系，支持自由探索和结构理解 |
| **学习过程与数学思维** | 怎么想？怎样解释和解决问题？ | 通过猜想、操作、建模、寻找规律、推理、论证与检验等活动，创造可观察的思维过程 |
| **学习反馈与足迹** | 用了什么方法？怎样改进与迁移？ | 依据实际尝试、作品和解释提供有边界的反馈，帮助孩子认识、反思并在其他知识中继续运用方法 |

**一句话原则：知识是探索的对象，思维是探索的方法，真实学习成果是探索留下的证据。**

## 二、统一 3D 交互：空间唯一，操作连续

**知识有层级，操作不分层。空间唯一，工作区统一，状态连续。**

- 数学主题、知识群、知识点可以分层组织，用户无需逐层进入、退出独立页面或多张地图。
- 整体知识结构是产品主体，不是网页面板背后的装饰。理解、关系、学习活动、反馈、成果均围绕当前知识在同一空间的上下文工作区展开。
- 选择知识、切换关系、打开或收起学习/足迹，不得擅自重置或移动相机；只有用户主动聚焦、归位、平移、旋转、缩放或切换视角才改变相机。
- 用户可以从任意知识、真实关系、保存作品或待续问题继续探索；不按年级、教材或预设路线锁定路径。
- 3D 布局的节点坐标、关系方向/强弱、学段和已收集的学习证据具有不同含义；**空间距离与位置不能被误写成难度、掌握水平或必须遵守的学习顺序**。

## 三、50 个数学思维节点的产品定位

现有固定来源包含 **537 个领域知识节点、50 个数学思维节点及 1,223 条数学源关系**。其中 50 个思维节点及其八条发展链应继续保留在底层知识和活动数据中。

**产品决策：数学思维不是第二张需要逐级点击的知识树，而是贯穿不同数学知识与任务的思考方法体系。**

- **不必将 50 个思维节点全部固定呈现为三维球体**，也不为它们编造 XYZ 坐标或新关系。
- 只有当存在可信的源知识关联、活动行为或学习反馈价值时，才在相关知识的探索、任务与结果中适度呈现思维节点。
- 在学习过程中，根据实际观察到的操作、表达与解释，提示**可能涉及**的数学思维；无足够证据时不推断。
- 在反馈中，帮助孩子理解刚才用了什么方法、其适用条件、存在的不足，以及这种方法可以在何处继续使用。
- 八条发展链用于设计、解释和长期观察，不要求孩子依次完成，也不直接充当能力等级或评分体系。

这项定位是**产品设计方向**，不表示现有运行时已经完成自动思维识别，更不表示完成了 50 个思维节点的独立教研或儿童使用验证。

## 四、从学习过程到真实反馈的边界

**完整闭环：发现问题 → 理解关系 → 猜想与操作 → 验证与解释 → 反馈与反思 → 迁移应用 → 保存成果 → 回到数学空间继续探索。**

反馈必须区分四个层次：

1. **结果**：题目、构造或提交是否符合已实现的可检查条件。
2. **过程证据**：怎样操作，是否查看提示，是否修改、重试，是否提供解释或寻找反例。
3. **思维方法提示**：哪些具体行为可能体现了论证、建模、寻找规律等方法，必须说明依据和不确定性。
4. **持续发展**：是否能在不同知识和新情境中再次运用该方法；需要多个实际表现支持，不能由一次答对或一次解释直接认定。

### 例子：等值分数

孩子答出 **1/2 = 2/4**，只能说明该次结果符合预期，不能单凭正确答案判定其具备“论证与质疑”能力。

如果孩子能用**同一整体的等分**说明为什么两者相等，系统可以据其解释反馈：*“你尝试用等分的关系解释结果，这是一种为结论提供理由的方法。”* 如果孩子主动检验条件、比较不同分法或寻找反例，才有进一步提示“质疑与检验”行为的根据。

即便如此，反馈也是对**这一次可观察行为**的描述，而不是“已掌握论证与质疑”的认证。自由文字、口述或没有实际采集的思考过程，不应被虚构为可验证证据。

## 五、长期验收标准

从产品层面，后续设计应能回答：

- 用户是否能从一张真实、可读的 3D 数学关系图发现兴趣点，并沿有依据的关系自由探索？
- 用户是否能在保持空间上下文的情况下进入真实任务、尝试、检查、修改、解释和拓展？
- 系统能否清楚区分**结果正确、有效作品、思维方法线索、能力长期发展**，避免自动夸大学习效果？
- 作品、问题、草稿和真实尝试能否回到原知识及相关思维上下文，支持下次继续？
- 即使没有独立思维地图，数学思维的呈现与反馈是否能够帮助孩子认识自己的思考方法，并尝试迁移？

自动化回归、内容映射核查、独立数学教研和真实儿童学习效果验证必须分别记录，不能互相代替。

## 六、实现现状与任务边界

- **已有工程基础**：固定源节点和关系、唯一 3D 数学全景、部分学习活动、判题与提示/重试/草稿/保存解释、足迹和本地状态恢复。
- **尚需持续验证和完善**：数学空间视觉可读性、完整学习闭环的真实体验、50 个思维节点与学习活动的逐项证据对齐、解释与反馈的数学准确性、跨问题迁移及实际儿童理解。
- **未作出的承诺**：自动识别所有自由解释的数学思维、自动测定思维成长、根据一次正确操作判定掌握、不经验证宣称教学效果。
