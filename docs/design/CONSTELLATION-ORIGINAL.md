## 独立创作，无须购买模板

用户选择的是 Constellation（Vandromeda / Framer）中「整屏可探索星空 → 点击星体 → 全屏专注内容 → 返回星空」的体验方向。所有星空 Canvas、CSS、HTML 和 WebGL 色彩调整独立实现，不使用付费模板代码、图片或第三方星空纹理。

## 结构与语义

- 主页：全屏知识星图，真实 587 个数学知识点与 1,223 条正式先修关系保留原坐标。未选中节点为低饱和银蓝星点，选中节点为暖金，直接关系节点为雾青。三态学习进度标记不变；第四态不启用。
- 星空背景：不接收点击的独立 Canvas 装饰层；所有真实星体节点、数学前后关系与 hit test 仍归原 SpatialScene，不添加假知识节点。
- 知识：点击节点后用原 #focus-card 的真实数学来源和关系内容打开全屏专注页，关闭后返回原相机。
- 课程：复用真实学习 iframe、纠错、Next、存储/备份，改为深空全屏外框和中心可读的数学操作区；不再强制两栏并排。
- 观察：原完整观察工具可展开；原地图/查找/旋转/缩放/学习/足迹均可使用。动画尊重 prefers-reduced-motion。
