# P11｜宇宙知识星图视觉试点 v1

状态：候选实现；等待真实 Chromium 截图与用户视觉验收。来源：用户确认的深空数学树概念图；知识网络结构参考 Marble Curriculum。Issue #377。

## 范围与硬边界

- 仅改变主 3D 地图及外围 UI 的视觉主题：深蓝黑背景、细腻暗色节点、雾青关系线、香槟金焦点和玻璃质感信息面板。保留五主题颜色分组。
- 不替换真实交互地图为静态图片。空间沿用原 587 个数学节点、1,223 条来源关系与原三维坐标；无假节点、无假关系。未开发第四学习状态。
- 维持探索、学习、足迹、搜索、手动旋转缩放、全貌、知识详情和真实 Next 行为；不改题目、数学判题、学习记录、离线或备份数据。
- 视觉主题由 body.cosmos 启用，CSS 覆盖放在 space.css 末尾；原 CSS 及资源仍可回退。WebGL 清屏透明以露出深空环境背景，保留真实节点和方向/强度关系。
- 按真实数学图谱着色。金色用于当前操作焦点，冷青用于键盘焦点/后续方向，暖铜用于前置方向；原 hard/soft 线型和学习完成光环保持独立。
- 学习 iframe 暂保持亮色阅读纸，以确保算式、数轴、分数及教具具备对比度。首次视觉试点不改所有题型颜色或堆叠提示。

## 验证

- 应以 1440×900、1280×720、620×800 的真实 Chromium 分别检查全貌、选中概念、前后关系、学习中的地图与题目、键盘焦点、返回、历史及离线体验。
- CI 与源码检查不能替代用户审阅截图，也不能证明儿童独立识别。合并及 VPS 发布分别按现行流程审批；本 PR 不部署 VPS。
- 风险：深色 WebGL 绘制与 CSS 标签跨层对比度需实图检查；不修改坐标、相机保存、课程数据或默认操作模型。
