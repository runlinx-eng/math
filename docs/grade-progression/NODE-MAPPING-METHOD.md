# 知识点与中国小学课程标准映射方法

状态：本分支工作方法；尚未合并 main。
适用对象：537 个领域知识节点。50 个数学思维节点另行处理。
主要依据：教育部《义务教育数学课程标准（2022年版）》。

## 1. 映射目标

把知识树现有节点放到中国大陆“六三”学制小学三个学段的整体轮廓中，帮助观察知识出现、深化和延伸的位置。映射不是教材目录，不指定唯一年级，不改变数学前置关系，也不构成个体学习建议。

## 3. 阶段与证据等级

阶段 ID：
- `stage-1`：第一学段，1—2 年级。
- `stage-2`：第二学段，3—4 年级。
- `stage-3`：第三学段，5—6 年级。
- `beyond-primary`：主要属于初中或小学之后的衔接内容；不把它塞进小学三个阶段。

证据等级：
- `direct`：课程标准明确写出相同或实质相同的知识内容。
- `conceptual`：课程标准没有使用该节点的专门名称，但节点是标准明确要求的概念、操作或能力的合理组成部分。
- `adjacent`：与课程内容有联系，但现有证据不足以说它是该学段明确要求的知识点。
- `not-covered`：目前没有找到小学课程标准中的对应要求，需保留为扩展内容或继续研究。

阶段角色：
- `main`：标准有明确支持，可作为该阶段的主要观察内容。
- `extension`：可作为前后阶段的复现、深化或拓展，不代表该阶段首次学习。
- `transition`：主要用于小学后续或初中衔接，不纳入小学核心分布。

## 4. 逐节点判断规则

1. 先读节点的实际数学目标、描述和证据，不以标题单独判定。
2. 对照国家课程标准的内容要求、学业要求和教学提示，记录可定位的标准引用 ID。
3. 以“六三”学制三个学段作粗粒度映射；课程标准没有逐年级规定时，不推断一年级、二年级等单一年级。
4. 一个节点可以有多个阶段；不同阶段应分别说明是主要学习还是延伸。
5. 上游 `ageRangeStart` / `ageRangeEnd` 只作差异检查，不能作为中国年级归属依据。
6. 上游 ACARA、Common Core、England National Curriculum 的代码只可作为比较线索，不可代替中国课程标准。
7. 节点包含多个内容时，按其核心目标判断；如果一个节点混合了不同学段内容，标记跨阶段或待拆分审查，不通过虚构唯一阶段来掩盖。
8. 数学思维节点不按普通知识点方式分配阶段；优先关联小学核心素养或综合实践要求，必要时记录为跨阶段过程能力。
9. 年级顺序不能新增、删除或改变任何数学前置关系。

## 5. 数据字段

每个领域知识节点在 `node-stage-candidates.json` 中保留原字段，并增加 `chinaCurriculumMapping`：

- `stages`：阶段 ID 数组，可多选。
- `roles`：阶段 ID 到 `main` / `extension` / `transition` 的映射。
- `evidenceLevel`：`direct` / `conceptual` / `adjacent` / `not-covered`。
- `standardReferences`：上表中的引用 ID。
- `rationale`：用中文说明节点目标与课程标准的对应关系。
- `scopeBoundary`：说明课程标准没有直接保证的部分，避免过度推断。
- `reviewStatus`：当前统一标记 `ai-first-pass-needs-independent-review`。

原有 `candidateStages` 是按上游年龄范围生成的机器候选，必须保留，不与中国课程标准映射混为一谈。

## 6. 批次和验收

按数学领域分批核对。每批需做到：
- 节点 ID 与源数据一一对应，无增删、无重复。
- 每个节点有可追溯的标准引用，或明确标记无直接对应。
- 阶段角色和理由与节点的实际数学内容一致。
- 不能把“年龄重叠”写成“课程标准明确要求”。
- JSON 可解析，源 ID、原始名称、数学关系及坐标不变。
- 报告 AI 辅助初审的范围与限制，不宣称独立教研、教师审阅或儿童测试。

本方法本身不构成课程专家审核。完成所有批次后，仍需安排独立教研复核。
