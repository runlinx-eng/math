# 知识点与中国小学课程标准映射方法

状态：本分支工作方法；尚未合并 main。
适用对象：537 个领域知识节点。50 个数学思维节点另行处理。
主要依据：教育部《义务教育数学课程标准（2022年版）》。

## 1. 映射目标

把知识树现有节点放到中国大陆“六三”学制小学三个学段的整体轮廓中，帮助观察知识出现、深化和延伸的位置。映射不是教材目录，不指定唯一年级，不改变数学前置关系，也不构成个体学习建议。

## 3. 阶段与证据等级

阶段 ID：
- `stage-1`：第一学段，1—2 年级。
- `stage-2`：第二学段，3—4 年级。
- `stage-3`：第三学段，5—6 年级。
- `beyond-primary`：主要属于初中或小学之后的衔接内容；不把它塞进小学三个阶段。

证据等级：
- `direct`：课程标准明确写出相同或实质相同的知识内容。
- `conceptual`：课程标准没有使用该节点的专门名称，但节点是标准明确要求的概念、操作或能力的合理组成部分。
- `adjacent`：与课程内容有联系，但现有证据不足以说它是该学段明确要求的知识点。
- `not-covered`：目前没有找到小学课程标准中的对应要求，需保留为扩展内容或继续研究。

阶段角色：
- `main`：标准有明确支持，可作为该阶段的主要观察内容。
- `extension`：可作为前后阶段的复现、深化或拓展，不代表该阶段首次学习。
- `transition`：主要用于小学后续或初中衔接，不纳入小学核心分布。

## 4. 逐节点判断规则

1. 先读节点的实际数学目标、描述和证据，不以标题单独判定。
2. 对照国家课程标准的内容要求、学业要求和教学提示，记录可定位的标准引用 ID。
3. 以“六三”学制三个学段作粗粒度映射；课程标准没有逐年级规定时，不推断一年级、二年级等单一年级。
4. 一个节点可以有多个阶段；不同阶段应分别说明是主要学习还是延伸。
5. 上游 `ageRangeStart` / `ageRangeEnd` 只作差异检查，不能作为中国年级归属依据。
6. 上游 ACARA、Common Core、England National Curriculum 的代码只可作为比较线索，不可代替中国课程标准。
7. 节点包含多个内容时，按其核心目标判断；如果一个节点混合了不同学段内容，标记跨阶段或待拆分审查，不通过虚构唯一阶段来掩盖。
8. 数学思维节点不按普通知识点方式分配阶段；优先关联小学核心素养或综合实践要求，必要时记录为跨阶段过程能力。
9. 年级顺序不能新增、删除或改变任何数学前置关系。

## 5. 数据字段

每个领域知识节点在 `node-stage-candidates.json` 中保留原字段，并增加 `chinaCurriculumMapping`：

- `stages`：阶段 ID 数组，可多选。
- `roles`：阶段 ID 到 `main` / `extension` / `transition` 的映射。
- `evidenceLevel`：`direct` / `conceptual` / `adjacent` / `not-covered`。
- `standardReferences`：上表中的引用 ID。
- `rationale`：用中文说明节点目标与课程标准的对应关系。
- `scopeBoundary`：说明课程标准没有直接保证的部分，避免过度推断。
- `reviewStatus`：当前统一标记 `ai-first-pass-needs-independent-review`。

原有 `candidateStages` 是按上游年龄范围生成的机器候选，必须保留，不与中国课程标准映射混为一谈。

## 6. 批次和验收

按数学领域分批核对。每批需做到：
- 节点 ID 与源数据一一对应，无增删、无重复。
- 每个节点有可追溯的标准引用，或明确标记无直接对应。
- 阶段角色和理由与节点的实际数学内容一致。
- 不能把“年龄重叠”写成“课程标准明确要求”。
- JSON 可解析，源 ID、原始名称、数学关系及坐标不变。
- 报告 AI 辅助初审的范围与限制，不宣称独立教研、教师审阅或儿童测试。

本方法本身不构成课程专家审核。完成所有批次后，仍需安排独立教研复核。

10. **分数的学段边界**：第一学段的数与运算要求以简单整数运算为主，不因上游年龄范围或生活中的平均分经验而推断为国家课程的正式分数内容；第二学段初步认识分数、感悟分数单位、比较简单分数并学习同分母分数加减；第三学段深化分数意义，进行分数与小数转化及简单分数四则运算。
11. **通分与约分的证据等级**：课程标准教学提示明确解释通分是为了得到相同计数单位；“约分”未作为独立内容要求逐项列出，映射时不将两者都标成直接对应。
12. **算法与数域边界**：第三学段的简单分数运算不等于课标规定某一种倒数口诀、书写算法或全部分母组合；含负数的有理数运算和更一般的有限小数—分数互化需标注初中衔接。
13. **百分数与小数精度**：第三学段明确要求理解百分数意义并进行简单分数、小数转化；具体的百分数算子策略、千分位、三位小数和取整精度需按节点目标标为概念关联或拓展，不扩大为统一必学清单。

14. **图形与几何的学段边界**：第一学段以常见平面、立体图形的直观辨认、分类、拼图及基本方向为主；第二学段深化线、角、三角形和四边形特征，测量角并感受平移、旋转和轴对称；第三学段学习三角形边角关系、圆、面积与体积、自然数有序数对、比例尺和方格纸上的简单变换。
15. **初中几何不提前并入小学**：平行线性质与判定、对顶角关系的推理、三角形全等、勾股定理、一般多边形角和、尺规作图、相似、四象限负坐标和三角函数均按第四学段或初中衔接处理。
16. **空间直观与截面知识区分**：小学标准支持常见立体图形辨认、不同方向观察、展开图以及体积和表面积；不能仅凭“空间观念”目标推断棱柱截面性质属于明确课程要求。

17. **测量的学段边界**：第一学段以长度、生活时间、货币等直观活动为主；第二学段明确周长、长方形正方形面积及相关测量；第三学段深化多边形面积、常见立体体积及表面积。跨学段节点按实际数学操作与复杂度记主或延伸，不将上游年龄机械换成年级。
18. **计量与文化情境**：容量和液体当前体积、质量与重量、面积与周长应区分；英制单位、英美澳货币符号、澳大利亚GST和现金5分舍入规则不视作中国国家数学课标必学内容。含复杂外币表达的节点可以标记为概念关联或相邻拓展。
19. **综合量与精度**：分数边长体积、复杂组合立体、精细刻度及分数点图，不能仅因小学有相邻知识就判作国家小学明确要求；关注多量纲单位一致性、钟表时刻与时长的区别，源标题与实际目标不一致时按描述和证据映射并在审查台账注明。

## 7. 代数与规律的专门边界（第十批）

- 第一学段的“用数或符号表达简单情境中的变化规律”，不能等同于正式数列、通项公式、流程图或编程条件循环。
- 第三学段明确包含字母表示数量关系、等式性质、成正比的量与`y=kx`数据作图；第四学段才系统规定整式运算、解方程与不等式、一般一次与二次函数。
- 使用长方形周长、三角形面积公式不等于学习函数，也不等于会处理带负数或幂的通用代数式求值或公式变形。
- 自然数有序数对不等于四象限负坐标；比较大小不等于数轴表示不等式解集。
- 源目标跨越学段时保留小学`extension`与初中`transition`；`direct`可能来自第四学段，不能误写为小学直接要求。


## 8. 数据与统计、概率的学段边界（第十一批）

- **第一学段（1—2年级）**：核心是按特征和标准对物体、图形或数据分类，并用文字、图画或表格记录分类结果；不能把条形图、统计调查、平均数或概率计算整体前移。
- **第二学段（3—4年级）**：明确要求简单数据收集、整理、描述和分析，认识并使用条形统计图，探索平均数意义并解决简单实际问题。条形图是类别数量比较，不等同于连续数据变化趋势。
- **第三学段（5—6年级）**：进一步收集、整理和分析真实问题数据；认识折线图、扇形图，会用条形图和折线图表达数据；理解百分数的统计意义；对简单随机现象列举可能结果，并定性描述可能性大小。认识扇形图不等于必须计算扇形角度；定性可能性不等于数值概率。
- **第四学段（7—9年级）统计**：正式进入简单随机抽样、样本与总体、样本均值估计总体均值、中位数众数、方差、频数直方图、四分位数和箱线图等。节点中MAD、IQR具体算法约定、点图、散点图、相关分析和标准化差异等方法，只有在标准未直接列明时标为相邻拓展，不借用国际年级代码强行认定为中国课标要求。
- **第四学段（7—9年级）概率**：从小学的定性描述走向定量分析；课标明确列出简单随机事件结果、等可能条件、列表和树状图、简单概率计算，以及通过大量重复试验用频率估计概率。小学阶段不要求把概率写成分数或按有利结果数计算。
- **未被明确列出的概率术语**：独立/相依事件、互补事件公式、概率总和为1、0—1刻度、韦恩图和复杂模拟模型，若只与正式内容相邻，应标为adjacent，不能写成课标直接要求。
- **生活活动与数学知识区分**：调查、媒体读图、表格、电子表格和数字模拟可以是承载数学的活动或工具；应按节点实际数学目标判断，不把情境或软件操作自动升级为正式知识要求。

以上映射仍为AI辅助初审；课程标准映射不等同于教材逐册核对、独立教研审核或儿童理解测试。


## 9. 比、比例、百分数与复合量的学段边界（第十二批）

- **第一、第二学段（1—4年级）**：学习数与分数、常见数量关系、单位和测量，为比与比例积累乘法关系、等分和计量经验；2022年版课标没有把正式的“比和比例”主题列为这两个学段的核心要求，不因生活中出现“几份对几份”就提前标为正式比。
- **第三学段（5—6年级）比与比例**：明确要求在实际情境中理解比和比例、理解按比例分配的含义并解决简单问题；学业要求进一步包括判断两个量的比、计算比值、理解比值相同的量。条形模型、带状图、双数轴、比值表等是可选教学表示，不是课标指定的唯一方法。
- **第三学段（5—6年级）正比例**：明确要求认识成正比的量、在方格纸上表示给定数据并了解 y=kx。不要把正比例扩展为所有一次函数，也不要把反比例关系、反比例曲线或更一般的比例函数自动归入小学。
- **第三学段（5—6年级）百分数**：明确要求理解百分数意义、解决简单百分数问题；教学提示列举果汁含量、税率、利息和折扣等情境。简单求一个量的百分之几及真实情境应用有直接依据，但反求原量、连续百分比变化、超过100%的复杂问题不应一概视为明确必学算法。
- **第三学段（5—6年级）比例尺**：明确要求认识比例尺、按给定比例换算图上距离与实际距离，并在方格纸上放大或缩小简单图形。地图比例尺与图形缩放应区分实际距离和图上距离，并先统一单位。
- **第四学段（7—9年级）相似**：课程标准明确图形相似、相似比、相似三角形性质，并指出相似三角形面积比等于相似比的平方。相似图形求边长、由比例图求实际面积可以归入初中衔接；不能把长度比例因子直接用于面积。
- **复合单位与比例推理术语**：速度和单价可由小学常见数量关系作铺垫；密度、单位率、复合单位体系和反比例等，不因出现在上游国际课程节点或生活情境中就认定为中国小学明确要求。2022年版标准未将这些术语全部列为小学独立内容。
