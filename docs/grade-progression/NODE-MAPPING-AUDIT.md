## 本批主要发现

1. 这17个节点均能与第一或第二学段的数与代数内容建立合理联系，但并非每个节点都在课程标准中作为独立知识条目出现。
2. “一一对应”“基数原则”“瞬时识数”“十框分解”等是具体的数学学习概念或教学方法；本轮将其标为概念关联，没有伪装成标准原文。
3. 跳数节点中有些把乘法事实、数位计数和规律探索混在一个目标里，单一学段难以准确概括；目前保留跨学段角色，后续再决定是否需要拆分内容，而不是修改原始节点。
4. 本批没有任何数学关系、源 ID、节点坐标或学习记录被修改。

### 本批发现

1. 中国课程标准第一学段明确要求理解万以内数的意义、数位含义和大小比较。因此，1000以内的读写、排序和位值内容不能仅因上游年龄范围而被推迟到3—4年级。
2. 奇数、偶数在2022年版国家课程标准的第三学段数与运算中明确出现。本节点上游年龄范围较早，但中国课标映射应以国家标准内容为主，年龄只作辅助提示。
3. 两个“英文数词读写”节点没有中国小学数学课程标准对应项，应从数学课程年级分布中排除或另作双语辅助内容；不能悄悄将英语学习目标当作数学内容。
4. “用数位理解运算”“表示100以内的数”等宽泛节点可能覆盖不同复杂度，保留跨阶段角色，不强制唯一归属。

### 本批发现

1. 第一学段的“万以内数”覆盖范围比部分国际课程年龄映射所暗示的更广，1000以内和10000以内的位值内容应归入1—2年级学段基线。
2. 第二学段明确承接“万以上数”和十进制计数；百万级读写、比较和实际应用适合放入3—4年级的宽阶段观察，但不据此指定某一年级。
3. 负数在中国小学课程中并非完全没有出现：第三学段综合与实践明确引入温度、海拔等相反意义的量。但这不意味着小学要求系统学习负数四则运算。
4. 罗马数字读写不属于国家小学数学课程标准的明确要求，标记为拓展内容，不纳入核心年级分布。
5. 舍入和近似数与估算有关，但标准没有逐项规定国际节点中所有舍入精度、误差区间和取整规则。
