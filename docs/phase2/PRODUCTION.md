# 阶段 2 制作方式、实耗与后续估算

2026-10-24。B01 已完成本地内容与技术验证；孩子试用尚未发生。

## 已验证的制作方式

1. 逐一读取源目标与原活动、预期发现、常见误解。先做目标对应，不先复制一个通用题目页。
2. 选择共用数学对象：分割/百格/数轴，三维单位块/拆层/切分，计数/图形/观察记录。任务参数与数学判断写在 `dist/learning/tasks.js`；同一套页面和状态模块承载 12 个节点。
3. 先提供自由试，再改变条件或表示，最后呈现正式名称。目标涉及解释时给出具体提示并保留原话；程序不按字数或点击判断解释成立。
4. 明确正例和反例后检查界面实际操作、首次错误、提示、保存和导入。组件可以复用，目标和反馈必须逐节点核对。

复用了原库 Marble Builder 的先预测、操作、反馈、迁移方法，以及 Hidden Cubes 的计数计划规则和拆层思路；已有本地分割判断也复用。三维渲染、中文表达、任务变式、数据控件和记录扩展为本地适配。两个研究缺口的依据单列在 [RESEARCH.md](RESEARCH.md)，全部目标单列在 [COVERAGE.md](COVERAGE.md)。

## 下一批的规划区间

下表是**粗规划区间，不是已实测工时或交付日期**。计量为同一助手持续实施、内容核对和技术检查的经过时间；不含孩子等待/试用、需求变更、额外素材制作或真实外部调查。依据 B01 已明确的组件复用范围、未验证新教具、缺资料数量与返工项目做工程估计；由于有效工时缺测，不能称为实耗校准后的预测，置信度低。阶段 3 的每日流程独立安排，不包含在内容批次内。
