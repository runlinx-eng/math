# 关系名称与理由核对（v51 历史记录）

**本页是 v51 阶段的历史适配记录，不是当前文字审查的统计权威来源。** 当前 587 节点名称审查以 [机器台账](../language/NODE-NAME-AUDIT.json) 为准；概念解释、关系理由与学习反馈的现状以 [文字表达基准](../language/TERMS.md) 和 [关系审查](../language/RELATIONS-ACTIVITIES-REVIEW.md) 为准。

此目录记录 v51 空间交互使用的本地适配，不改变 `vendor/os-taxonomy/`、`dist/data/atlas.json` 的源节点、源关系或节点 ID。`relation-review.json` 逐条保存来源理由、两端的来源目标、当前显示名称和中文理由的核对状态。

在 v51 适配时，587 个节点中的 130 个属于 44 组重名，均按来源目标添加限定语；当时另修正了四个不够准确的显示名称，包括将“两个两个地数”明确为“按2、5、10跳着数”。这是当时的局部记录，不是当前全量命名结果。2026-11-02 的首轮名称—来源目标审查已覆盖全部 587 个节点：84 个展示名修正（38 个重名节点、46 个非重名节点），92 个重名限定语与 406 个唯一名称暂时保留；详细口径见当前机器台账。

1,223 条源关系均有本地中文说明，逐条绑定来源理由；显示时仍可查看原文。说明依据来源理由和相关数学目标编写，不仅根据两个名称生成。2026-11-02 的后续专项审查已修订其中 44 条理由并增加 39 条防回退断言；其余理由仍未完成全量独立数学教研或儿童理解验收。若后续来源理由变化或出现新边，界面会明确标记待核对并提供原文。此项 v51 适配记录不代表阶段 6 的全部来源目标和实际活动已审计。

有些来源理由只写学段承接，例如 `mt_pyMD_SIiYO > mt_a3dov8CZkq` 和 `mt_a3dov8CZkq > mt_2ESZh70NyS`，本地说明依据两端数学目标描述共同的推理内容，没有把年龄翻译成必须先学的理由。对等可能、概率波动、几何单位及可选方法等容易误解之处保留明确条件。

运行 `node scripts/build_spatial_exploration_inventory.mjs --check` 核对清单与当前数据、名称和已核对理由的一致性。`reviewed` 指本次本地内容对照，不能代替教师审阅、首次使用者验收或儿童学习效果验证。
