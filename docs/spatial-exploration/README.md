# 关系名称与理由核对

此目录记录 v51 空间交互使用的本地适配，不改变 `vendor/os-taxonomy/`、`dist/data/atlas.json` 的源节点、源关系或节点 ID。`relation-review.json` 逐条保存来源理由、两端的来源目标、当前显示名称和中文理由的核对状态。

当前 587 个节点中的 130 个属于 44 组重名，均按来源目标添加限定语；另根据目标和现有活动，修正了四个不够准确的显示名称，包括将“两个两个地数”明确为“按2、5、10跳着数”。源标题和现有活动标题仍保留，原标题仍可用于搜索。

1,223 条源关系均有本地中文说明，逐条绑定来源理由；显示时仍可查看原文。说明依据来源理由和相关数学目标编写，不仅根据两个名称生成。若后续来源理由变化或出现新边，界面会明确标记待核对并提供原文。此项适配不代表阶段 6 的全部来源目标和实际活动已审计。

有些来源理由只写学段承接，例如 `mt_pyMD_SIiYO > mt_a3dov8CZkq` 和 `mt_a3dov8CZkq > mt_2ESZh70NyS`，本地说明依据两端数学目标描述共同的推理内容，没有把年龄翻译成必须先学的理由。对等可能、概率波动、几何单位及可选方法等容易误解之处保留明确条件。

运行 `node scripts/build_spatial_exploration_inventory.mjs --check` 核对清单与当前数据、名称和已核对理由的一致性。`reviewed` 指本次本地内容对照，不能代替教师审阅、首次使用者验收或儿童学习效果验证。
