# 三维空间探索与学习面板视觉方向参考（圆柱星盘 + 学习闭环草案）

> **定位与边界说明**：本文档及配套交互原型 [cylinder-layout-visual-reference.html](./cylinder-layout-visual-reference.html) 仅作为**探索板块（3D 空间排布）与学习板块（固定壳工作台）的视觉与交互方向参考**，使用 587 节点 / 1,223 边的模拟图谱验证构图比例、层级可读性与探索↔学习闭环体验。  
> **真实项目落地红线**：不修改 `vendor/upstream.json`、`dist/data/atlas.json` 的源节点、源关系或节点 ID，也不得凭空间相近、学段顺序或主题分类新增数学前置。正式接入生产代码时，**真实起点判定、引导主干条数（含大主题并列副干）、50 个数学思维节点的挂接语义，以及 P7/P8/P11 既有学习合同与记录格式**，必须严格以真实源数据与现行规则为准。

## 一、五通道正交表达分工（探索底图）

587 个节点与 1,223 条前置联系包含至少 6 维信息，三维空间仅承担 3 个最稳定的结构维度，其余维度交给正交通道，确保信息完整且互不干扰：

| 表达通道 | 负责表达的信息 | 关键设计原则 |
| :--- | :--- | :--- |
| **三维空间坐标 `(Y, θ, R)`** | 认知海拔（前置生长方向）、主题扇区与语义邻域、抽象/枢纽层级 | 坐标只承接不变的宏观结构，确保空间记忆稳定 |
| **连线（Edges）** | 跨距离的精确前置因果与方向 | 全景静默压暗，悬停/选中时按需点亮上游前置链与后继流光 |
| **筛选切面（Filters）** | 主题、学段、学习足迹/问题等离散切片 | **留影不重排（Ghosting）**：未命中节点原位降暗，不坍塌、不重算坐标 |
| **节点本体（色/形/径/环）** | 主题色相、领域球体 vs 思维菱形、枢纽尺寸、动态学习足迹光环 | 将变化的学习证据与不变的空间坐标彻底解耦 |
| **原地展开（In-Place Focus）** | 概念名称标签、前置/后继明细、学习草稿与证据 | 遵循“空间唯一、操作不分层”，高密度信息就地浮现 |

## 二、圆柱星盘 `(Y, θ, R)` 排布参考

1. **`Y` 轴（认知海拔）**：按学段基准带软锚定（1—2 / 3—4 / 5—6 年级），再结合同主题 DAG 最长前置路径深度拉开层次，并对有效前置边执行单调防倒挂松弛（$y_v \ge y_u + \Delta y_{\min}$），保证前置依赖自下而上生长。
2. **`θ` 方位角（5 主题扇区）**：按 5 个主题两两跨主题边权穷举 12 种圆周排列择优（减少穿越圆心的长交叉边），扇区间保留空白走廊，扇区内用重心迭代（Barycenter）使直接关联节点在角度上靠拢。
3. **`R` 半径（抽象与枢纽分层）**：50 个数学思维节点置于中心轴核，与领域概念环之间留出真空隔离带以消除圆心团块；领域概念按对数压缩枢纽度由内脊骨干向外围应用舒展，并随高度微倒锥外扩以容纳更高密度的 5—6 年级概念。
4. **防重叠策略**：采用各向异性圆柱松弛（切向 65% / 径向 30% / 高度 5% 微调），每轮后强制夹紧回各自扇区与径向边界，不破坏宏观结构。
5. **起点与引导主线**：底部中轴设统一出发原点与五条启程根脉；每个主题沿核心脉络绘制柔和发光主干与向上流光，配合精细收细的星点直径，避免 587 点退化为无方向星云。

## 三、学习板块框架参考（三层固定壳 + 四拍统一流程）

1. **前景 / 背景焦点切换（同时解决防抢戏与旁路查前置）**：
   - 学习操作中，右侧学习面板为亮前景，左侧 3D 空间自动叠加暗化 + 轻模糊滤镜（如 `brightness(0.46) blur(2.6px)`）退为沉静背景。
   - 点击左侧 3D 任意区域时，滤镜在 `240ms` 内淡出、3D 立刻切回清晰前景供旋转查看前置节点，右侧学习面板原地半透挂起且不丢失草稿；点回右侧面板瞬间切回学习前景。
2. **三层固定壳**：
   - **顶栏固定壳（Sticky Top）**：知识点标题、学段标签、题序圆点、`留到下次`、单一退出 `×`，以及第二行**四拍统一流程条**。
   - **中间主舞台（Fluid Stage，唯一滚动区，占 70%+ 视口）**：去掉多余静态 H2 标题壳，直给核心问题与数学教具 `#work`；检查反馈卡与发现总结卡**按需显隐**，改动作品时旧反馈立即失效收起。
   - **底部固定行动坞（Sticky Bottom Dock）**：左侧 `☰ 更多` 向上抽屉收纳历史尝试、可选“想一想”与关联前置入口；右侧只保留**唯一高亮主按钮**，绝不掉出首屏。
3. **四拍统一流程状态机**：
   - `① 看清问题`（若有必选猜想则先确认解锁教具）→ `② 动手尝试`（操作就绪点亮「检查我的作品」）→ `③ 检查验证`（展示真实反馈，改动即失效退回 ②）→ `④ 记下发现`（保存发现后同步点亮 3D 节点足迹光环并推进下一题）。

## 四、本地打开交互原型

直接用浏览器打开同目录下的 [cylinder-layout-visual-reference.html](./cylinder-layout-visual-reference.html)（零构建、无外链依赖，离线可用）：
- 拖动旋转、滚轮缩放，点击左侧主题/学段体验留影过滤与右上角 `✦ 回到起点`；
- 点选任意领域节点，点击右下角「开始学习这个概念」打开右侧学习面板，完整走完四拍流程并体验点击左侧 3D 切换前景/背景模糊滤镜。
