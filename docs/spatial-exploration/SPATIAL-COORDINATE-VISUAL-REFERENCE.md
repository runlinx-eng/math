# 三维空间节点排布视觉方向参考（圆柱星盘草案）

> **定位与边界说明**：本文档及配套交互原型 [cylinder-layout-visual-reference.html](./cylinder-layout-visual-reference.html) 仅作为**三维空间视觉与交互方向参考**，使用 587 节点 / 1,223 边的模拟图谱验证构图比例、层级可读性与交互反馈。  
> **真实项目落地红线**：不修改 `vendor/upstream.json`、`dist/data/atlas.json` 的源节点、源关系或节点 ID，也不得凭空间相近、学段顺序或主题分类新增数学前置。正式接入生产代码时，**真实起点判定、引导主干条数（含大主题并列副干）及 50 个数学思维节点的挂接语义**，必须严格以真实知识图谱关系为准。

## 一、五通道正交表达分工

587 个节点与 1,223 条前置联系包含至少 6 维信息，三维空间仅承担 3 个最稳定的结构维度，其余维度交给正交通道，确保信息完整且互不干扰：

| 表达通道 | 负责表达的信息 | 关键设计原则 |
| :--- | :--- | :--- |
| **三维空间坐标 `(Y, θ, R)`** | 认知海拔（前置生长方向）、主题扇区与语义邻域、抽象/枢纽层级 | 坐标只承接不变的宏观结构，确保空间记忆稳定 |
| **连线（Edges）** | 跨距离的精确前置因果与方向 | 全景静默压暗，悬停/选中时按需点亮上游前置链与后继流光 |
| **筛选切面（Filters）** | 主题、学段、学习足迹/问题等离散切片 | **留影不重排（Ghosting）**：未命中节点原位降暗，不坍塌、不重算坐标 |
| **节点本体（色/形/径/环）** | 主题色相、领域球体 vs 思维菱形、枢纽尺寸、动态学习足迹光环 | 将变化的学习证据与不变的空间坐标彻底解耦 |
| **原地展开（In-Place Focus）** | 概念名称标签、前置/后继明细、学习草稿与证据 | 遵循“空间唯一、操作不分层”，高密度信息就地浮现 |

## 二、圆柱星盘 `(Y, θ, R)` 排布参考

1. **`Y` 轴（认知海拔）**：按学段基准带软锚定（1—2 / 3—4 / 5—6 年级），再结合同主题 DAG 最长前置路径深度拉开层次，并对有效前置边执行单调防倒挂松弛（$y_v \ge y_u + \Delta y_{\min}$），保证前置依赖自下而上生长。
2. **`θ` 方位角（5 主题扇区）**：按 5 个主题两两跨主题边权穷举 12 种圆周排列择优（减少穿越圆心的长交叉边），扇区间保留空白走廊，扇区内用重心迭代（Barycenter）使直接关联节点在角度上靠拢。
3. **`R` 半径（抽象与枢纽分层）**：50 个数学思维节点置于中心轴核，与领域概念环之间留出真空隔离带以消除圆心团块；领域概念按对数压缩枢纽度由内脊骨干向外围应用舒展，并随高度微倒锥外扩以容纳更高密度的 5—6 年级概念。
4. **防重叠策略**：采用各向异性圆柱松弛（切向 65% / 径向 30% / 高度 5% 微调），每轮后强制夹紧回各自扇区与径向边界，不破坏宏观结构。

## 三、视觉参考关键要素

- **统一底部总起点**：底部中轴放置可交互的 `✦ 起点 · 数学出发` 锚点，向外延展出 5 条启程根脉接入各主题首站，并提供一键 `✦ 回到起点` 视角。
- **引导主线光带**：每个主题沿核心脉络绘制柔和发光主干与缓慢向上的行进光点，分支概念向两侧舒展，避免 587 个点退化为无方向星云。
- **精细星点比例**：整体收敛节点直径与外环光晕，突出主干骨架与选中时的上下游前置链。

## 四、本地打开视觉参考

直接用浏览器打开同目录下的 [cylinder-layout-visual-reference.html](./cylinder-layout-visual-reference.html)（零构建、无外链依赖，离线可用）：
- 拖动旋转、滚轮缩放；
- 点击左侧主题/学段体验留影过滤；
- 悬停预览 1 跳前置与后继，点击锁定完整上游前置链；
- 点击右上角 `✦ 回到起点` 聚焦底部总起点，或切换对比圆柱星盘与模拟力导向团块。
