# 阶段 4 的资料适配与补充

这是本地活动设计依据，不是本产品的效果研究。已有研究逐项见 source-review.json 的原始 JSON 指针；沿用先操作、换条件、解释及诊断错误的结构。未改动上游数据。以下七项是本轮新增 38 个节点中的研究缺口，均已补充本地活动依据；加上阶段 2 的两项，首批 50 个节点的九项缺口已处理。技术验证与孩子试用另列。

| 源节点 | 补充设计与依据 | 完成所能说明的范围 |
| --- | --- | --- |
| mt_NSC3LT_-ch 容量 | 先估、用标准量逐份装满，再区分容量和当前水量。[MathsHub 测量规划](https://www.mathematicshub.edu.au/planning-tool/3/measurement/metric-units-and-using-instruments/)支持估计与测量、单位及工具的联系。 | 屏幕模型操作；不代表会使用真实量杯。估计不要求恰好正确。 |
| mt_gC-6JXAG5S 二、四、八等份 | [Open University 折纸](https://www.open.edu/openlearn/mod/oucontent/view.php?id=115996&section=1.1)展示折叠细分而涂色总量不变；本地将连续对折延伸到八份，并增加圆与方形的迁移。 | 折痕模拟、涂色与等量对应；真实折纸尚待实际操作。 |
| mt_iykH2P5oFq 统计问题 | [ASA GAISE II](https://www.amstat.org/docs/default-source/amstat-documents/gaiseiiprek-12_full.pdf)正文第 14–15 页强调可由数据回答且预期存在变异；活动构造对象、属性和不同回答。 | 能构造预设情境中的问题；自由表述保留但不自动判懂。个人跨多天的变化也可构成统计问题，不能只按“问几个人”判断。 |
| mt_QpJydot2Kh 按目的选图 | 同一份运动偏好记录由表格换成条形，保持类别与数量；分别查准确人数与比较差距。依据同上正文第 25–27 页的频数表、图及解释。 | 对这份资料的表示保持与用途比较；不宣称唯一画法或泛化的图表判断能力。 |
| mt_8DT3LXwwH- 数字模拟 | 同上正文第 11、80–81 页关于重复模拟、记录比例与波动。本地改编为骰子 10／100／1000 次各五轮，绘制实际比例，并明确更多次不保证每一轮更接近。 | 观察模拟和给定反例；不自动证明理解概率极限。所有数值来自带种子的伪随机序列，可复算；不调整结果以制造规律。 |
| mt_ZjIFGc6zPW 重复单元 | [NCETM Pattern](https://www.ncetm.org.uk/classroom-resources/ey-pattern/)以识别重复单元、延伸、改变材料保持结构为基础。制作 ABB、1223 与动作到形状的转换。 | 对所做结构的构造与迁移；不以颜色记忆代替单元辨认。 |
| mt_W3VOAuFwVw 增长规律 | 同一 NCETM 资料包含逐次增长与预测；本地改编为固定增加、减少及积木塔。 | 观察给定规则与构造后续；有限项可有多个延伸，活动明确采用固定步长，不把一个例子当唯一数学规律。 |
