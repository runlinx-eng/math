# 数学探索：结构、活动与证据

2026-10-24，三维空间简洁进度版 v6。本文件区分已经实现的框架与新增待实现需求，不把设计意图当作教学效果。

## 从目标到实现

学习由“想弄明白的问题”进入，使用知识关系寻找基础或延伸。年龄、年级和课程标准保留在上游资料中用于追溯，不参与本地分类或解锁。入口显示五个主题区域，每个主题有 3–6 个知识簇，默认先保留这些选择；样板区域只显露三个编号问题，其他叶节点可从查找或主动展开全体知识进入。它们在同一三维坐标系中，不再逐层切换页面。没有先做定位试卷的必要流程，没有家长入口。

“验证是否学会”依然需要任务与证据，动手界面本身不会自动比传统课堂有效。本版增加的是：能自由改变的数学对象、可保存的构造作品、跨表示的尝试、可回看的解释，以及对“已完成”和“有证据”的区分。探索、构造和解释在传统教育中也可能出现；此处不声称这些方法是开源项目独有的发明。

## 每天的学习体验：新增需求，尚未实现

用户补充：「每天点亮几个知识点，打通连接，如果出现新问题就是明天的起点」。

目标是形成连续的个人学习经历：每天点亮少量知识点，逐渐连起相关想法；
学习中出现的新问题可以留下，成为第二天继续的入口。全景让孩子看见自己
逐渐连起来的知识，继续学习时能回到问题所在的位置和现场。

这一需求继续使用完成／未完成和简洁进度。当前 v6 已有节点完成记录和
现场恢复，但尚未实现个人连接的打通记录、新问题留存及次日从问题继续。
点亮与打通的具体触发条件、提问方式和入口呈现仍需设计，不视为已完成。

## 分类与关系

| 本地主题 | 探索包 |
| --- | --- |
| 数与运算 | 数的样子与大小；合起来与拿走；成组与平均分；一份与同一个量；分数也能运算；放大、缩小与比例 |
| 图形与空间 | 形状有什么共同点；位置与变换；转弯与角；从平面到立体 |
| 测量与变化 | 用单位比较；边界与铺满；装得下多少；时间怎样走；钱与选择 |
| 规律与推理 | 寻找与创造规律；相等与未知数；一起变化的量；把想法说清楚 |
| 数据与可能性 | 问问题与收集；把数据画出来；比较与推断；可能与不一定 |

每个原始节点有一个导航主归属，原始 ID、领域、定义、证据目标和全部数学关系保持不变。跨主题能力可通过原有关系在不同地方出现。涉及多个概念的节点仍保持原有整体，例如“面积与体积公式”以面积包为主归属；没有为了凑数量复制知识点。

`build_atlas.py` 依概念名称、原始领域和必要的具体 ID 规则分类；`classification-audit.json` 记录全部 587 项的理由。汇总连线只来自原始叶节点关系，保留原边、强弱和理由。包之间可能互相连接，不表示包级先修图必须无环，也不构成强制学习顺序。

全貌保留未探索区域；按需展开具体知识与关系，选中对象不会自动铺开全部箭头。每个知识点可以单独查看原始前置与后续。查看原始定义时保留英文，尚未为所有节点编写中文讲义。

## 连续空间的实现边界

三维空间是持续存在的导航和工作环境：五个主题、23 个簇、587 个叶节点都有固定位置；主动展开全部知识后，缩放改变可见的标签密度；旋转和平移改变观察位置，原图的基础与延伸关系可以跨区域显示。查找与连线可以直接带到对象，无需逐层进入。

主题和簇的坐标为本地布局，簇间及簇内的真实连接会产生小幅、确定性的靠拢。同一数据版本重新打开位置不变，使用状态也不会让对象移动。空间距离与大小帮助辨认位置，不代表难度、年级、先修程度或能力。连线表达具体关系，原始方向、强弱和理由保留。

路线 A 直接展开一个操作现场，关系与记录按需展开。旧活动仍作为挂在对象旁边的工作面展开，最多同时保留两个。镜头移动时工作面跟随世界锚点，远离时收成标题；“定位”或“并排看”可重新摆到合适的视角。视角、工作面和学习记录分别保存。当前工作面本身面向屏幕保持可读，已有活动仍是纸带、数轴、网格等平面表达；没有把全部概念制作成三维教具。

全貌用一条进度条和完成数量汇总已有任务；任务和路线入口只显示完成／未完成，A–02 内用三个步骤和勾选呈现进展。总量是已有任务的三个不同节点，预览和未制作内容不计入。同节点的新旧活动只计一次；完成 A–01 的短任务也只代表这次活动完成。浏览、尝试、提示与独立证据继续保存，但不作为主界面的状态或图例。尚未完成的区域仍保留。三维操作本身不是学习证据，空间导航是否帮助孩子理解关系，仍须实际使用观察。

## 路线 A：先体验，后命名

路线是本地教学建议，不是原项目给出的课程编号，不设锁定。入口为「分一份，换个名字」，对应原有 `same-amount` 知识簇。没有修改其主归属、对象坐标或原始边。

| 编号 | 孩子看到的问题 | 来源与当前范围 |
| --- | --- | --- |
| A–01 | 先分得一样大 | `mt_ndGqFPWyen`；先操作两份大小。原有完整平均分活动另行保留。 |
| A–02 | 分细了，会变多吗？ | `mt_Ep7TDFuYUa`；同大的巧克力分细，观察所取总量；换到上下同粗且等高分格的果汁杯，自己倒半杯；最后呈现正式名称和定义。 |
| A–03 | 半杯，还能怎样记？ | `mt_DRlbMok2lT`；半杯与 0.5 的简单预览，不声称已完成该节点的活动。它与原有 decimal 活动的节点 `mt_TqDq6jyOmL` 不同。 |

两条示范箭头分别对应原图 `mt_ndGqFPWyen → mt_Ep7TDFuYUa`（hard）及 `mt_Ep7TDFuYUa → mt_DRlbMok2lT`（soft）。显示时用「先分得一样大，才方便数份比较」「同样的量还能换个写法」解释用途；强弱和英文理由仍留在原始数据中。建议序号不是新的先修关系。

A–02 操作阶段使用生活用语；总结先回顾量不变，再给出等值分数、分子分母与分数基本性质。杯子与巧克力构成不同的表现情境，但这仍是有即时反馈、提示充分的短样板，不能据此证明独立理解或长期保持。

样板数据进入原有备份的可选 `journeys.portions`，不替换原活动证据。首次杯子尝试与后续修改分别保留，重试标记反馈暴露。解释草稿自动保存；正式笔记始终待确认。A–02 只有实际再分过、提交过杯子尝试并进入总结后才完成，错误尝试同样保留。A–01 把切口移到中点并点击「完成，继续」后记录完成，加入可选字段 `fairFinishedAt`；旧备份缺省为空，合并保留已完成时间。两种完成均不自动授予独立操作证据。A–03 仍为预览，操作不产生完成记录。

## 上游能力与本地适配

固定来源是 `vendor/upstream.json` 中的上游提交。数学子图包含 587 节点、1,223 内部关系和 32 条其他学科前置参考。502 个数学节点有教学研究，85 个没有；已将研究覆盖、活动条数、诊断方法、误解条数编入索引，但并未把 502 份研究自动制作成课程。

三个样板的完整记录来自 `vendor/os-taxonomy/data/teaching-research.json`，同时保存在 `dist/data/atlas.json` 的 `focusResearch`：

| 原始节点 | 从研究中采用的设计 | 本地实现与诊断 |
| --- | --- | --- |
| `mt_ndGqFPWyen` 分数的意义 | “Cut it fair, then count the unit”；强调平均分、单位份和同一整体 | 孩子亲自移动不均匀切口，再选份数；在 12 或 15 个物体组成的新整体中构造相应数量。区分只数块、未平均分、误把分子当物体数。 |
| `mt_Ep7TDFuYUa` 等值分数 | 再分割保持同一点；与分子分母各加一作对照；原诊断方法 `interpret_translate` | 自由操作纸带和对齐数轴；构造三个不同分母的等值分数；换成不同刻度的数轴验证。所有整体保持同样长度。 |
| `mt_TqDq6jyOmL` 分数与小数 | 百分格同时命名；位值和占位零；原诊断方法 `two_tier` | 自由涂色、构造 0.35 / 0.42，再把 6/100 与 6/10（或 9/100 与 9/10）放在同单位数轴。区分十分与百分的位置。 |

本版参考研究方向并重新实现，没有照搬其全部活动或评估方案。原研究中的完整两层诊断没有直接上线：解释作为独立、未评定的记录保存。涉及不同整体大小、同分子比较和长期保持的目标，不能由这三个活动的成功推断已经掌握。

重新核对的外部依据：

- [IES / WWC《Developing Effective Fractions Instruction for Kindergarten Through 8th Grade》](https://ies.ed.gov/ncee/wwc/docs/practiceguide/fractions_pg_093010.pdf)，建议 1–2：从分享与比例直觉建立分数；将分数视为数，使用数轴。等值数轴示例及 Roadblock 2.3 支持跨刻度表示的设计。
- [Mathematics Developmental Continuum：Comparing Decimal Numbers](https://smartvic.com/teacher/mdc/number/N40001P.html)：小数比较中的位值和整数类比误解。这里只采用其关于位值辨别的提醒，没有部署该资料的完整诊断分类。

上游研究由代理整理；其 `verified` 字段不是本地验收结论。上面两份资料在本次制作中实际查阅，但资料支持教学思路，不证明本软件有效。英格兰等课程标准没有用于安排孩子的路线。

## 记录中的学习证据模型

以下维度用于保存和回看过程，不作为孩子在主界面必须辨认的状态。导航与任务进度只使用完成／未完成。

自由探索可以随时改变参数、看即时现象、保存快照。没有强制打分，也不算独立验证。构造和迁移案例则先记录作品，再显示反馈；记录包含切口、选取对象、分子分母或数轴位置，而不只存一个分数。

| 维度 | 当前规则 | 不代表什么 |
| --- | --- | --- |
| 浏览 | 打开节点的关系 | 没有证明做过或理解 |
| 探索 | 进入活动、保存操作现场和观察 | 自由操作不算独立验证 |
| 活动完成 | 旧活动构造与迁移各至少提交一份作品；路线 A 按上节的体验完成条件 | 错误作品也可能已完成，不能等同学会 |
| 独立操作证据 | 相应案例首次提交成立，未使用提示或看反馈，最近提交仍成立 | 不足以证明整体概念、解释、保持或全包掌握 |
| 有支持的尝试 | 曾用提示、首次不成立或后续出现矛盾 | 保留具体过程，不是能力标签 |
| 自己的解释 | 保存多份文本版本，状态保持待确认 | 不用文字长度或提交按钮自动评分 |

每种构造与迁移各有两套固定案例。每类以最近提交的案例显示摘要，所有旧案例和尝试保留。使用过提示的案例按有支持处理，包括合并导入的提示记录；切换案例不会重置旧案例首次暴露。记录构成可回看的证据，不是防作弊的认证系统。

解释允许不写，可以先做、先口述给自己听，后来补充。当前不采集音频、视频，不连接 AI 评分，也不把未确认的解释交给必须出现的家长入口。将来如增加解释确认机制，需要独立设计并验证，不能靠一个“我会了”按钮替代。

程序建议已有独立构造和迁移证据后七天再访，其余有作品的情况次日再访。它们是初始产品规则，不是经验证的个体化记忆模型。历史操作证据不会被包装为永久“已掌握”。

## 当前交付边界及孩子试用

一个样板包内保留三个原有完整活动，新增路线 A 的简化入口与 A–02 操作流程；A–03 是另一个原始节点的简单预览。地图仍覆盖 587 个数学节点，其余节点尚无完整互动课。完成 A–02 体验只计本节点的活动进度，不点亮整个包或下游知识，也不增加独立理解证据。

技术验证能确认数学规则、操作、记录和恢复按设计工作。孩子试用仍需观察：能否不经解释找到想去的地方；能否从现象提出自己的问题；改变整体或表示后是否仍理解；能否用自己的作品说明原因。尚未获得这些实际结果，不宣称学习效果或用户验收完成。
