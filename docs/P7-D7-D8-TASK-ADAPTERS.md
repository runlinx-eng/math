# P7-D7/D8｜原生任务交互合同与第一轮学习界面优化

> Issue #34，关联 #30。堆叠 Draft PR #58，基于尚未合并的 D6 PR #57。**工程实现与待验收记录；不能代替 Mac、儿童或数学教研验证。** 不合并、不部署。

## 1. 实际任务覆盖口径

`node scripts/build_p7_d3_inventory.mjs` 和 `node scripts/build_p7_d7_coverage.mjs` 每次从当前仓库真实 `TASKS`、`BRIDGES` 和 `atlas` 重建任务清单。历史目标数 1,996 个节点题、776 条真实知识关系上的双任务桥（合计 1,552 联合子题）、587 个知识及思维来源节点，只能在 CI 执行生成器之后视为本次核对的数量；**任务条目不等于已逐题验收。**

生成 `verification/p7-d7/coverage.json`，逐类型列出数学操作族、实例数量、就绪规则是否明确，以及所有保留原规则的未适配类型。D3 的 603 条遗留或待归类能力仍保留，既没有擅自移除，也不声称已经等效迁移。

本轮明确的 12 个模型就绪适配类型：`x-wideshift`、`x-pvshift`、`x-parityjoin`、`x-r38-chain`、`x-r38-counterexample`、`x-g27-build`、`x-g27-net`、`x-g27-sort`、`x-g27-face`、`x-g27-cut`、`x-r37-pair`、`x-r37-shape`。其余类型使用原检查入口安全回退；不能用非空文本、任意一次点击等虚构“已完成作品”。

所有原始 `inspect`、`currentSubmission`、任务及关系 ID、存储/旧备份格式、3D 坐标/相机行为保持不变。

## 2. 共用状态合同与 D8 变化

- 所有任务使用唯一四区结构：当前问题 → 数学操作与作品 → 检查与反馈 → 发现与继续。不产生题型专属页面。
- 由模型已经发生的真实操作决定主要焦点：未留下猜想时突出原猜想按钮；需要构造或实验时先留在教具；已有对应当前作品的操作记录则允许共用检查。
- `revise` 与 `recheck` 保留实际当前作品与旧检查快照的区别；`passed` 和 `reflect` 仍按现有路线继续或保存。
- 等值分数纸带增补 `aria-pressed`、点击说明、键盘焦点环和指针/悬浮/已选状态；改变份数后即时同步状态。
- 当前问题与教具区在字号、宽度和间距上建立独立层级；保留 P8 的紧凑主按钮位置。缩窄视口调整纸带，避免拉伸整页。
- 来源、应用、联合任务、草稿和历史仍按原路径按需访问，未以视觉精简删除功能。

## 3. 浏览器样本与验收证据

新脚本 `tests/p7-d7-multi-type-browser.cjs` 按三种视口（1440×900、1280×720、600×800）抽查五种不同数学机制：

| 实例 | 原生任务机制 | 预期验证路径 |
| --- | --- | --- |
| `equivalent` | 三条分数纸带直接构造 | 初次、故意错误、点击修改、重检前恢复、通过、下一题 |
| `shiftfine` | `3.456×100` 数位猜想与操作 | 猜想、两次移动、错误结果、修订、通过、下一题 |
| `solidstack` | 几何搭建与旋转 | 操作前禁检查、错误组合、修改积木、通过、下一题 |
| `argument38` | 原生推理卡论证 | 空推理不能检查、错误链、撤回修正、通过、下一题 |
| `link-equivalent-quarters` | 真实来源关系上的双任务 | 纸带→百格，错误、修正、通过、总结、刷新恢复 |

截图与机器可读结果保存到 CI artifact 中的 `verification/p7-d7/`。没有得到当次全部 required/overview CI 绿灯和截图时不得标记合并准备完成。反例 `x-r38-counterexample` 先由 Node 原模型测试覆盖；完整前台操作留在 D9 专项浏览器回归。

## 4. 仍待 D8/D9 的问题

1. 补齐 `coverage.json` 标为“沿用原检查路径”的任务类型，优先检查旧自由操作、实验、反例以及多步数值记录，不允许把全部非空输入视为可以检查。
2. 扩充更多真实数学题而非只有五个代表实例，尤其检查检查失败→修改→复检是否可能被老界面状态遮挡。
3. 用 Mac 实机 100% 缩放、嵌入式 3D 面板、长题双滚动、触控和键盘逐任务验收；截图只是自动浏览器证据。
4. 对旧自由练习 `models[-1]`、历史、首次错误、草稿、提示、离线、导入/导出、备份冲突、3D 相机保持分别验收。
5. 儿童独立学习与数学教研需另行建立观察证据，不由 CI 或任务数量代替。
