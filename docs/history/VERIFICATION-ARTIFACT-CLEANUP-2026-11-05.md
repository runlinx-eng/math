# 历史验证产物清理范围（2026-11-05）

本分支只减少 Git 工作树中的历史验证产物；课程源数据、现行自动测试、学习记录与产品运行文件不在清理范围。

- 从 `verification/` 解除跟踪 2,455 个 PNG、JPG、AIFF、TAP、JSON、TXT 等可再生成或仅供历史阶段验收的产物。历史提交保留，可由 Git 历史读取，但不会在新检出目录中自动出现。
- 移除 26 个 `scripts/build_b14_verification.mjs` 至 `scripts/build_b39_verification.mjs`：它们是旧批次报告汇总器，直接读取上述已移除的验证日志、截图索引和阶段性 JSON，无法在清理后的工作树正常执行；它们不属于现行 CI 或产品构建。
- 移除 `verification/` 内 5 个旧临时 Playwright runner（含机器绝对路径和历史服务假设），避免保留不可移植的活跃脚本。
- 保留 `verification/` 中 8 份历史说明/审查 Markdown 和 1 份版式对比 SVG；现行 `tests/` 与现行 `scripts/verify_spatial_*.cjs` 继续保留，并在运行时自行创建验证输出目录。
- 历史执行脚本、验证结果与来源信息仍能在清理前 Git 提交中追溯；若要原样重跑某一历史批次，应检出当时完整快照，而不是在当前分支运行已经过时的脚本。
- `.gitignore` 防止上述生成文件再次被意外纳入 Git；忽略规则不能自动清除本地已有文件，也不减小 Git 历史大小。

验收标准：新工作树没有悬空的旧报告汇总器；现行 CI 通过；组合版本另行在隔离验证分支运行浏览器回归。该清理 PR 保持 Draft，不单独合并或触发线上部署。
