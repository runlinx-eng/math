## 两种状态，统一边界

**同一张三维数学空间**：全景 → 用户手动缩放/平移/旋转 → 选中知识点 → 看基础/看后续/完整关系 →「认识这张图」及其五步 → 返回全景，均是同一个空间，操作规则一致。

- 537 个有空间位置的领域节点始终保留在同一组固定 XYZ 中；选中、过滤与导览**不能从底图删除不相关节点**。其他节点和真实背景关系以低亮度、浅色的半透明视觉效果退到背景；当前、已走过的节点及源关系逐级突出。标签可按屏幕密度隐藏，但不是删除知识或伪造关系。
- 选中屏幕内已可见的知识点，只更新高亮、关系及详情，**不自动改变镜头位置、方向、缩放或旋转中心**。沿相邻知识连续探索、切换关系方向/深度、进入和切换导览步骤同理。确实处于视口外的搜索结果允许仅作必要平移，不自动放大。
- 用户在全景、选中知识和导览时均可手动缩放、平移、旋转。**不得再以“知识详情模式”为理由隐藏 +/−、禁用滚轮或改成只许平移的独立地图。**
- 关系过滤只是**强调范围**：一跳包含真实关键和辅助直接关联；多跳沿真实关键前置关系扩展；所有源边仍可追溯。它不会强制改变地图视角或清空未高亮的 537 点背景。
- **直接关系列表默认展开**：点选知识点立即显示「这里会用到／还会连到哪里」及真实直接关系；长列表可在详情卡内滚动，也能主动折叠。关系高亮层级与完整直接关系列表互不替代。
- **「认识这张图」是地图内行动引导**：第一步只展示五大主题并突出入口，随后通过点击真实知识节点观察第一条联系、分叉、汇合，最后由用户选择真实相邻节点开始自由探索。左上保留短提示与进度，地图目标附近提供短操作提示；不能再恢复长篇说明卡或无条件「下一页」。非目标知识群名称默认不展开，但 537 点背景与五大主题空间仍可辨认。进入与步骤推进不自动移动镜头，导航提示不得伪装成数学前置边；导览状态不等于学习成果。

左侧原观察控件在真实学习运行时默认缩成一个可展开入口，明确点击后原有学段、主题、关系筛选及导览原样可用；在展开原控件时隐藏当前知识文字定位，防止两个浮层重叠。文字定位里的「聚焦这处知识」是明确的用户镜头操作，不得在打开任务、切换学习/足迹、刷新、恢复草稿或仅选中节点时自动执行。小于等于 800px 的覆盖式学习面不显示该浮层，回到探索/足迹自动还原观察工具与地图布局。空间数据、原始 1,223 条来源关系、节点 XYZ、知识选择、判题、存储和备份格式均不变。

技术验收：`tests/p6b-layout-browser.cjs` 验证源边方向真实性、浮层对 3D 画布边界的避让、工具展开恢复、相机不变、切足迹隐去、五种视口；浏览器截图必须进一步检查节点遮挡、键盘可达性和真实学习是否清晰。仍需 Mac 人工与儿童独立使用验收；工程合并不能替代这些证据。

## P8 三模式共享节点合同（2026-11-10，PR #60）

- 探索、学习、足迹是单一 3D 知识图上的**持续任务模式**。只有顶部模式导航、明确退出操作或浏览器历史恢复才改变模式；URL 是模式历史的序列化，不从当前面板可见性反推模式。单击/连续选择地图标签、Canvas 节点、搜索结果或足迹中的节点链接，均沿当前模式解释同一个源节点 ID。
- 探索显示当前知识的真实解释与直接关系。学习打开当前节点实际配置的数学任务（含既有早期任务入口），无任务时明确说明不可用；其他节点的历史课程不得覆盖当前明确选择。足迹显示该节点已存的真实尝试、进度、草稿与记录；纯查看足迹不能变成“已学”或写入浏览证据。
- 从探索知识详情明确进入学习时，模式必须同时更新；随后再次点击任意节点仍是学习。任务在学习/足迹/探索切换时可暂停或恢复，同一节点未经更换时不得无故重载或丢弃作品；切换到另一节点才关闭旧任务现场，而不能删除保存记录。
- 足迹普通节点选择只更新当前节点标题及摘要，不应读写、克隆、重新校验和刷新全部学习状态；记录实质更新、导入和恢复仍需走原来的有效校验流程。原有历史 iframe 与备份/离线入口保持可达。
- 真实 DOM 标签/Canvas 点击回归、桌面与窄屏截图、Chromium 时间测量以及 Required/Overview Checks 是工程验收依据。Mac 人工手感、儿童独立使用与数学教研仍需独立验收。


## P11 R2｜知识详情与足迹的唯一主操作（2026-11-12，第二批）

- 在探索模式，点击真实知识节点才选择上下文。节点详情固定一个主按钮：真实原生课程未有未完成记录时显示「开始学习」，有该课程的未完成模型、尝试或文字草稿时显示「继续学习」；没有原生课程时显示「查看联系」，不伪装成可以开始课程。收藏、旧活动、联系、相机聚焦仍是可找到的次要能力，不等同也不能随意删除。
- 在足迹模式，当前节点的学习按钮携带该节点实际原生 session ID。不能仅切换顶部「学习」而误恢复另一个此前暂停的课程；多个课程各自的尝试与模型仍按原记录保持。纯访问、收藏、完成状态都不能冒充未完任务。
- 顶部「探索／学习／足迹」切换暂时暂停现有学习 iframe；明确「返回知识空间」则关闭当前工作面。内嵌课程已有外层固定返回入口，内层头部返回收纳；独立课程的内层返回保留。尚未证明等效的早期活动/浏览器历史退出不强行合并。
- 入口迁移需要真实 3D 点击、五视口 Chromium 截图、Tab/Enter/触控、P10 草稿与备份/离线/升级兼容检查。工程检查不是 Mac/儿童独立验收；不改节点坐标、1,223 条来源关系、判题、学习 Schema 或 VPS 部署。

## P11 R3｜跨工作区的焦点与主操作（2026-11-12）

- 同一已选知识的详情在收藏、进度或关联信息刷新时，应保留键盘焦点在对应按钮，不能因为重建详情 DOM 把 Tab/Enter 用户丢回页面起点；切换为另一知识时不得沿用旧节点焦点。
- 地图节点悬停是弱预览；真实选中的当前操作节点仍是唯一强标记。不能通过悬停打开额外操作群或改变学习任务。
- 足迹中的指定课程「开始／继续学习」是首要操作，应有明显主按钮外观和触控可点击面积。触控导航、详情主操作与工作区关闭入口至少保留 44px 高度；此前课程的 session ID、尝试及草稿保持原义。
- 五种视口对探索／学习／足迹各自留图，浏览器内核的可点击性与布局检测是工程验收，不等同儿童独立体验、Mac 实机视觉认可或 VPS 部署。
