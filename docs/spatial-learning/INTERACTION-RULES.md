# 数学树当前交互基准（v53 空间 / v58 界面）

2026-11-02。适用于 `feat/structure-guide-readability-v1` 的当前交互；**不是孩子使用效果的验收结论**。本页是后续 Codex 修改 v53 三维地图、知识详情、结构导览、学习工作区时的**现行规则**。既有 v49、v50、v54、v55 记录仍可作为历史证据，但与本页冲突的旧交互方案不再作为执行要求。参见 [导览与修改沿革](GUIDE.md)。

## 两种状态，统一边界

**同一张三维数学空间**：全景 → 用户手动缩放/平移/旋转 → 选中知识点 → 看基础/看后续/完整关系 →「认识这张图」及其五步 → 返回全景，均是同一个空间，操作规则一致。

- 537 个有空间位置的领域节点始终保留在同一组固定 XYZ 中；选中、过滤与导览**不能从底图删除不相关节点**。其他节点和真实背景关系以低亮度、浅色的半透明视觉效果退到背景；当前、已走过的节点及源关系逐级突出。标签可按屏幕密度隐藏，但不是删除知识或伪造关系。
- 选中屏幕内已可见的知识点，只更新高亮、关系及详情，**不自动改变镜头位置、方向、缩放或旋转中心**。沿相邻知识连续探索、切换关系方向/深度、进入和切换导览步骤同理。确实处于视口外的搜索结果允许仅作必要平移，不自动放大。
- 用户在全景、选中知识和导览时均可手动缩放、平移、旋转。**不得再以“知识详情模式”为理由隐藏 +/−、禁用滚轮或改成只许平移的独立地图。**
- 关系过滤只是**强调范围**：一跳包含真实关键和辅助直接关联；多跳沿真实关键前置关系扩展；所有源边仍可追溯。它不会强制改变地图视角或清空未高亮的 537 点背景。
- **直接关系列表默认展开**：点选知识点立即显示「这里会用到／还会连到哪里」及真实直接关系；长列表可在详情卡内滚动，也能主动折叠。关系高亮层级与完整直接关系列表互不替代。
- **「认识这张图」是地图内行动引导**：第一步只展示五大主题并突出入口，随后通过点击真实知识节点观察第一条联系、分叉、汇合，最后由用户选择真实相邻节点开始自由探索。左上保留短提示与进度，地图目标附近提供短操作提示；不能再恢复长篇说明卡或无条件「下一页」。非目标知识群名称默认不展开，但 537 点背景与五大主题空间仍可辨认。进入与步骤推进不自动移动镜头，导航提示不得伪装成数学前置边；导览状态不等于学习成果。

- **导览权限与悬停（v59）**：沿用全貌的同一套节点、标签、手势和相机。导览期间全部 537 个领域知识点保留空间位置；背景与已经观察过的节点可以悬停查看名称（不扩展其他真实关系、不改变当前任务），但不允许通过点击、双击、查找等入口打开非任务知识；只有当前步骤明确指定的真实目标可点击推进。已实际点击过的才显示已观察状态，当前所在和待点击目标分别突出。退出导览后立即解除全部标签锁定，恢复全貌的自由选择、悬停和双击。始终允许返回上一步、退出和手动调整视角。
- **五步的视觉层级（v58）**：整张知识森林始终可见；主题名称以轻量地标表达；当前真实连线与端点比历史联系更清楚；地图操作提示采用浅底小标签、完整真实知识名称及独立动作文字，互相避让并避免遮挡主题标题；浅色虚线只用于把操作提示指回原节点，不能充当数学关系。左上卡保留标题、目的、动态状态、5步进度和原有返回／动手／退出操作，只优化字重、空间与主次顺序。不为美化更改节点位置、数学来源关系、步骤语义或镜头。
- 「返回全貌／取消选中」取消高亮，保留用户当前手动镜头；**不等于归位**。用户明确点击「归位」才对完整数学图重新取景，点顶视/侧视/立体总览才切换指定视角；普通选中不能偷偷调用这些操作。
- 缩放具有根据完整知识图尺寸计算的可用边界，防止无限缩远而迷路；只有**页面启动恢复保存的镜头**时，检测到极端不可读的投影才允许自动恢复。不能在选择知识、导览或切换过滤时触发该补救。旋转保留稳定观察目标，不能随点击换轴。
- 知识详情卡应位于浏览器可见安全区域，不被左侧侧边栏遮挡；必须允许长内容独立滚动。

**进入实际学习活动**（「开始学习／动手试试」）才打开独立的学习面板：

- 面板与三维镜头隔离，打开和退出不移动或放大后台地图；退出回到原知识、原镜头，若来自导览则返回原步骤。
- 学习面板位置稳定，高度由题目实际内容测量并受可用视口约束。内容短则收缩，内容长则在活动区域内部滚动；最后一个操作和返回入口必须可到达，不得被固定高度截断。
- 学习时隐藏地图工具；这条规则**不适用于**数学空间中的知识详情卡。浏览、预览、导览不自动记为学习完成；实际活动与联合任务依据既有有效提交记录。

## 五个主题入口（同一张地图）

2026-11-02 起，三级悬停均遵循**当前目标始终可见，次级内容只辅助预览**的规则。悬停地图中的五大主题时，原主题标题**仍在鼠标所在处显示并高亮**，不透明消失、不挪动命中区域；同一主题的彩色节点与多个真实知识群次标题暂时显现，已有的屏幕标签避让保证主次标题不遮挡，左上角对应主题同步高亮。悬停左上角主题入口时也可预览其真实知识群。悬停知识群时强调该群的真实节点并标明所属主题；悬停领域知识节点时，当前标签最醒目，真实直接前置与后续标签次之，沿来源关系显示橙色前置与蓝色后续。所有悬停不弹详情卡、不改变持久选中、URL、学习状态、空间坐标或镜头，鼠标移开恢复原状。**点击**才进入对应层级的详情。触屏直接点击；其他主题的领域节点继续以淡色背景保留，地图不会另建知识树或伪造关联。

主题详情默认展示**来源中的主题说明、真实知识群名称、各群问题及节点数量**，用户可从任意知识群继续，不宣称这是一条规定课程顺序。数与运算有 6 群，图形与空间 4 群，测量与变化 5 群，规律与推理 4 群，数据与可能性 4 群，共 23 群。537 个有空间坐标的领域节点继续留在地图；50 个无常驻空间球的数学思维节点按所属知识群标注为「学习中」，不为了显示主题而强加坐标。知识群按钮只沿真实 pack ID 导航，不因此创建前置关系、学习完成记录或新的课程路线。

点击知识群后可用「上一处」返回主题，主动「全貌」取消选中并保留当前镜头。**主题 → 知识群**的切换同样必须原地完成，不得通过 `fitGlobalView` 或其他自动取景移动镜头、修改缩放或旋转目标；只有用户主动拖动、缩放和选择「归位／顶视／侧视／立体总览」才改变视角。点击知识群后，地图中只优先显示本群真实领域节点的名称（为可读性限制同屏数量，放大后可显示更多），537 个领域知识点和源关系数据仍在原位置、其他群只作为淡背景存在。左上角标明当前知识群及所属主题，详情保留该群的完整学习入口。**不能因为旧版 zoom 标签阈值在点击知识群后把全图节点名称同时展开。**

## 现有回归与验收界限

| 用户行为 | 必须观察到 | 主要浏览器回归 |
| --- | --- | --- |
| 地图悬停主题 → 多个知识群标签 → 移开 | 鼠标所在主题标签保持可见、原位置和最醒目状态，不遮挡真实知识群标题；左上角主题高亮，镜头与节点坐标不变；移开恢复 | `tests/spatial-theme-overview-browser.cjs` |
| 悬停知识群或知识点 → 移开 | 知识群只强调本群节点；知识点优先显示当前标签及真实直接关系，前后关系分色；均不改变选中或学习记录，移开恢复 | `tests/spatial-theme-overview-browser.cjs` |
| 主题 → 点击知识群（含「数据与可能性 → 可能与不一定」） | 点击仅切换选中群组及其详情，不移动镜头；537 点不丢失，地图只显示本群少量真实知识名称，手动缩放也不泄漏其他群名称 | `tests/spatial-theme-overview-browser.cjs` |
| 五个主题标题 → 查看知识群 → 进入群组 → 返回主题 | 每个主题的实际群组、问题和节点计数正确；地图仍保留 537 个领域点；选中主题不移动镜头、重设观察目标或缩放，手动调整视角后同样保持；卡片可滚动，不混入其他主题标签 | `tests/spatial-theme-overview-browser.cjs` |
| 全景 → 点击可见节点 → 切换关系层级 → 取消选择 | 537 个底图节点仍在，背景淡化；镜头不跳，地图缩放工具一直可用 | `tests/spatial-unified-map-browser.cjs`、`tests/spatial-focus-filter-browser.cjs` |
| 选中节点 → 阅读基础与后续 | 直接关系列表默认展开、可滚动或主动折叠 | `tests/spatial-focus-filter-browser.cjs`、`tests/spatial-local-focus-browser.cjs` |
| 认识这张图 → 逐步观察 → 退出 | 同一原始镜头、同一 537 点底图，仅当前源关系变亮 | `tests/spatial-guide-inplace-browser.cjs` |
| 重复手动缩小 → 归位；重新加载极端保存镜头 | 缩放不会让数学图不可辨认；归位由用户主动触发；异常恢复仅在启动时 | `tests/spatial-unified-map-browser.cjs` |
| 小屏 / 浏览器左侧竖栏 → 点击知识 | 知识详情卡完整处于可视安全区，内容可滚动 | `tests/spatial-unified-map-browser.cjs` |
| 从知识或导览进入学习 → 改变窗口尺寸 → 退出 | 独立内容自适应面板，末尾控件可达，返回原空间状态 | `tests/learning-workspace-browser.cjs` |

以上是工程验收项，不得写成孩子已理解关系、三维优于二维或用户视觉已批准。有关联的代码测试还包括 `tests/spatial-overview-browser.cjs`、`tests/spatial-focus-transition-browser.cjs` 和 `tests/spatial-focus-semantics-browser.cjs`。旧 `tests/spatial-local-focus-browser.cjs` 已更新为现行「全景保持、真实路径可追溯」回归并纳入 CI，旧提交中的“选中隐藏节点”断言只作历史参考。此前通过的检查见 [GitHub Actions](https://github.com/runlinx-eng/math/actions/runs/41303409824)，本次更新应以新检查为准；**自动测试通过不等于本地手感及视觉验收**。
