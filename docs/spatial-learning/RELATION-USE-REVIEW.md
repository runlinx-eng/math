# 关系如何在活动中使用：首批核对

2026-11-01。此页记录第一批人工本地代码核对，不是独立数学审阅，也不是孩子实际使用记录。源节点、方向、原理由、本地解释和活动入口仍以 [inventory.json](inventory.json) 为准；单个节点完成不会补记为关系完成。

首批核对三个等值分数节点及其相邻关系：9 条中，3 条已有独立联合任务，4 条无联合任务但已有目标节点任务明确涉及两端的表示或操作，2 条当前证据不足。即使有联合任务，也只说明对应操作可以做；开放解释、独立迁移和一般证明不因任务完成而成立。以下任务编号从 1 开始，程序数组下标从 0 开始。

可机器核对的首批结论、源边和任务指纹保存在 [relation-use-review.json](relation-use-review.json)。运行 `node scripts/check_relation_use_reviews.mjs` 可检查源边、任务归属、任务内容与已登记的相关实现文件是否发生变化；变化后应重新检查，不让旧结论静默沿用。该检查不穷尽间接依赖，也不能证明结论本身正确。`inventory.json` 的 `useReview` 保留首轮映射基线，实际局部核对结果以上述独立文件为准。

全部 1,223 条关系的两端候选任务、已有联合任务与源目标索引汇总在 [relation-evidence-index.json](relation-evidence-index.json)，可用 `node scripts/build_relation_evidence_index.mjs --check` 核对。候选任务只是可供检查的入口，不表示它实际使用了对应关系；联合任务存在也不自动通过内容审阅。

全部 1,223 条关系已经具备来源和入口映射；除上表外 1,214 条仍保持待核对。447 条没有独立联合任务只是一种库存状态，不等于存在 447 个教学缺口。后续应继续逐条记录具体操作、源目标、未评能力和处理决定，不能用自动匹配名称代替内容检查。
