## 正交状态模型

1. **3D 核心**：地图对象和坐标永久常驻；`scene.selected` 是 `theme/pack/node/null`；相机 `position/target/cameraZoom` 独立。
2. **观察**：`selectedGradeStage`、`traceMode`、`edgeDisplay`、`networkView`、导览是同一场景的视图过滤与标注；不重建图谱。
3. **工作表面**：URL 查询参数 `surface=learn|trail|about`，缺省 `explore`；保留原 `#space/{kind}/{id}` 以及老 `#atlas/#trail`。
4. **学习现场**：`journeyOpen` 表示 iframe 已挂载，`journeySuspended` 表示界面收起但仍挂载。两者与当前显示工作表面不同；收起不清空 `src`。
5. **学习证据**：原 `math-explorer-v2` 数据及活动运行器负责保存；工作区开关不执行提交、评分、迁移和覆盖。
6. **视图本地记录**：`math-explorer-network-relationship-view-v1` 添加可选的 `journeySuspended` 提示；老记录缺字段时保持旧行为。

## 操作状态转移

| 操作 | 知识选择 | 相机 | 工作区 |
| --- | --- | --- | --- |
| 点击任意节点／真实关系 | 切到所点对象 | 不变 | 留在探索 |
| 点击「聚焦所选」 | 不变 | 主动定位 | 不变 |
| 「收起信息」／Esc 最后一层 | 清空 | 不变 | 探索 |
| 「上个关注」 | 恢复前一个选择 | 不变 | 探索 |
| 学习→探索／足迹 | 不变 | 不变 | 挂载活动，隐藏显示 |
| 探索／足迹→学习 | 恢复当前学习活动，或打开学习入口 | 不变 | 同一学习运行器 |
| 足迹→作品／知识 | 选择真实关联源节点，打开原活动（如有） | 不变 | 受控切换 |
| 浏览器前进／后退 | 保持选中或应用合法深链 | 不变 | 按 URL 显示 |
| 刷新 | 保留合法选中和镜头 | 从原视图键恢复 | 从原 URL 和挂载提示恢复 |

`learn.html`、`v2.html` 仍能单独打开；不改判题或原学习 schema。主动从学习活动内部执行「结束／看关联知识」仍按任务语义离开该任务；外层「收起」只是视觉收起，不能混为一谈。
