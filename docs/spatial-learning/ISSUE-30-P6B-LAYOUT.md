# Issue #30｜P6-B 空间主体与统一上下文工作区

## 人工反馈与代码原因

本轮修正来自探索、学习、足迹三张实际用户截图；截图只能证明静态布局，不代替键盘/历史/草稿和跨尺寸交互验收。

| Issue #30 项 | 实际原因 | 本轮修改 |
| --- | --- | --- |
| 3D 空间弱、留白偏多 | 节点非结构成员过度淡化、真实关键边背景 opacity 0.085/0.024、默认全貌避让参数对高纵横比不理想 | 提高源节点与关键边可读性；只在主动全貌或首次启动取景使用随窗口比例调整的镜头 |
| 详情卡漂移、过长 | `updateOverlays` 以被选节点投影决定卡片 xy | 右侧统一锚点、视口限定最大高度、详情内部滚动；关系理由可独立滚动 |
| 学习大面板遮蔽空间 | 旧断点下活动面板接近整个窗口宽度，观察工具和镜头条与工作面冲突 | 桌面工作区宽度不超过约 49vw，左侧留真实地图；学习、足迹、知识详情共享右侧定位 |
| 足迹把无提交状态当作作品 | `lessonRecords` 用是否存在学习对象作为进入作品列表的条件 | 真实尝试/保存解释 > 可续草稿 > 待续问题 > 折叠未开始任务；不重算原判题，不迁移旧 schema |
| 跨屏遮挡、空白竖轨、长虚线 | 多层 CSS 的工具轨道覆盖，面板锚点随地图投影改变；独立 UI tether 无最大距离 | 镜头工具固定为底部横向操作组；消除面板排布导致的镜头飞行，限制长距离工作面 tether |

## 空间与信息规则

1. 地图永久常驻并保持可交互。537 个领域节点、50 个数学思维节点及 1,223 条源边、固定 XYZ、学段数据不受本轮编辑。
2. 空间镜头状态与信息工作区正交：选择、查看关系、切换学习/足迹、收起/恢复学习现场、面板排布均不移动镜头。只允许明确的全貌、聚焦、缩放、旋转、平移和标准视角改变相机。
3. 左侧简化观察区，底部相机工具，右侧单列上下文。知识详情按理解、联系、学习与接续分组；关系证明信息仍完整可访问。
4. 通过 `math-explorer-v2` 原保存数据判断足迹优先级。`lessonRecordTier` 与 `activityRecordTier` 不写存储：打开记录不等于已有作品；有草稿不等于正式提交；已保存解释也属于真实记录，但文字内容不自动判正确或推断掌握。
5. iframe 收起时不卸载，原 URL/query/hash、Back/Forward 与 Service Worker 按 P6-A 的数据兼容设计保留。地图 SVG 工作面引导线不是源数学边，过远时不显示。
6. 小屏可以覆盖部分画布，但不得出现第二张图、任务导航页面层级或独立知识树。
