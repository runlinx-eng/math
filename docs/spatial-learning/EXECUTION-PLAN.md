# 新空间与学习引导执行方案

日期：2026-11-01。状态：第 1–4 步完成接入、关系可读性调整、导览与原有点亮整合的有界技术验证；第 5 步进行中，第 6 步待实施或验收。

**当前有效的具体交互及验收要求见 [v53 空间交互基准](INTERACTION-RULES.md)。** 本计划的早期步骤保留实施历史；冲突的聚焦隔离、禁用缩放及自动镜头跟随方案均不再执行。

本文件由[项目执行计划 v3](../EXECUTION-PLAN.md)引用，负责空间、引导和点亮工作的实施分解。当前产品界面及缓存为 v56，新坐标为 v53，v49 与更早坐标继续保留。原计划的阶段 6 审计、阶段 4 真实试用和独立数学审阅继续保留。

## 目标与顺序

把用户选定的新分布接入现有产品，让孩子能从真实起点认识分支与汇合，再沿完整内容学习、留下记录和继续探索。数学关系是核心；空间帮助看懂关系，学习活动提供操作与思考的机会。

先保全信息并接通新布局，再改善可读性，再做引导与长期点亮。数学思维在相关活动中呈现，过程反馈以实际行为为依据。当前不承诺三维地图已经产生长期认知或学习效果。

1. 建立完整对照清单。
2. 接入新布局与 v52 功能。
3. 优化整体和局部的关系读法。
4. 接入结构导览、注意力引导和长期点亮。
5. 核对关系的活动使用，按需补充活动与思维反馈。
6. 完成全量审计收口，分别记录数学审阅和实际试用。

第 1 步开始建立全量审计清单；后续每一步更新其状态。第 6 步负责收口，不把所有检查都推到最后。每步先完成可检查的产物，再进入依赖它的下一步；这些检查不新增人工审批。人工试用未发生时，继续不依赖该结果的实现和核对，并明确待验收状态。

## 已确定的设计边界

| 内容 | 本轮采用的规则 |
| --- | --- |
| 空间分布 | 以用户指定 HTML 的完整领域节点分布为起点，不重新拼接小样树；整体、局部和引导共用同一套固定坐标 |
| 高度 | 不展示 26 级台阶，不强制等距层高；连续高度表达基础到后续。默认领域图中每条 hard 关系的前项仍低于后项；soft 不决定高度 |
| 水平位置 | 用来表达关联邻近、分支与汇合；X、Z 不必分别对应独立指标。距离和中心位置不宣称是难度、重要性或必经次序 |
| 主题和分组 | 五主题、23 分组继续作为分类、查找、活动和旧路线入口，不再强制决定新世界的全部水平位置 |
| 537＋50 | 537 个非 thinking 节点构成默认主图；50 个 thinking 节点保留来源、关系、活动和记录，通过搜索、列表及相关活动进入，无需全部常驻为球 |
| 关系可达 | 全部 1,223 条关系可查。收起、淡化和不常驻为球均不删除关系，不连接被省略节点的两端来伪造一条新边 |
| 轮廓 | 骨架只是一种显示选择，不命名为唯一数学主干。完整直接前置、汇合、跨分支关系始终可展开 |
| **统一空间交互** | 全景、手动缩放、选中、按源关系逐层突出和五步导览均使用同一张可缩放的 3D 地图；不因聚焦删除 537 个底图节点。点击可见节点和引导切步不自动移动镜头；取消选中保留相机，用户点「归位」才重新取景 |
| **独立学习工作区** | 只有进入真实学习活动才隐藏地图控制，面板随内容与可用视口自适应；退出回到原知识位置/引导步骤。避免固定高度截断操作区 |
| 导览 | 提供起步建议，可以跳过、换起点和自由探索；不把源箭头或主干变成强制课程次序 |
| 信息密度 | 全图持续可访问；新引导不施加全局“只能看 2–3 个入口”的硬上限。已有短路线与分页能力继续保留 |
| 点亮 | 当前观察使用临时高亮，学习完成使用持久标记。浏览、导览、两个端点分别完成都不自动完成一条关系 |
| 思维反馈 | 描述这次实际采用的方法及修改过程；开放解释保存待核对，不自动评级，不由一次答对或节点完成认定能力成长 |
| 产品范围 | 中文、电脑、本地离线；不新增家长端、云服务、模型接口、外部分析或移动端任务 |

26 层是当前最长 hard 链产生的结构统计，可以继续保留用于检查与解释。改变等距层高不改变源图的前后关系，也不需要另造三层或五层。切换顶视、侧视和立体视角只换相机；默认继续使用 v52 的正交相机和真实固定视角，不照搬原型约 77° 的“俯视”及其透视混合。

涉及 thinking 节点的源边在完整数据中保留其方向和类型，通过上下游列表、来源说明及活动上下文呈现。没有空间位置的节点不参与主图球体数量统计，也不被计为丢失；其既有进度、问题和操作现场仍能恢复。需要完整旧空间时仍可进入 v49 世界。
