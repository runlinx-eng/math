## 五个观察步骤

| 步骤 | 本步强调的来源联系 |
| --- | --- |
| 一个起点 | 一一对应地数 → 一共有多少／顺序数到 100／数 20 以内的物品 |
| 共同基础 | 一一对应地数 → 一共有多少 |
| 分叉 | 一共有多少 → 合起来就是加法／拿走与分开：减法的意义 |
| 汇合 | 合起来就是加法、拿走与分开的意义 → 表示加减法 |
| 继续探索 | 拿走与分开 → 平均分与除法 → 什么是二分之一 |

每条箭头都按源 ID 核对为实际 hard 边。第五步明确回到之前的减法分支，不虚构“表示加减法”直接通往除法的边。原型从“一一对应地数”开始，但不宣称它是数学唯一的起点。

图中保留完整底图；按现行交互约定，观察步骤只调整说明与真实关系的强调范围，不自动改变当前相机，已看过的节点及联系逐步留在画面中。孩子可回到上一步、从头看、离开导览、直接选节点或进入实际活动。导览的进度条表示看到了哪一步，不是学习或掌握进度。

## 自由探索与学习记录

- 选中任意有后续活动的节点时，建议从该节点真实的外向关系中选择；有到期问题的节点优先，其次考虑未完成活动和关键关系。理由来自对应源边已有的本地说明；完整直接关系列表仍然可用。
- 五步是一个明确的示例。动态建议从完整 587 节点和 1,223 条关系中筛选当前节点的外向边及有活动的后项；已核对跨主题、思维节点以及没有独立联合任务的源关系。没有符合条件的后项时不显示建议；每次只展示一条建议，但全部直接联系仍可查看。
- 继续入口先处理待续问题与真实未完成活动。若该活动来自导览，续做后可以回到原观察步骤；无匹配内容的问题仍保存原话，不编造答案。
- 节点完成标记沿用实际任务规则；关系金线只来自对应联合任务。两个端点分别完成不会自动点亮连线。导览高亮、浏览、预览或看完步骤不会写入完成。
- 真实完成的节点标记与联合关系在注意力切换时保留；图外对象仍可通过搜索和关系列表进入。背景淡化不表示未学或未掌握。

导览状态单独保存在学习记录的 `daily.guide` 中，并随备份导入合并；导览中留下的问题保存步骤及原有现场。刷新、模拟跨日、重复导入和离线续接有隔离浏览器检查。来源边若发生变化导致示例无法验证，导览会暂时收起，其他地图内容仍可使用。

本轮只完成引导与标记的技术接入；它没有自动评判开放解释，也没有证明思维能力成长、长期记忆或知识迁移。关系逐项使用审计和独立数学审阅仍待完成。

## 现行关系地图交互约定（2026-11-01）

本节是新关系地图 v53+ 的**当前产品交互口径**，覆盖之前“选中后只保留局部节点”“选中时禁用缩放”“导览自动追随镜头”等历史尝试。旧实现说明与对应测试结果仅证明当时的行为，不得用来要求恢复这些旧限制。以下是预期行为，**文档统一不等于代码或人工验收已经通过**。

1. **全景与缩放是一张地图**：全景显示 537 个有空间位置的领域知识点，以及所选背景真实关系；滚轮缩放、旋转、平移和视角切换是同一套连续操作。缩放可让名称逐步显现，但不改变固定三维坐标和真实边。
2. **点击节点只是选中，不是进入学习页面**：当前节点及真实前置、后续和已探索的实际路径醒目，其他节点和背景以低对比度／半透明状态**继续留在原来的空间**，而不是突然消失或换一张“局部地图”。侧栏展示详情、完整直接联系与主动追溯入口。点相邻节点可沿真实边连续探索；不相邻的搜索跳转可以重置高亮路径，但不得删除全景背景或虚构新边。
3. **“认识这张图”仍在同一张地图上**：从当前视角和缩放进入导览；开始、下一步、上一步、跳过或退出，只改变强调的真实节点／连线、说明和步骤状态，**不自动转动、追踪、缩放或重置镜头**。导览中已走过的真实联系可继续强调，周围全景仍保持低对比度可见。
4. **地图控制始终可用**：全景、放大后的地图、选中节点、导览期间都允许缩放、旋转和平移；“选中禁用缩放”不再有效。只有用户主动选择“全貌”或固定顶视／侧视／立体视角时，才执行相应的明确归位或视角变化。相机需有限度地控制缩放和可恢复范围，避免跳轴、旋转后找不到图；不以自动追镜头替代“全貌”等显式找回动作。
5. **真正进入知识点学习后才切换固定自适应面板**：点击“开始”等明确的学习入口，才离开自由地图操作，使用固定、适配屏幕的任务面板；普通选点和“认识这张图”均不触发该切换。返回数学树时恢复进入前的视角、缩放与选中／导览上下文，不重排节点。

保留 50 个没有常驻空间球的思维节点的搜索、列表和学习入口；完整 587 节点与 1,223 条来源关系、hard／soft 类型、实际完成记录和旧 v49 相机／问题恢复规则均不受上述显示约定影响。探索历史最多保留 16 个连续节点的原规则可作为高亮范围，不可作为隐藏其他背景点的理由。

**交互验收口径**：连续操作“全貌 → 手动缩放／旋转 → 选中节点 → 认识这张图 → 导览前后步骤 → 返回自由探索”，相机不得无指令跳动，非相关节点不得消失，缩放不得被禁用；“开始 → 学习面板 → 返回地图”应恢复原观察状态。历史 `tests/spatial-local-focus-browser.cjs` 检查的是旧局部隔离行为，不能单凭它通过就声称本约定已验收；需依新口径另做运行和人工核对。
